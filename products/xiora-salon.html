What XioraSalon is

「実務 質問 の 場」+「記事 archive」を、
1 会員 で 提供。

XioraSalon は、単なる 情報 発信 ではなく、実務者 が 質問 と 相談 を 出せる Discord コミュニティ と、Xiora が 継続 公開 する note 有料 記事 archive を 束ねた 会員 サービス です。 AI 実務 / SaaS 起業 / 個人投資家 の 3 領域 で それぞれ 独立 サロン を 運営予定。

3 Salons

3 領域 の サロン

AI 実務 サロン

Claude Code / Playwright / Ollama / MCP 等 の 実装 相談 と 事例 共有。 Xiora の 24/7 運用 knowledge を 会員 共有。

SaaS 起業 サロン

個人 / 小規模 チーム で SaaS を 立ち上げる 実務 相談。 決済 / インフラ / 法務 の 3 論点 を 中心 に 共有。

個人投資家 サロン

個人投資家 の 情報 共有 と 疑問 交換。 投資助言業 に は 該当しない 情報 共有 場 として 運営。

note 有料 記事 archive

Xiora の note 有料 記事 (継続 公開) を 会員 が 全 閲覧 可能。 個別 購入 不要。
