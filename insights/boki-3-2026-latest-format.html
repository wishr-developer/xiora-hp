日商 簿記 3 級 の 概要

日本商工会議所 実施、 業種問わない 経理 の 基礎、 年間 受験者 20 万人 前後。 CBT 通年実施 (2020 開始)、 統一試験 は 年 3 回。 合格 率 CBT 40-50 % / 統一試験 30-40 %。 学習時間 目安 50-100 時間。

Nexa v2 簿記 講座 の 章立て

全 10 章: (1) 簿記 の 基本 / 貸借対照表 / 損益計算書 (2) 仕訳 の ルール (3) 現金 と 預金 (4) 商品 売買 (5) 手形 (6) 固定資産 (7) 費用収益 の 計上 (8) 決算 整理 (9) 精算表 と 財務諸表 (10) 総合演習。

2026 出題傾向

第 1 問 (仕訳) 45 点、 第 2 問 (帳簿) 20 点、 第 3 問 (精算表 / 財務諸表) 35 点 = 合計 100 点、 70 点以上 合格。 出題 は 商品 売買 (第 1 問 頻出)、 固定資産 減価償却 (第 3 問 頻出)、 決算 整理 の 3 分野 が 中心。

Nexa v2 の AI 演習

各 章末 の 演習 は 過去 5 年 の 過去問 パターン を base に 生成、 学習者 の 弱点 分野 を 個別 検出。 「仕訳 の 選択肢 選択 ミス パターン」を 5 分類 (現金 / 買掛金 / 未払金 / 前払費用 / 減価償却) で 特定、 弱点 分野 に集中演習。

CBT vs 統一試験

CBT は 通年実施 で 好きなタイミング で 受験可能、 結果 は 即時 判定。 統一試験 は 年 3 回、 会場 制限、 結果 は 後日。 Nexa v2 は CBT 前提 で 「1 問 制限時間」を 意識した 演習 パターン を 実装。

受験 スケジュール

学習 開始 → 3 週間 で 全 10 章 完了 → 過去問 3 回 演習 → 弱点 補強 1 週間 → CBT 受験 = 標準 6 週間。 Nexa v2 の 講座 完了時 に 「模擬 CBT」機能 で 実 試験 想定 の 60 分 演習 が可能。

2027 出題変更

2026 年 4 月から の 出題変更 (第 2 問 の 商品有高帳 追加、 電子記録債権 廃止 の 段階的移行) が 継続。 Nexa v2 講座 は 2026 出題変更 を 反映済み、 過去問 も 2026 4 月以降 分 を 中心 に 更新。

合格 保証 なし の 明記

免責: 本 講座 は 合格 を 保証 する もの では ありません。 学習 内容 は 情報提供 のみ、 合否 は 学習者 の 学習量 と 試験 対策 に 依存 します。 講座 完了 + 過去問 3 回 演習 で 標準 合格率 70 % 前後 が 経験的 estimate ですが 個人差 あり。
