差別化 factor 1: 日本語 native UI + サポート

A 社 · B 社 (海外 LMS SaaS) は 英語 native の platform で、UI 翻訳 が 進んで いる ケース も ある もの の、深部 の 設定 画面 / 契約 書 / support は 英語 が 中心 と なる 想定 です。 Nexa Academy は 開発 元 が 日本 (xiora、代表 沓澤 怜士 = 日本 単独 開発 運営) で、全 UI + support + 契約 書 + 請求 書 が 日本語 で 完結 します。

  • 管理 画面 / 生徒 画面 / 講師 画面 全て 日本語 native (機械 翻訳 なし)
  • customer support は xiora の 日本語 対応 (email + Slack)
  • 契約 書 (利用 規約 / 特商法 表記 / 個人 情報 取扱) 全て 日本語 で 準拠
  • コース 内 で 日本語 formatting (縦 書き / ルビ / 顔文字 / 絵文字) の 表示 崩れ が ない

差別化 factor 2: ¥ 円 決済 + 国内 適格 請求書

日本 の 法人 が 海外 SaaS を 使う 際 の 実務 上 の 大きな 摩擦 は「請求 が USD 建て で 経理 処理 が 面倒」「適格 請求書 (invoice) が 出ない」「消費 税 の 逆 charge 処理 が 必要」の 3 点 です。

  • Nexa Academy は 全 プラン ¥ 円 建て 請求、Stripe Japan 経由 で JP QR / クレカ / 銀行 振込 対応
  • 適格 請求書 (invoice) は Nexa 側 で 自動 発行、消費 税 込 表示 が 標準
  • 領収 書 は xiora 名義 (JP 事業者)、経理 処理 が 単純
  • 海外 SaaS の 場合 は USD 建て 請求 → 為替 レート で 記帳 → 適格 請求書 なし → 消費 税 逆 charge 処理 が 必要 (経理 担当 の 実 工数)

この 4 点 は 特に 中小 企業 (経理 担当 1 人 or 兼務) で は 決定 要因 に なり やすい 想定 です。

差別化 factor 3: AI 講師 / AI 採点 / AI 学習 ロードマップ 内蔵

2026 年 時点 で、海外 の 主要 LMS SaaS が AI 機能 を 内蔵 する 傾向 は 進んで います (海外 LMS SaaS の AI course creator (A 社 / B 社 / C 社)). しかし、日本語 の 講師 発話 + 日本語 の 生徒 回答 に 対して 精度 の 高い 対応 が できる かは、追加 で 別 API (OpenAI / Anthropic) を 経由 する 前提 と なる 想定 です。

  • Nexa は AI 講師 (24h 質問 対応)、AI 採点 (記述 式 の 部分 点)、AI 学習 ロードマップ (個別 最適 コース 順) を 標準 内蔵、追加 API 契約 不要
  • AI モデル は 内部 で Ollama (self-host) + 商用 API を 適材 適所 で 切替、日本語 精度 を 最適化
  • 教材 up 時 の 「AI が 小 テスト 自動 生成」「AI が 動画 の 目次 抽出」も 内蔵

差別化 factor 4: SCORM 1.2 / xAPI 対応 (既存 教材 の 流用)

既に 別 LMS で e-learning を 運用 して いる 事業 者 が 「移行 コスト を 抑えて 乗り換えたい」場合、SCORM / xAPI (Tin Can API) 対応 が キー に なります。 Nexa Academy Growth プラン 以上 で SCORM 1.2 / xAPI 対応 済、既存 教材 の import が 可能。 A 社 · B 社 (海外 LMS SaaS) は SCORM 対応 状況 が プラン に よる の で 都度 確認 が 必要 な 想定 です。

どんな 事業 者 に Nexa が fit する か

  • 日本 の juku・個別 指導 塾: 教材 配信 + 保護者 通知 + 修了 証 発行 を 日本語 で 完結
  • 企業 の 研修 部門: 新人 研修 / コンプラ 研修 の 内製 化、¥ 円 経理 + SCORM 移行
  • 士業 事務所 (社労士 / 税理士 / 弁護士): 顧問 先 に 「法改正 e-learning」を 追加 課金 で 配信 → 収益 化
  • 個人 講師 / 資格 学校: Learner プラン ¥1,980/月 で 手軽 に 開始、成長 段階 で Growth に upgrade

どんな 場合 A 社 · B 社 (海外 LMS SaaS) が 合う か

  • 顧客 が 海外 中心 (US / 欧州)、UI + 契約 書 は 英語 でも 問題 なし
  • USD 決済 で 問題 なく、為替 リスク を 事業 者 が 吸収 できる
  • 既 に A 社 · B 社 (海外 LMS SaaS) で 稼働 中、移行 コスト より 継続 コスト が 低い

よく ある 質問

Q. A 社 · B 社 (海外 LMS SaaS) から の データ 移行 は 可能 ですか?
A. SCORM 1.2 / xAPI で export できる 場合、Nexa Growth 以上 で import 可 です。 独自 form 埋込 の 場合 は 個別 対応 に なります (info@ で ご 相談 ください)。

Q. Free プラン と Learner プラン の 違い は?
A. Free は 3 コース お試し + 個人 学習 のみ。 Learner (¥1,980/月) で 36+ コース 全て 学び 放題 (順次 拡充 中) + progress 保存 が 使えます。

Q. 生徒 側 の 決済 は Nexa 経由 で 可能 ですか?
A. Growth プラン 以上 で 貴 事業 者 の Stripe アカウント 連携 が 可能、生徒 の 受講 料 は 貴 事業 者 に 直接 入金 されます (Nexa 手数料 は プラン 内 で 完結)。

Q. 契約 期間 の 縛り は?
A. 月 単位 契約、いつ でも 変更 / 解約 可。 年 契約 割 引 は 別途 relations@ で 相談 可。
