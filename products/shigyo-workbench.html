よくある質問

freee / MFクラウド 以外 でも 使えますか？

CSV 連携 は 対応 済。 API 連携 は 弥生 会計、 マネーフォワード クラウド、 freee を 標準 で 提供。 他 会計 ソフト は 相談 ください。

顧問先 の 個人情報 は どこ に 保存 されますか？

日本国内 の AWS Tokyo リージョン に 保存。 顧問先 単位 で テナント 分離 し、 事務所 が 顧問先 を 解約 する 際 は 30 日 以内 に 完全 削除。

AI が 出す draft の 精度 は どのくらいですか？

標準 業種 (製造・小売・飲食・サービス) で 90% 以上、 特殊 業種 (医療・不動産・農業) で 70-85% を 目安。 精度 は 事務所 毎 に 用語 学習 で 継続的 に 上がります。

解約 は いつでも できますか？

Starter は 3 ヶ月 継続 後、 Standard は 6 ヶ月 継続 後、 Firm は 年 契約。 解約 時 は 引継 用 の 顧問先 データ (CSV) を 全て お渡し します。
