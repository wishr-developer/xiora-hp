What's inside

含まれる もの

  • Playwright (Python) 汎用 contact form 自動 submit script (name / email / phone / message 4 field mapping + CAPTCHA 敬意 skip 判定)
  • Gmail SMTP 送信 module (Vault key 読み込み + SMTP login user rule + 送信 log)
  • IMAP 返信 watcher (auto-reply / bounce / real reply の 3 分類 filter + Gmail label 貼り付け)
  • 4 段 follow-up state machine (初回 → D+3 → D+7 → 停止 判断、 各段 で opt-out 有無 check)
  • launchd plist 2 本 (send daemon · watch daemon) + systemd unit 2 本 (VPS 版)
  • 特電法 準拠 template (opt-out URL + 発信者 情報 5 要素 + 送信前 3 点 checklist)
  • research-based cold email の 骨格 (10 業種 skeleton は Xiora Cold Email Template Pack と 別 販売、 本 SKU は pipeline 本体)
  • README.md 6,000 字 (setup · Gmail app pw · 送信 rate 設計 · noise 除去 rule)

Where to use
