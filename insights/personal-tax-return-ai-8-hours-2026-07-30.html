個人 事業主 が AI で 確定 申告 を 8 時間 で 終わらせる 実務 手順 (2026 年 版)

2026-07-30

重要 な 前提 — 税務 代理 · 税務書類 作成 は 税理士 独占 業務

本 記事 で 扱う の は 「事務 作業 の 自動 化」の 範囲 のみ です。 税務 代理 (税務署 と の やり取り 代行) · 税務書類 の 作成 · 税務 相談 は 税理士 法 第 52 条 に 定める 税理士 の 独占 業務 で、 xiora · Nexa Academy · 記事 執筆 者 は 一切 提供 しません。 個別 の 税務 判断 (経費 該当 性 · 勘定 科目 · 控除 適用) が 必要 な 場合 は 必ず 税理士 に ご 相談 ください。

1. 「確定 申告 に 時間 が かかる」の 内訳

副業 · 個人 事業主 の 確定 申告 で 発生 する 作業 は、 大 きく 3 分類 に 分け られる。 それぞれ 「AI で 圧縮 できる 部分」と 「税理士 判断 が 必要 な 部分」が 混在 して いる こと が、 見積 り の 難しさ の 原因。

  • ① 領収 書 · 明細 の 収集 · 分類 (事務 作業): 紙 の 領収 書 撮影、 銀行 · card 明細 の csv download、 費目 分類。 一般 に 全 体 の 60-70% の 時間 を 占める。
  • ② 会計 ソフト へ の 入力 · 集計 (事務 作業): 仕訳 入力、 月次 集計、 決算 整理 仕訳、 青色 申告 決算 書 · 収支 内訳 書 の 数字 埋め。 20-25% の 時間。
  • ③ 税務 判断 · 提出 (税理士 領域): 経費 該当 性 の 最終 判断、 控除 適用 の 可否、 e-Tax 提出 · 税務 相談。 10-15% の 時間 だ が、 独占 業務 に 該当。

AI で 圧縮 できる の は ① と ② の 事務 作業 部分。 ③ は 判断 の 責任 が 発生 する ため、 税理士 に 依頼 する か、 本人 が 税務署 の 無料 相談 窓口 で 確認 する 前提 と なる。

2. 8 時間 の 内訳 (実務 手順)

「合計 8 時間」の 目安 は、 副業 · 個人 事業主 で 年間 領収 書 300-500 件 · 取引 銀行 1-2 行 · 収入 源 2-3 の 想定 case。 領収 書 数 · 収入 源 数 に よって 増減 する。

Step 1 — 領収 書 · 明細 の 一括 収集 (2 時間)

  • 紙 領収 書 を スマホ カメラ で 撮影 (100 枚 で 30 分 目安)
  • 銀行 · クレジット card の csv 明細 を 期間 指定 で download (1 行 30 分 目安)
  • Amazon · 楽天 等 の 購入 履歴 を csv export (1 サイト 15 分 目安)

会計 SaaS (freee · マネーフォワード 等) を 使う 場合、 銀行 · card の 連携 を 有効 化 する と csv download が 自動 化 される (初期 設定 に 30 分 · 2 回 目 以降 は 0 分)。

Step 2 — AI で 仕訳 分類 の 下書き 生成 (3 時間)

ここ が AI 活用 の コア。 領収 書 画像 と csv 明細 を AI (OCR + 分類 model) に 投入 し、 「日付 · 金額 · 支払 先 · 推定 費目 · 摘要」の 表 を 生成 する。 一般 的 な AI 経理 補助 tool は 過去 の 仕訳 履歴 を 学習 し、 2 年 目 以降 の 分類 精度 が 上がる 設計 が 多い。

  • 会計 SaaS 内蔵 の AI 分類 (freee · マネーフォワード) を 使う 場合、 学習 済み の ルール で 80-90% 程度 は 自動 分類 される (残り は 人 が 修正)
  • 汎用 AI (Claude · ChatGPT 等) に csv を 貼って 「摘要 から 費目 を 推定 して」と 依頼 する 方法 も 実務 で 使用 されて いる が、 個人 情報 · 取引 先 情報 の 送信 可 否 を 事前 に 判断 する 必要 が ある

AI の 出力 は あくま で 「下書き」。 費目 の 最終 判断 (交際 費 か 会議 費 か · 消耗 品 費 か 事務 用品 費 か · 経費 該当 性) は 事業 実態 に 依存 する ため、 本人 の 判断 or 税理士 確認 が 必要。

Step 3 — 会計 ソフト へ の 反映 · 集計 (1.5 時間)

AI 生成 の 仕訳 下書き を 会計 ソフト に 取り込む (csv import or API 連携)。 月次 · 費目 別 の 集計 表 が 自動 生成 され、 青色 申告 決算 書 · 収支 内訳 書 の 各 欄 に 数字 が 埋まる。

Step 4 — 税務 判断 · 最終 確認 (1.5 時間)

ここ から は 税務 判断 の 領域。 経費 該当 性 · 控除 適用 · 減価 償却 の 計上 方法 · 家事 按分 の 割合 等 の 個別 判断 は、 税理士 相談 or 税務署 無料 相談 (毎年 2-3 月) で 確認。 e-Tax で の 提出 手続 も この 段階。

「本人 が 判断 する か · 税理士 に 依頼 する か」は 事業 規模 · 取引 の 複雑 度 に 依存。 副業 で 年 収 300 万 円 未満 · 事業 内容 が 単純 なら 本人 判断 + 税務署 相談 で 完結 する ケース も 多い。 事業 収入 が 大 きい · 減価 償却 資産 が ある · 消費 税 の 課税 事業 者 の 場合 は 税理士 依頼 の 検討 価値 が 高い。

3. 会計 SaaS と AI の 使い分け 判断 軸

「freee 等 の 会計 SaaS を 契約 する か · AI + スプレッド シート で 済ませる か」の 判断 軸 を fact-based で 整理。

  • 会計 SaaS (freee · マネーフォワード 等): 銀行 · card 連携 · 仕訳 学習 · 決算 書 出力 が 統合 済み。 費用 は 年 ¥12,000-¥40,000 程度。 青色 申告 65 万 円 控除 の 電子 帳簿 要件 に 標準 対応。 取引 数 が 多い · e-Tax 提出 まで 一気通貫 で 使いたい 場合 に 向く。
  • AI + スプレッド シート: 費用 は AI 利用 料 のみ (月 ¥0-¥3,000)。 仕訳 分類 · 集計 は AI + Excel · Google Sheets で 実行。 決算 書 は 国税 庁 の 手書 き 用紙 or e-Tax 直接 入力。 取引 数 少 (年 100 件 未満) · コスト 優先 の 場合 に 向く。
  • 会計 SaaS + AI 併用: 会計 SaaS 内蔵 の AI 分類 で 80-90% を 自動、 残り の 分類 · 摘要 生成 を 汎用 AI で 補助。 取引 数 中 (100-500 件) の 実務 で よく 見る パターン。

4. AI 活用 で 気 を 付ける 3 点

  • 個人 情報 · 取引 先 情報 の 送信 範囲: 汎用 AI に csv を 貼る 場合、 取引 先 名 · 金額 · 住所 等 の どこ まで を 送信 する か を 事前 に 判断。 匿名 化 して から 分類 依頼 する 選択 肢 も ある。
  • AI 分類 の 精度 は 100% で は ない: 「絶対 に 合って いる」と 過信 せず、 高額 取引 · 特殊 費目 は 人 の 目 で 再確認。 分類 誤り が 税務 判断 に 影響 する ため。
  • 電子 帳簿 保存 法 の 要件: 電子 取引 の データ 保存 に は 検索 要件 等 が 定め られて いる。 AI 生成 の 分類 結果 で は なく、 元 の 領収 書 · 明細 データ を 適切 に 保存 する 必要 が ある。
