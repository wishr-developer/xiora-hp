差別化 factor 1: 日本語 native な 文面 生成 + 返信 分類

海外 sales engagement platform の LLM 統合 は 進んで います が、日本語 の 敬語 / お客様 呼称 / 業界 慣習 (「株式会社」を 頭 に 置く / 部署 名 の 表記 揺れ 対応) を 深く 学習 した モデル は 少 なめ です。 汎用 LLM 経由 で 日本語 出力 させる 場合、次 の 3 課題 が 起き やすい 想定 です。

  • 敬語 の 微妙 な 選択 (「ご検討 いただけ ませ ん でしょう か」等) が 直訳 調 に なる
  • 宛先 の 姓 + 敬称 が 「様」でなく「さん」「殿」等 mix する
  • 返信 の sentiment (「検討 させて ください」= 実質 NG、「一度 話 を」= 高 意向) の 分類 精度

Sales AI OS は 日本語 sales 文面 の corpus で fine-tune した 内部 LLM 経由 で 生成 + Ollama (self-host) で cost 圧縮、外部 API 経由 なし に 日本語 で 高精度 な 生成 が 可能 です。

差別化 factor 2: ¥ 円 決済 + Stripe JP + 国内 適格 請求書

A 社 · C 社 · B 社 (海外 sales engagement SaaS) の 主 課金 通貨 は USD、日本 の 法人 が 使う 際 は USD 建て 請求 + 為替 記帳 + 適格 請求書 なし + 消費 税 逆 charge 処理 が 経理 側 の 実 工数 に なります。

  • Sales AI OS は ¥ 円 建て 請求、Stripe Japan 経由 で JP QR / クレカ / 銀行 振込 対応
  • 適格 請求書 は Stripe から 自動 発行、消費 税 込 表示 が 標準
  • 領収 書 は xiora 名義 (JP 事業者)、経理 処理 が 単純

差別化 factor 4: 18 体 設計 中 の AI agent (18/18 α 稼働、純粋 関数 layer 完成)

Sales AI OS は 営業 + post-sale の 8 割 (リード 収集 / 文面 生成 / 返信 対応 / 日程 調整 / CRM 更新 / 提案 書 作成 / customer success / churn 予兆 / upsell · cross-sell / referral 等) を 18 種 の AI agent が 分業 して 自動 実行 する 前提 で 設計 されて います。 SDR チーム を 雇用 する 前 の 選択肢 と して、または SDR + CS の 補助 tool と して 使える 想定。 現在 18 体 の 純粋 関数 判定 layer (pytest 100% coverage) が 稼働中、次 Phase は LLM 統合 と 外部 CRM 双方向 sync。

  • リード 収集 agent · ICP (Ideal Customer Profile) を 元 に web + 公開 DB から 収集
  • 文面 生成 agent · 対象 別 に customize、テンプレ blast 回避
  • 返信 対応 agent · sentiment 分類 → interested/question/opt_out/decline 別 に draft 生成
  • 日程 調整 agent · Google Calendar 連携 で 30 分 枠 提示 → 相手 が 選択
  • CRM 更新 agent · 全 事象 を CRM に 自動 記録、更新 忘れ 防止

どんな 事業 者 に Sales AI OS が fit する か

  • 個人 事業 主 + 1-3 名 の 小 team: Starter ¥3,000/月 で 開始、営業 専業 の 人員 コスト を 抑える
  • SMB 経営 者 (5-30 名): SMB ¥30,000/月 で 全 AI 機能、SDR 雇用 (月給 30 万円) の 代替
  • 成長 期 の 中小 (30-100 名): Business ¥100,000/月 + 専属 CS + custom integration
  • 士業 事務所 / 不動産 / 保険 / 教育 系: 日本語 native + JP 顧客 が 中心 の セグメント で は 差別化 明確

どんな 場合 海外 platform が 合う か

  • 顧客 が グローバル (US/EU) 中心、英語 で 商談 が 進む
  • SDR チーム が 10-100 名 規模、advanced dialer / power dial 等 の 深機能 が 必須
  • 既 に Salesforce + A 社 サービス (海外 sales engagement SaaS) で 稼働 中、移行 コスト より 継続 コスト が 低い
