1. なぜ dogfood 進捗 を 公開 する か

「AI で 事業 を 動かす」を 訴求 する SaaS 会社 は 多い です が、内側 の 実装 log を 数値 で 公開 する 例 は 少 なめ です。 xiora は 個人 事業 (代表 1 名) で 7 稼働 SaaS + 2 α 版 を 24/7 で 運営 して おり、 各 週 の build 進捗 を 実 commit / 実 DB / 実 送信 log の 数値 で 記録 · 公開 する こと で、 SMB · 個人 事業 者 の 実装 判断 の 参考 材料 に なる こと を 目指し ます。

2. build 側 の 24 時間 (agent 実装 + コース 追加)

Sales AI OS (α 版 · 13/13 稼働 完成)

7 月 25 日 時点 4/13 稼働 → 26 日 に かけて 9 agent 追加、13/13 稼働 (α 純粋 関数 layer 完成) に。 追加 した agent の 実装 pattern は 純粋 関数 (pytest 100% coverage) + AI 呼出 なし の 決定 的 判定 で、confidence は 常時 1.0。 次 Phase = LLM 統合 + 外部 CRM 双方向 sync。

  • reply-agent: 受信 email の intent (interested / question / decline / opt_out / auto_reply / bounce) を keyword base で 分類、intent 別 draft 返信 を 生成
  • scheduling-agent: 平日 10-18 JST の 30 分 slot を 3-5 個 提示、営業 電話 070-9165-0203 を footer に 埋込
  • contract-agent: plan tier 別 に 契約 書 draft を 生成 (Starter / SMB / Business = ¥3,000 / ¥30,000 / ¥100,000 月 額)、弁護士 review 必須 明示
  • crm-agent: stage 遷移 (lead → contacted → engaged → meeting → proposal → won / lost / opt_out) の 検証、次 action 提案
  • proposal-agent: customer_size (individual / smb / mid / large) → plan mapping + 多 product bundle、総額 計算
  • billing-agent: Stripe payment link mapping (LIVE 3 link) + invoice 番号 + 銀行 振込 案内 (口座 情報 は 別 mail、セキュリティ 配慮)

EC-Autopilot (α 版 · 17/20 稼働)

7 月 25 日 時点 4/20 稼働 → 26 日 に かけて 13 agent 追加、17/20 稼働 に。 EC-Autopilot も 全 て 純粋 関数 ベース (AI 呼出 なし) の 判定 layer。 追加 分 に 含まれる: legal-checker (景表法 · 薬機法 二重 検査)、shipping-monitor (発注/発送/紛失 判定)、order-processor (冪等 pipeline)、marketer (segment 別 channel 推奨)、sns-writer (platform 別 draft + NG 検査)、email-marketer (特電法 遵守 頻度 cap)。 残 3 (orchestrator / product-scout / review-manager) は Phase 5+ 予定。

  • fraud-detector: 注文 の 不正 リスク を 15 signal で スコア 化、pass / review / block を 決定
  • return-judge: 返品 リクエスト を 自動 承認 / 目視 / 却下 に 判定、返送 送料 の 負担 者 も 決定
  • dynamic-pricer: 在庫 · 需要 · 競合 価格 から SKU 価格 算出 (下限 保証 付き)
  • supplier-selector: 候補 仕入先 群 から 総 コスト + 信頼 性 の 総合 スコア で 最適 選択
  • inventory-monitor: 現在 在庫 と 平均 日 販 から reorder 推奨 · 緊急 · out 検知
  • seo-writer: 商品 名 + カテゴリ + benefit + keyword から SEO title / meta / description / tags を 生成 (禁句 二重 check)
  • tokusho-generator: 販売 事業 者 情報 + 商品 情報 から 特商法 表記 draft を 生成、必須 fields validate、弁護士 review 必須 明示

6. 遵守 rule (Xiora 憲法)

  • 資格 必要 事業 NG: 投資 助言 業 · 医療 機器 業 · 弁護士 業 · 税理士 業 等 の 業許可 · 士業 資格 必要 事業 は 一切 行わ ない
  • 事故 領域 exclusion: 薬機法 · 金商法 · 景表法 · 著作 権 · 政治 · 宗教 · 差別 に 該当 する コンテンツ · アフィリエイト は 全 pipeline で 自動 exclude
  • ステマ 規制 (2023-10): アフィリエイト リンク 含む 全 投稿 に PR 明示 (Amazon Associates · A8.net 承認 後 に activate)
  • 誇大 表現 禁止: 「絶対 · 必ず · 100% · 爆売れ · 保証 · 業界 最強 · 業界 No.1」等 の 禁句 は 全 layer (planner / producer / analyzer) で grep block
  • fake account · bot follower 禁止: 全 8 SNS accounts (準備 中 含む) は xiora 名義 の self-owned、透明 branding、クリックファーム と は 明確 分離
  • Mac heavy load ban: 並列 subagent max 2、Playwright 直列 1 process、docker build · cargo · VOICEVOX 音声 合成 等 の 重 process は VPS 側 に 移設

7. どう やって 24 時間 で これ だけ 進めた か
