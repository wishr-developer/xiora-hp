Pine Script v5 の 概要

TradingView 独自 の DSL、簡潔 な 文法 で indicator / strategy を記述。 v5 は 2021 発表、v4 と 非互換 で 大幅刷新。 主要 変更: `study` → `indicator`、`security` → `request.security`、変数 型 の 明示。

indicator の 骨格

//@version=5
indicator('Xiora RSI+BB', overlay=false)
length = input.int(14, 'RSI length')
source = input(close, 'Source')
rsi_val = ta.rsi(source, length)
plot(rsi_val, 'RSI', color=color.orange)
hline(70, 'Overbought', color=color.red)
hline(30, 'Oversold', color=color.green)

varip vs var

`var` = init 時 1 度のみ (bar 単位で保持)、`varip` = tick 毎に 保持 (リアルタイム 実行時 のみ差)。 backtest では 挙動 が異なる、リアル運用時のみの trailing stop 等 で varip 使用。

backtest 実装

//@version=5
strategy('Xiora BB Reversal', overlay=true)
[bbUpper, bbBasis, bbLower] = ta.bb(close, 20, 2)
longCondition = ta.crossover(close, bbLower)
if longCondition
    strategy.entry('Long', strategy.long)
shortCondition = ta.crossunder(close, bbUpper)
if shortCondition
    strategy.entry('Short', strategy.short)

backtest の 落とし穴

look-ahead bias (未来 データ 参照)、over-fitting (train 期間 に fit)、survivor bias (退場 銘柄除外)、slippage 無視、手数料 過小評価 の 5 大 落とし穴。 Xiora Algo は 全 backtest で スリッページ 2 pips / 手数料 0.1 % 込 を 標準 適用。

alert 設定

`alert(message, alert.freq_once_per_bar_close)` で bar 確定時 に 通知。 TradingView Alert → Webhook で Discord / Slack / メール / 独自 API に 転送。 Xiora Algo は Discord community に 自動投稿、 有料会員 の み 閲覧可。

マルチマーケット 対応

`request.security()` で 別 銘柄 の データ 取得可 (単一 chart から Forex + 米株 の 相関 分析 等)。 Xiora Algo indicator は デフォルト で 対応 マーケット list (Forex 28 通貨 / 仮想通貨 top 50 / 米株 S&P500) を 内蔵。
