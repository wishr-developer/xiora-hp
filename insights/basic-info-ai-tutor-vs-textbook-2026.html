2026-08-14

基本情報技術者 の 概要

IPA の 国家資格、 IT パスポート の 上位、 応用情報 の 下位。 受験料 ¥7,500、 CBT 通年実施。 合格率 25-35 %、 学習時間 目安 100-200 時間。 AI 導入 の 前 は 「テキスト 独学 + 過去問 500 題 演習」が 標準。

従来 テキスト の 課題

1 冊 ¥3,000-4,000 で 全分野 網羅 だが、 学習者 の 弱点 を 特定 する 機能 なし = 「わかっている 分野 も 復習 → 弱点 も 同じ 時間」= 非効率。 過去問 の 解説 も画一的 = 「なぜ 間違えたか」の 個別 洞察 なし。

Nexa v2 AI 個別 チューター

Nexa v2 の 基本情報 講座 は 全 12 章、 各 章末 に 演習 100 問。 AI チューター は 学習者 の 回答傾向 を 分析、 弱点 分野 を 特定 → 追加 演習 を 自動 生成、 解説 も 学習者 レベル に 合わせて 深浅 調整。

学習効率 比較 (仮想 estimate)

従来 テキスト 独学 = 100 時間 で 合格 60 % 到達 (仮定)。 Nexa v2 AI チューター = 60-80 時間 で 同 到達 (30-40 % 効率化)。 実 データ は 受講者数 蓄積 後 に 公開 予定 (現時点 は estimate、 「サンプル」badge 明記)。

2026 出題傾向

AI / DX 関連 出題 比率 が 増加 (2020: 5 % → 2026: 18 %、 IPA 統計)。 セキュリティ 分野 も 拡大 (SASE / Zero Trust / MITRE ATT&CK)。 Nexa v2 講座 は 2026 出題傾向 を 反映、 章 5-8 が AI / セキュリティ 特化。

学習 continuation の 仕組み

AI チューター が 3 日 学習 停滞 で リマインド (mail 通知)。 週次 進捗 レポート で 「今週 の 弱点 分野 top 3」を 提示。 モチベーション 維持 の 仕組み を 講座 自体 に 組込み。

合格 保証 なし の 明記

免責: 本 講座 は 合格 を 保証 する もの では ありません。 学習 内容 + 演習 は 情報提供 のみ、 実 試験 の 合否 は 各 学習者 の 学習量 と 適正 に 依存 します。 過去 の 合格 者 事例 は 「サンプル」badge 付き で 掲載。

Xiora Academy の 位置付け

Nexa Academy は 実務ワークフロー を 教材化 する 教育 SaaS、 基本情報 は 「資格 = 実務 の 入り口」として提供。 合格 後 の 上位 資格 (応用情報 / 高度) は 追加 講座 として 順次 開発 予定。
