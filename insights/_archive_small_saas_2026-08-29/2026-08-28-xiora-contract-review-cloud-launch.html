Xiora Contract Review Cloud 販売開始 — NDA / 業務委託 を 貼る だけ で AI が 3 tier 判定 (Free 月 3 件 / Pro ¥1,980)

公開: 2026-08-28 · Xiora Engineering

本記事 で 紹介 する Xiora Contract Review Cloud は 「business観点 での 気づき」 を 提供 する 情報提供サービス です。 弁護士法 上 の 個別 具体的 な 法的助言 は 行いません。

この記事で 分かる 3 つ

  • LegalOn 未満 の 予算 で 契約書 AI レビュー を 使い始める 方法
  • SMB 空白地帯 = 「弁護士 5 万円 の 前 に 自分 で 気づき を得る」 の 選択肢
  • Xiora Contract Review Cloud の 3 tier 判定 と 実 出力 例

なぜ 作ったか

契約書 レビュー の 選択肢 は 現在 大きく 2 極 化 して います。

  • LegalOn / リーガルフォース: 月額 ¥100,000+、 大企業 向け、 実装 も 導入 に 3-6 ヶ月
  • 弁護士 スポット: 1 契約 ¥30,000-¥100,000、 気軽 に 頼み にくい

間 の 「今 判断 が 必要」 な 個人事業主・SMB に 向けた 選択肢 が 空白 です。 特に、 週次 で 1-2 通 の 契約書 を 見る 業種 (フリーランス、 SaaS 事業者、 コンサル、 デザイナー、 エンジニア 業務委託) は、 弁護士 を 呼ぶ ほど でも ない 契約 が 大量 に 発生 します。

Xiora Contract Review Cloud で できる こと

  • 3 tier リスク 判定 — 総合 で 「即受入 / 交渉推奨 / 弁護士確認推奨」 の 1 語 判定
  • 条項 別 気づき — 問題 条項 を 引用 + business観点 での 論点 + 具体 交渉 提案
  • 欠落 条項 検出 — 一般的 に あるべき が 抜けている 条項 を 指摘
  • 履歴 保存 — 過去 の レビュー を いつでも 再閲覧
  • パスワード 不要 — メール に 届く リンク を クリック する だけ で サインイン

実 出力 例 (NDA · 短縮版)

入力:

第5条 (違反時) 違反 した場合 の 損害 は 制限 なし で 賠償 する。

出力:

severity: high
point: 賠償責任 が 無制限 で 設定 されており、 相手方 に とって 過度 に リスク が 高い。 実務上 は 合理的 な 上限 や 損害額 の 算定基準 が 必要。
suggestion: 賠償額 の 上限 設定 や、 実際 の 損害額 に 基づく 算定方法 を 明示 し、 過度 な 負担 を 回避 する

技術 構成

  • Frontend: バニラ HTML/JS (SPA)、 依存 ゼロ
  • Backend: Cloudflare Pages Functions (serverless)
  • AI: Cloudflare Workers AI (@cf/openai/gpt-oss-120b) — 122 neurons/リクエスト、 データ は Cloudflare の エッジ で 処理
  • Database: Cloudflare KV (3 namespace = users / data / sessions)

AI 分析 は 第三者 の LLM API (OpenAI / Anthropic / Google) には 送信 されず、 Cloudflare の エッジ ネットワーク で 完結 します。
