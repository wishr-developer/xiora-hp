Core Features

4 つの standard 機能

10-stage AI Legal Chain

preflight → 弁護士 → 行政書士 → 司法書士 → 税理士 → 弁理士 → 社労士 → 中小 企業 診断士 → final_scorer → verdict。 8 士業 role が Ollama qwen2.5:7b で 独立 review、fail-open で 1 stage 落ちても 全体 継続。

4 例外 = 自動 BLOCK

士業 独占 業務 (「代理」「代行」「登記」「訴訟」 regex) / 業許可 事業 (派遣 / 貸金 / 医療 機器 等) / 事件 対応 (「訴えられた」) / 契約書 legal 署名 の 4 種 は AI Chain 判定 で 自動 BLOCKED + escalate_to_lawyer=true。

PASS / CONCERNS / BLOCKED verdict

PASS (7-8/8 士業 ok + preflight ok) → 1 タップ 承認 で launch OK。 CONCERNS (4-6/8) → 修正 提案 生成、判断 は 事業者 側。 BLOCKED → 停止 + 弁護士 escalate 明示。

Xiora 内部 dogfood 済

Xiora 30+ product の launch 全て を 本 Chain で review 済 (月 平均 100+ review)。 弁護士 spot への 依存 を 除去、time-to-first-yen を 2-6 週間 短縮 する 内部 実 績 が 顧客 提供 の 前提。
