移行 フロー (5 step)

  1. ヒアリング (メール、 24-48h 以内 返信)

    現行 tool、 データ 量、 移行 希望 時期 を info@xiora-official.com へ お知らせ ください。 貴社 の 事業 規模 と compliance 要件 に 合わせ、 最適 な 移行 プラン を 24-48 時間 以内 に ご提案 いたします。

  2. データ export (現行 tool 側 の 標準 手順)

    Salesforce / HubSpot / Shopify 等 の 主要 tool は 標準 CSV / JSON export を 提供。 export 手順 の ガイド は 事業別 に 用意 (下 の 対応 tool 一覧 参照)。

  3. Xiora 側 import (自動 変換 + validation)

    Xiora の import wizard が field mapping を 自動 提案、 validation で エラー データ を 事前 検出。 大量 データ (100k+ rows) は API 経由 で バッチ import。

  4. 並行 稼働 + 差分 同期 (推奨 期間: 2-4 週)

    既存 tool と Xiora を 同時 稼働。 新規 データ は Xiora に 記録、 既存 tool は read-only 化。 差分 は 日次 で 自動 同期。

  5. 切替 + 30 日 rollback 期間

    顧客 承認 後 に 完全 切替。 30 日 以内 なら 完全 rollback 可能 (既存 tool へ の データ 逆同期 含む)。 切替 後 も サポート 継続。

データ 主権 / エクスポート 保証

Xiora は 「顧客 データ の 所有 権 は 顧客 に 帰属 する」 を 基本 方針 と して います。 契約 終了 時 or いつ でも、 全 データ を 標準 format (CSV / JSON / SCORM) で 一括 export 可能。 API 経由 でも 個別 取得 可。 lock-in を 目的 と した 独自 format 化 は 一切 行いません。
