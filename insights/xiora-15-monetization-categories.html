Category ① AI・IT 系 — Xiora の 主戦場

AI 導入支援 / チャットボット制作 / HP・LP 制作 / ノーコード / 業務自動化 / LINE 公式 / Notion 構築 / データ分析 / SEO コンサル。

Xiora は XCloud Connect / Restaurant OS / Gourmie / Shigyo Agents / Agent Factory / Content Engine の 6 product で この category を カバー。 SMB 向け AI 導入診断 spot (¥15,000/60min) から 開始する pattern を 実運用中です。

初期費用: 小 (Zapier / Notion Free tier)、利益率 高、月収 target range 月 30 万-500 万。

Category ② コンテンツ販売

電子書籍 / note / PDF 教材 / 動画教材 / AI プロンプト販売 / テンプレート販売 / Canva 素材 / Notion テンプレ。

Xiora は Skillshop kit 12 本 (title.md / body.md / pricing.md / tags.md フォーマット) と Nexa 教材コース で この category を カバー。 note 単発 ¥500-¥5,000 × 月 10-200 件 が 想定 revenue range。

利益率 極めて 高 (デジタル、原価ほぼゼロ)、time-to-first-yen 1-14 日 の 短い path です。

Category ③ SNS 運用

Instagram / TikTok / X 運用代行 / YouTube 運営 / ショート動画 / メルマガ。

Xiora は VideoOS (asyncio daemon + HealthServer :8090) + Content Engine + video-creator 代理人 で 内部 SNS 運用 pipeline を 走行中。 顧客向け SNS 運用代行 SaaS は T+6 ヶ月 target で 検討段階 (Xiora の 弱い category、gap 補完対象)。

Category ④ 動画編集

YouTube 長尺編集代行 / ショート編集代行 / Vlog / 講義動画 / 広告動画。

Xiora の VideoOS Phase 1+2 は 内部 pipeline のみ。 Phase 3 (Research / Trend / Idea 実 agent) で 顧客向け AI 支援型 動画編集 SaaS 化を T+6 ヶ月 target で 計画中。

Category ⑤ Web ライティング

記事執筆代行 / SEO 記事 / インタビュー / 校正代行 / セールスコピー。

Xiora の Content Engine + research handler (217 sources allowlist) + Xiora HP insights の 41 記事 実装 track record を 顧客案件に 転用可能。 単価 ¥1-¥10/字 × 月 10-100 本 が 想定 range。

Category ⑥ 営業代行

Cold email / SNS DM / テレアポ / インサイドセールス / リード獲得。

Xiora は XAIOutreach 経由で 越谷 / 草加 の 10 target research を 完了 (research-before-outreach 原則、テンプレ blast 禁止)。 Cold email SaaS 化は T+6 ヶ月 target で 検討中。

Category ⑦ 事務代行

データ入力 / 経理サポート / 秘書業務 / スケジュール調整 / メール返信代行。

Xiora は 秘書 AI (Agent Factory) と Shigyo Agents で 士業事務 の バックオフィス AI 化を 進行中。 AI 秘書 SaaS 化は T+3 ヶ月 target。

Category ⑧ デザイン

ロゴ / バナー / SNS 素材 / 名刺 / 資料 / UI/UX / イラスト / パッケージ。

Xiora は Brand Kit (白基調 ミニマル) + Canva SNS 8 tool で 内部 デザインパイプライン を 運用中。 顧客向け AI デザイナー SaaS (XioraDesign 仮称) は T+6 ヶ月 target で 検討段階。

Category ⑨ 受託開発 — 現金 flow の 中核

Web / モバイル / API 開発 / システム連携 / スクレイピング / RPA / DevOps。

Xiora は Aiverse / XAI Brain / OceanLLM (base) の agent オーケストレーション 基盤 を 受託カスタマイズ の base として 提供可能。 単発 ¥30-¥300 万/案件 × 月 1-5 件。

受託開発 → 自社プロダクト化 の pivot pattern は Xiora の Gourmie (越谷 / 草加 飲食向け レビュー返信代行 の 受託 pattern から 生まれた 自社プロダクト) が 代表例。

Category ⑩ 広告収益

YouTube / ブログ / アプリ / Web サービス / ニュースサイト。

Xiora HP insights 41 記事 の SEO 経路 は 楽天 / Amazon アソシエイト 導入を T+1 週で 実施予定 (first-yen 狙い)。 Xiora Official YouTube channel は T+3 ヶ月で 開設予定。

Category ⑪ サブスク型 — 最も 事業価値 高い

AI ツール / 会員サイト / コミュニティ / オンラインサロン / SaaS / 保守契約。

Xiora の 最大 unlock 済 category。 Stripe products live 14 本、Kigen / Aiverse / Nexa / Gourmie / XCloud Connect / Restaurant OS / Content Engine / Shigyo Agents / Agent Factory / XioraSalon / Ocean Pro (¥1,980/月) で 14 product 実運用中。

利益率 極めて 高、MRR 資産化、企業価値評価に 直結。 Xiora の 主戦場です。

Category ⑫ マッチングサービス

求人 / 家事代行 / フリーランス / 家庭教師 / ペット / 不動産。

Xiora は XioraHire (求人マッチング) と Xiora Career (Nexa 内 の 6 SKU) で 2 product カバー。 家事代行 / ペット / 不動産 は Xiora の ドメイン外、T+12 ヶ月以降 検討 (優先度 低)。

Category ⑬ 教育

オンラインスクール / 家庭教師 / コーチング / コンサル / 法人研修。

Xiora の Academy Nexa (11 商業コース + 3 dogfood コース) + Xiora Career 6 SKU + Xiora Skillshop kit 12 本 で 6 product カバー。 T+1-3 ヶ月 で 月 30-100 万 target。

Category ⑭ AI エージェント — Xiora の core 領域

営業 AI / 秘書 AI / 採用 AI / CS AI / AI ライター / AI 動画 / AI デザイナー。

Xiora の 12 product で カバー: Agent Factory / Shigyo Agents / XAIOutreach / XioraHire / Gourmie / Content Engine / video-creator / OceanChat / OceanLLM / VideoOS。 20 代理人 の orchestration 知見 が 差別化 point。

今後 有望な category、Xiora の 最大 unlock 済 領域の 1 つ です。

Category ⑮ 自社サービス — 最終目標

自社 SaaS / 自社 プラットフォーム / 自社 メディア / 自社 ハードウェア。

Xiora は 全 20+ 自社 product を 保有し、Aiverse Marketplace / Nexa Marketplace / Content Engine Marketplace を T+9 ヶ月で launch 計画中。 年 1 億 到達 (T+12 ヶ月 target) の 中核 category。

「受託 → 自社 → サブスク」flow の Xiora 実装 pattern

Phase 1 受託 (T+0-3 ヶ月、月 5-30 万): AI 導入コンサル spot + XioraHire 受託 + Coconala 出品 で 現金 flow 確保。

Phase 2 自社プロダクト (T+3-6 ヶ月、月 30-300 万): Kigen / Aiverse / Nexa / Gourmie の 単発売り切り + 教材コース販売 で 資産化。

Phase 3 サブスク (T+6-12 ヶ月+、月 100-1000 万+): Ocean Pro ¥1,980/月 × 500 + Restaurant OS 30 社 + Aiverse Marketplace take rate で MRR 安定。

Xiora は 3 phase を 並行 運用中 (Phase 1 走行、Phase 2 一部走行、Phase 3 Stripe products live 14 本で 実 subscribe 待ち)。

15 category の 選び方 (Xiora の 判断軸)

Xiora の north star = time-to-first-yen 昇順。 今週 ¥1 が 欲しいなら ② コンテンツ販売 (note 単発) / ⑦ 事務代行 (Coconala) から。

月 30-100 万 を 3 ヶ月 で 作りたいなら ① AI・IT (コンサル spot) + ⑬ 教育 (Nexa 11 コース) の 複合。

月 500 万+ を 目指すなら ⑪ サブスク + ⑭ AI エージェント + ⑮ 自社サービス の 3 本柱、Xiora が 実際に 進行中の path です。
