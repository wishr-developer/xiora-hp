Xiora Lingua の 概要 (fact 整理)

Xiora Lingua は Xiora が 運用 する 語学 SaaS — 英語 12 週 syllabus (β waitlist)。

英語学習 を 5 axis で 整理

軸 1 (目的): 対象 業務 / user segment / 期待 KPI を 事前 に 明文化。

軸 2 (投入 資源): 初期 導入 の 工数 / 継続 運用 の 工数 / 教育 コスト を 3 段 で 見積り。

軸 3 (統合 先): 既存 SaaS / 社内 DB / 認証 (SSO/SAML) との 接続 経路 を map 化。

軸 4 (計測): 導入 前後 の baseline / 週次 KPI / 3 ヶ月 レビュー の 3 段 計測。

軸 5 (撤退 条件): 3 ヶ月 で KPI 未達 の 場合 の 縮小 / 撤退 判断 基準 を 事前 に 合意。

Xiora の 実運用 で 見えた 論点

論点 1: 「全部 自動化」 では なく 「一次 draft を AI、 承認 は 人」 の 2 段 構成 が 現場 で 受け入れられ やすい。

論点 2: 初月 は KPI が 揃わない ため、 log / event の 貯まり を 週次 で レビュー し 3 ヶ月 で 継続 判断。

論点 3: セキュリティ / プライバシー (個人 情報 保護法 / 業界 ガイドライン) は 導入 前 に チェックリスト 化 して 経営 承認 を 取得。

次 の action として 検討 出来る 3 stage

Stage 1 (0-2 週): 対象 業務 の 現状 KPI を 記録、 pilot 対象 の 1 チーム を 選定。

Stage 2 (3-8 週): pilot 導入、 週次 レビュー、 撤退 条件 の 妥当性 を 検証。

Stage 3 (9-12 週): 全社 / 全店舗 展開 の 可否 判断、 撤退 / 継続 / 拡張 の 3 択 決定。
