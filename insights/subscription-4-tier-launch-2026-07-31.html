解約 · 課金 タイミング (4 tier 共通)

  • 初回 課金: サブスク 決済 完了 と 同時 に 契約 期間 分 を 一括 決済 (例: Annual ¥19,800 は 1 度 で 決済)
  • 次回 課金: 契約 起算 日 に 自動 更新 (Monthly = 1 ヶ月 · Quarterly = 3 ヶ月 · Half-Year = 6 ヶ月 · Annual = 1 年 サイクル)
  • 解約: いつ でも 1 tap 解約 · 契約 期間 満了 まで 引き続き 利用 可 · 日割り 返金 なし
  • 領収 書: 決済 完了 メール + Stripe billing portal (Nexa/XCloud/Algo) or Apple ID (Kigen) で 自動 発行

なぜ 4 tier か

顧客 の 「試したい 期間 の 幅」に 対応 する ため。 単一 の Monthly のみ だと 継続 利用 顧客 も 毎月 更新 の 手間 と 単価 で 負担 が 増える。 Annual は 「継続 利用 を 決めた 顧客 向け の 割引」で、 xiora も 継続 収益 の 予測 可能 性 が 上がる。 3M/6M は Monthly と Annual の 中間 の 「まずは 短 中期 で コミット」ニーズ に 対応。

年間 契約 の 割引 は 17% (2 ヶ月 分 free equivalent) と SaaS 標準 水準 に 設定。 過度 な 割引 は 顧客 の 「解約 判断 の 心理 コスト」を 上げる ため、 「少し 安く」の レンジ に 抑え て います。

実装 状況

Monthly は 全 product LIVE (Xiora Algo を 除く)。 Quarterly/Half-Year/Annual は Stripe/Apple IAP 側 で 各 tier の price 発行 が 完了 次第 順次 リリース (2026 年 8 月 上旬 予定)。 各 LP の pricing tier に 「● LIVE / ◐ 準備 中」の badge を 表示 して います。

本 記事 の 価格 · リリース 時期 は 2026-07-31 時点 の もの、 変更 され る 場合 が あります。 特商法 に 基づく 表記 (/legal/tokusho.html) で 全 tier の 販売 価格 · 支払 時期 · 解約 手続 の 詳細 を 掲載。
