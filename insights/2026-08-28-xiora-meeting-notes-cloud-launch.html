なぜ 作ったか

会議 の 議事録 作成 は、 会議 1 時間 に 対して 30-45 分 の 追加 作業 が 発生 します。 Otter.ai や Fireflies が この 領域 を 大きく 効率化 した 一方 で、 以下 の 課題 が 残って います。

  • 音声 データ を 第三者 サーバー に 送る — 守秘義務 の 高い 会議 (法律 相談、 顧客 提案、 採用 面接) で 使い にくい
  • アクション項目 の 抽出 が 弱い — 「誰が いつ まで に 何を するか」 を 精度 良く 出せない
  • 月額 が 高い — Otter Pro は $16.99/月、 Fireflies Pro は $18/月

Xiora Meeting Notes Cloud は、 「既に 手元 に ある 書き起こし」 を 対象 に 議事録 化 を する 設計。 音声 は 送らず、 テキスト だけ を Cloudflare エッジ で 処理 します。

できる こと

  • 議事要約 — 3-6 文 で 会議 の 大枠 を 記録
  • 参加者 抽出 — 話者 リスト を 書き起こし から 推定
  • 決定事項 — 「〜と決定」 部分 を 背景 付き で 列挙
  • アクション項目 — 担当者 + 期日 + 優先度 を 推定
  • 未解決 論点 — 次回 持ち越し の 項目 を 明示
  • リスク フラグ — 法務 / 契約 / 予算 の 注意点 を 検出
  • Markdown コピー — Notion / Slack に そのまま 貼り付け

実 出力 例

以下 の ような 書き起こし を 入力 すると:

Speaker A: 予算は 100万円、 納期は 10月末 で 想定 しています。 Speaker A: 田中さん、 要件定義書 の 準備 を 8月末 まで に お願い できますか？ 田中: はい、 8月30日 まで に 初版 を 提出 します。 Speaker B: 契約書 の 締結 が 遅れる リスク が あります。

AI が 以下 の アクション項目 を 抽出 します:

- [ ] 要件定義書 の 初版 を 作成・提出 する (owner: 田中, deadline: 2026-08-30, priority: high) - [ ] 法務 と 事前 相談 し、 契約書 締結 リスク を 軽減 する (owner: Speaker B, priority: high)

担当者 (「田中さん」→「田中」)、 期日 (「8月30日」→「2026-08-30」)、 優先度 まで 自動 で 埋まります。

技術 構成

  • AI: Cloudflare Workers AI (@cf/openai/gpt-oss-120b) — 日本語 精度 高、 音声 送信 なし
  • Backend: Cloudflare Pages Functions + KV (3 namespace)
  • Frontend: バニラ HTML/JS、 依存 ゼロ
  • Auth: magic-link (パスワード 不要)
