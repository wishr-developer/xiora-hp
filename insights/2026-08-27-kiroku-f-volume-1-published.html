Writer Studios の 位置づけ

Writer Studios は、Xiora の 出版・IP 展開 事業 (Xiora の 中で 位置づけ が 明確 な 出版 Division) です。 SaaS / AI Agent 事業 とは 独立 した 収益 pillar として、書籍 IP を Kindle (KDP) を 中心 に 継続 供給 し、将来的 に 音声 / 映像 / 二次 展開 まで 束ねる 構想 で 立ち上げ ました。 今回 の Vol 1 リリース は、Writer Studios が 「構想」 から 「販売中 の 実 IP を 持つ 事業」 へ 移行 し た 節目 です。

Vol 1 の 内容

第 1 作 は 『クビになった俺の《記録:F》』。 冒険者ギルド から 「F ランク」 として 追放 さ れ た 主人公 が、〈記録〉 という 目立た ない 固有 スキル で 世界 を 読み替え て いく、育成 × 記録 スキル 型 の 異世界 ファンタジー です。 派手 な 戦闘 だけ で は なく、「日々 の 観測 と 記録 の 積み上げ が 力 に なる」 という テーマ を、章 単位 で 完結 感 を 持たせ ながら 構成 し まし た。 ライト ノベル 読者 と、育成 系 / 追放 系 テンプレ に 少し 飽き た 層 の 両方 を 想定 読者 に 置い て います。

Amazon で の 探し方

Amazon Kindle Store で 検索 キーワード 「クビになった俺の 記録F」 で ヒット し ます。 KDP の 反映 タイミング の 関係 で、公開 直後 は 検索 に 出る まで 最大 72 時間 程度 かかる 場合 が あり ます。 その 場合 は 少し 時間 を 置い て 再度 検索 し て み て ください。 商品 ページ が 反映 さ れ 次第、Xiora HP 側 の 直接 リンク も 差し替え 予定 です。

Vol 2 と 今後 の 予告

Vol 2 は 現在 執筆 中 で、Vol 1 の エピローグ から 直結 する 章 構成 に なる 予定 です。 Writer Studios の 継続 目標 は 「四半期 に 1 巻 以上 の 新刊 リリース」。 Vol 1 の 販売 動向 を 見 な がら、シリーズ の 巻数 展開、外伝、関連 IP の 展開 順 を 判断 し て いき ます。 新刊 情報 は Insights と 公式 の Xiora チャネル で 順次 告知 し ます。

Xiora の 事業 map の 中 で の 意味

Writer Studios は、Xiora の 20+ プロダクト の うち 「非 SaaS」 の 収益 pillar として 位置づけ て い ます。 SaaS は 月次 課金、書籍 IP は 単発 購入 と 長期 の テール、AI エージェント 事業 は 労働 代替 と、それぞれ 異なる 収益 プロファイル を 組み合わせ て、単一 事業 依存 を 避ける 設計 です。 今回 の 出版 開始 は、その 三本柱 の うち 「書籍 IP」 が 実 販売 段階 に 入っ た こと を 意味 し ます。
