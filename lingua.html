What Xiora Lingua is

43 lesson を Free で 全 開放。 5 分/日 で 続く 設計。

語学 学習 アプリ で 「Free 版 で ライフ 切れ · 途中 停止」の 経験 は 多く。 Xiora Lingua v1.0 は Free で 43 lesson × 3 course (日常 会話 18 · 旅行 英語 15 · 表現 力 10) を 全 開放。 音声 発音 · 弱点 復習 · streak を 内蔵、 iPhone SE から Pro Max まで 対応 の PWA で ホーム 画面 に インストール 可能 です。

Core Features

3 つ の 特徴 (v1.0 実装 済)

音声 発音 (Web Speech API)

Web ブラウザ 内蔵 の Web Speech API で 音声 認識 と 発音 練習。 端末 で 完結、 サーバ に 音声 データ を 送信 しません。 iPhone Safari · Chrome · Edge · Firefox に 対応。

弱点 復習 + streak · XP

間違え た lesson を 自動 で 復習 queue に。 連続 学習 日数 (streak) · 累計 XP · hearts (5 refill 24h) の gamification で 継続 を 支援。 dashboard で 過去 30 日 の 進捗 可視化。

PWA + 英語 UI 切替

iPhone / Android の ホーム 画面 に PWA として インストール 可能。 offline で 直近 3 lesson の 復習 が 動きます。 UI は 日本語 と 英語 の 切替 (145 key 対応)。

よくある質問

Xiora Lingua FAQ (8 項目)

Q1. Free (無料) で 何 が できますか?
日常 会話 (18 lesson) · 旅行 英語 (15 lesson) · 表現力 (10 lesson) の 3 course 合計 43 lesson を 全 開放 して います。 1 lesson = 5 問、 4 択 で 単語 · フレーズ · 穴埋め · 発音 練習。 XP · streak · hearts (5 個 · 5 時間 で +1 回復) · 弱点 復習 · PWA install · 音声 (Web Speech API) も Free で 利用 可能 です。
Q2. Super (¥980/月 税込) と Family (¥1,980/月 税込) の 違い は?
Super は hearts 無制限 (不正解 で 学習 停止 に ならない) · 上級 lesson 開放 · AI tutor 個別 質問 · offline 学習 · mistake review 自動 生成 の 5 機能 を 追加 します。 Family は Super の 全 機能 を 家族 6 名 まで 共有 でき、 各 メンバー は 招待 code で 追加 · 個別 進捗 管理 されます (¥1,980/月 で 実質 1 名 あたり ¥330)。
Q3. 支払 方法 · キャンセル 方法 は?
Stripe 決済 (VISA / Mastercard / JCB / American Express / Diners) に 対応 して います。 サブスク は 月 契約 で、 いつでも Stripe 顧客 ポータル から self-serve で キャンセル できます (返金 は 原則 行い ません が、 当社 の 過失 で サービス が 提供 できな かった 期間 は 個別 対応)。 詳細 は 特商法 表記 を ご 参照 ください。
Q4. 音声 認識 (発音 練習) が 動きま せん
音声 機能 は ブラウザ 内蔵 の Web Speech API を 使用 して います。 Chrome / Edge / Safari (最新版) で 動作 確認 済 で、 Firefox は 対応 が 限定的 です。 初回 使用 時 に マイク 権限 を 許可 して ください。 モバイル で は iOS Safari 17 以降 · Chrome for Android の 最新版 を 推奨 します。 認識 精度 は 環境 音 · ネットワーク 状況 に より 個人 差 が あります。
Q5. インストール は 必要 ですか? (Native App は あります か?)
現時点 で は Web app 版 (PWA 対応) のみ 提供 して います。 Chrome / Safari で 「ホーム 画面 に 追加」 する と アプリ 同等 の 体験 で 利用 可能 で、 offline でも 直近 3 lesson の 復習 が できます。 iOS / Android の Native App は 現在 実装 検討 中 (提供 時期 未 定) です。
Q6. Family plan の 招待 code は どう 発行 しますか?
Family plan 契約 後、 web-app の アカウント 画面 から 「招待 code 発行」 で 追加 メンバー 用 の 6 桁 code を 生成 できます。 各 メンバー は 自身 の メール アドレス で account 作成 し、 招待 code を 入力 する と 家族 グループ に 参加 します。 進捗 · XP · streak は 個別 に 管理 され、 支払い は 契約者 (親 account) に 一括 で 請求 されます。
Q7. 学習 効果 は 保証 されますか?
学習 効果 は 学習 頻度 · 継続 期間 · 個人 の 目標 レベル に 応じて 個人 差 が あり、 特定 の 効果 · 資格 合格 · TOEIC スコア 向上 等 を 保証 する もの では ありません。 3 course 43 lesson は CEFR A1-A2 相当 の 語彙 · フレーズ · 文法 を 段階 的 に 学習 する 設計 で、 1 日 5 分 × 継続 4-8 週 で 完走 する 想定 です。
Q8. 問い合わせ · 障害 報告 の 窓口 は?
機能 不具合 · 支払い 関連 · プラン 変更 等 は info@xiora-official.com 宛 に メール で ご 連絡 ください。 一次 回答 は 原則 48 時間 以内 (営業 日 基準) を 目安 と して います。 個別 契約 · Enterprise 相談 は 同 窓口 に 「Enterprise 相談」 と 明記 の 上、 会社 名 · 想定 利用 者 数 を お知らせ ください。
