なぜ 越谷 / 草加 の SMB か

越谷 / 草加 / 川口 / 春日部 の 4 市 は 東京 隣接 の 中小企業 集積地。 商工会議所 会員数 は 越谷 で 約 2,900 社、草加 で 約 1,800 社。 SaaS 導入率 は都心 と比較して低く、営業 の DX が進んでいない層が 多数残る 未開拓 市場です。

越谷 商工会議所 の 業種別分布

製造業 30 % / 建設業 20 % / 卸小売 15 % / サービス 業 25 % / IT・情報 5 % / その他 5 %。 IT 業界 の 割合が低い = Sales AI OS の 導入余地 が 大きい。 特に 製造業 と 建設業 の 営業チーム は アナログ 依存 が 強く 自動化 効果 が 大きい層。

導入 3 ステップ

Step 1: Sales AI OS の 14 日 free trial に sign up (self-serve、5 分)。 Step 2: 商工会議所 会員名簿 (会員向け DL 可) を CSV 形式で Lead agent にアップロード。 Step 3: Content agent が 各社の 公式 サイト を Research し 個別 pitch を生成 → 承認 → 送信。

cold email 送信頻度

特電法 遵守 のため 同一 domain へ 24 時間 内 1 通 制限、48-72h で 1 回 follow up、返信 なし 3 通 で 送信 停止。 100 社 / 週 のペースで 送信 = 4 週間で 400 社 到達 (越谷 商工会議所 会員 の 14 %)。

想定 ROI

SMB (SaOS SMB プラン ¥30,000/月) の 場合、 想定 反応率 3-5 % で 100 通 → 3-5 商談。 契約 転換率 20 % = 0.6-1 契約 / 週。 平均 契約単価 ¥300,000 = ¥18,000-¥300,000/月 の 追加売上。 SaOS 単価 の 6-100 倍 回収。

競合 との 比較

SmartHR (人事) / freee (会計) は既に SMB 浸透、 営業自動化 は 未開拓 category。 Salesforce / HubSpot は 単価 高 (SMB は 手が届かない)、 Sales AI OS は 単価 で 差別化 (¥3,000/月 - ¥100,000/月)。

導入前 の 準備

Step 0 = 送信元 email の DNS 整備 (SPF + DKIM + DMARC の 3 レコード追加)。 xiora-official.com は 既に 完了 済 (MailChannels 追記 + DMARC quarantine mode)。 自社 ドメイン で 送信 する 場合 は 同様 の 設定 が 必須。

KPI 設定 と 監視

OpsHub (社内 dashboard) で 日次 / 週次 / 月次 の 送信数 / 開封 率 / 返信率 / 商談 化率 / 契約 転換率 を 監視。 停滞 が 続けば Content agent の A/B test を 増やす、 Scoring 閾値 を 上げる、 Lead source を 追加 の 3 打ち手。
