6 SKU 概要

SKU 1: 就活対策 (新卒) — 大学 3-4 年生 対象。 業界研究 + ES 添削 + GD 対策 + 面接練習 の 4 モジュール。 月額 Silver ¥1,650 / Gold ¥5,500。

SKU 2: 転職対策 (第二新卒〜) — 20-30 代 転職検討層 対象。 職務経歴書 添削 + 職種別 スキル整理 + 面接練習。 月額 Silver ¥1,650 / Gold ¥5,500。

SKU 3: 資格取得 サポート — 応用情報 / 基本情報 / 簿記 / TOEIC 等 の 学習計画 + 教材選定。 月額 ¥1,650 (2026-07-31 買切 廃止 · サブスク 一本)。

SKU 4: 投資 リテラシー 教材 — 投資助言では 無く、投資の 基本 概念 (リスク / リターン / 分散 / 手数料 / 税制) を 教育目的で 情報整理。 月額 ¥1,650 (2026-07-31 買切 廃止 · サブスク 一本)。

SKU 5: 面接 AI トレーナー — 面接 質問 に対する 自身の 回答 を AI が トレーニング パートナーとして 相手役。 月額 ¥3,300 (無制限練習)。

SKU 6: 自己分析 レポート — Big 5 personality + 職業適性 診断 + 30 ページ カスタム レポート。 月額 ¥1,980 (2026-07-31 買切 廃止 · サブスク 一本)。

SKU 別 の 対象層 と 学習投下時間

SKU 1 (就活): 週 5-10 時間 × 3-6 ヶ月 = 60-240 時間 (新卒就活 期 全体)。

SKU 2 (転職): 週 3-8 時間 × 2-4 ヶ月 = 24-128 時間。

SKU 3 (資格): 資格難易度 に依存、応用情報 で 200-400 時間、簿記 2 級 で 200-300 時間、TOEIC 700+ で 300-500 時間。

SKU 4 (投資リテラシー): 週 1-2 時間 × 3 ヶ月 = 12-24 時間。 実 投資判断は 別途 助言業者 に相談。

SKU 5 (面接AI): 面接前 3-4 週間 × 週 3-5 回 練習 = 12-20 セッション。

SKU 6 (自己分析): サブスク 契約 で 診断 実施、初回 診断 45 分 + レポート 読解 60 分。

埼玉県内 3 大学 提携 想定

Xiora Career の 認知拡大策 として、埼玉県内 3 大学 との 提携 を 準備中です。 対象大学 は 越谷 / 大宮 / さいたま 周辺 の 中規模 私立大学 を 想定。

提携内容 想定: (a) キャリアセンター 経由の 学生向け SKU 1 (就活対策) の 割引提供 (b) キャリア講義 の ゲストスピーカー (c) インターンシップ 受入枠 (Xiora Career の コンテンツ 制作 補助)。

現時点 では 提携 想定段階 であり、正式 契約 締結 の 上 別途 発表いたします。

市場 と 競合 の 情報整理

個人向け キャリア 支援 市場 は 大手 (リクルート / パーソル / dodaX / ビズリーチ 等) が 大部分 を 占め、単価 は 転職成功時 の 数十万-100 万円 の 成功報酬 モデル が 主流。

Xiora Career は 「月額 数千円 の サブスクリプション モデル」+「複数 SKU 選択」 で、成功報酬 モデル と 差別化。 特に 就活生 (新卒) は 収入 が 限定的で、成功報酬 モデル が 参入しづらい ため、サブスクリプション モデル の 相性 が 良い 想定。
