Xiora Apps

Web・AI・モバイル。
アプリを、自分たちでつくる。

Xiora Apps は、Web アプリ・AI アプリ・モバイルアプリ・LINE アプリ・AI エージェントを、
自分たちで企画・開発・運営する アプリ事業 領域です。
業務システム・SaaS は System & App Development と Products（Kigen / XCloud） でご覧いただけます。

アプリの相談をする アプリ領域を見る

Categories

6 つの、アプリ領域。

ユーザー体験の単位ごとに、AI 時代の小さく強いアプリを届けます。
業務基盤側の "システム" は、別軸（Products / System & App Development）で扱います。

01 Web App

Web アプリ

ログイン、申込、決済、マイページ、検索体験まで。Web 上で完結するユーザー向けアプリを、Next.js / TypeScript で構築します。

  • 会員 / 申込フロー
  • マイページ
  • 決済 (Stripe)
  • 検索 / レコメンド
02 AI App

AI アプリ

AI チャット、要約、ドキュメント生成、画像生成、診断系。AI を主役にした単機能で強いアプリを設計・実装します。

  • AI チャット
  • 要約 / 生成
  • 画像生成 / 編集
  • AI 診断 / 推薦
03 Mobile App

モバイルアプリ

スマホで使うことを前提に設計されたアプリ。PWA / レスポンシブ Web / React Native で、ユーザーの手元に届きます。

  • PWA
  • Responsive Web
  • React Native
  • Push 通知
04 LINE App

LINE アプリ / Bot

LINE 公式アカウントを UI とする、軽量で導入しやすいアプリ。予約、問診、店舗オペレーション、ファンコミュニケーションまで。

  • LIFF
  • Messaging API
  • リッチメニュー
  • AI 応答
05 AI Agent

AI エージェント

指示を受けて自律的にタスクを実行する AI エージェント。リサーチ、メール作成、データ整理、レポート生成まで。

  • Function Calling
  • Tool Use
  • 長時間タスク実行
  • Slack / Email 連携
06 Mini Product

ミニアプリ / プロトタイプ

2〜4 週間で公開するスモールアプリ。仮説検証、社内 PoC、キャンペーン用 LP 風アプリなど、軽量に動かしたい場面に。

  • 2〜4 週間で公開
  • 仮説検証
  • キャンペーン
  • 社内 PoC

Web アプリ / AI アプリ / モバイルアプリ / LINE アプリ / AI エージェント ── 体験の単位は問いません。
業務基盤になる "システム"（CRM / 在庫 / シフト / SaaS / 管理画面）は、System & App Development または Products 側でご相談ください。
