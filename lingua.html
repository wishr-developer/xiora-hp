What Xiora Lingua is

「続くが 話せない」 空白 に、記憶科学 と 発音評価 と AI 会話 を 束ねる。

語学学習 アプリ 市場 は 世界 で 年間 約 2 兆円 規模、年率 15% 成長帯 と 見られています。 モバイル 学習 の 主戦場 は Duolingo が 支配 する 一方、「ゲーム で 続くが、話せる ように ならない」 という 構造的 な 不満 が 最大 の 空白 に なっています。 Xiora Lingua は、記憶科学 (FSRS/IRT) と 音素 レベル の 発音評価、無制限 の AI 会話 を 一つ の SaaS に 統合し、完全無人 運営 の 低コスト 構造 で 高粗利 を 目指す プロダクト です。 無人運営 は 単なる コスト削減 では なく、事業 model の 核 に 位置付け て います。

Core Features

3 つ の 特徴

FSRS / IRT の 記憶科学

ts-fsrs 互換 の FSRS-4.5 実装 と IRT 2PL に 基づく 適応型 診断 (CAT) を 採用。 想起 成功率 87-93% 帯 を 週次 較正 で 維持 する 設計 に よって、「開いた 回数」 では なく 「記憶 に 定着 した 量」 を 最上位 KPI に 置きます。

音素 発音評価

Azure Speech の Pronunciation Assessment を 統合。 音素別 スコア + 強勢 + 流暢性 を 構造化 保存 し、Phase 2 で は 中国語 の 声調 評価 に も 対応 予定。 UI で は 発音 の 弱点 が 音素 単位 で 可視化 されます。

完全無人 運営

QA Gate / SRE / Cost Governor / Support / Moderation / Growth / Curator の 7 種 の Ops AI が、教材 品質 検証・障害 対応・コスト 抑制・問い合わせ 一次 対応 を 分担。 全 判断 は 決定論的 な policy_engine を 通過 し、上限超え は human_queue に 積まれます。
