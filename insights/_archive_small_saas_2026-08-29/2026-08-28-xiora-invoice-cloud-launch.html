なぜ 作ったか

個人事業主 と スモールビジネス の 請求書 発行 は、Word / Excel + 印刷 + 郵送 or PDF 添付 メール で 20-30 分 かかる 作業 が 月 3-10 回 発生 します。

MoneyForward クラウド請求書 や Misoca は 高機能 ですが 会計 統合 まで 含む ため 月額 ¥800-¥3,000 + 学習 コスト が 高い。 「請求書 だけ 出せれば 良い」 層 に 対して、 パスワード 不要 で 即 使い始められる SaaS が 空白 でした。

Xiora Invoice Cloud で できる こと

  • パスワード 不要 ログイン — メール に 届く リンク を クリック する だけ で サインイン
  • 取引先 管理 — 会社名・住所・敬称 を 保存 して 再 利用
  • 請求書 CRUD — 明細・消費税 (10% / 8% / 免税)・振込先 を 保存、 いつでも 編集
  • PDF / 印刷 対応 — ワンクリック で ブラウザ ネイティブ 印刷 or PDF 保存
  • メール 送付 — 取引先 メール に そのまま 送信、 送信 履歴 も 保存
  • インボイス 対応 — 登録番号 (T1234...) を プロフィール に 保存、 請求書 に 自動 表示
  • 自動 採番 — INV-2026-0001 の 形式 で 年 単位 に 連番

技術 構成

  • Frontend: バニラ HTML/JS (SPA)、 依存 ゼロ
  • Backend: Cloudflare Pages Functions (serverless)
  • Database: Cloudflare KV (3 namespace = users / data / sessions)
  • Email: 現在 開発 モード、 順次 Resend / MailChannels 統合
  • PDF: サーバー サイド HTML 生成 → ブラウザ ネイティブ 印刷 で PDF 化

セキュリティ

Xiora の DLP (Data Loss Prevention) 統制 下 に あり、 request/response の 20 パターン 秘密 情報 を 自動 検出・遮断 します。 セッション は 30 日 で 失効、 HttpOnly + Secure + SameSite=Lax の Cookie で 管理。

無料で 今すぐ 使う

メールアドレス を 入力 する だけ で 開始 できます。 会員 登録 も、 クレジットカード 登録 も、 パスワード 設定 も 不要。
