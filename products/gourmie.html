Gourmie.

What Gourmie is

"店選び"を、
会話 3 秒で完結。

食べログ + Google Maps + 幹事の LINE 相談 の 3 stack を、1 つの会話で終わらせます。 店舗側には掲載 + 予約 + 分析 を提供し、幹事側と店舗側の双方に価値を届けます。

Core Features

4 つの standard 機能

3 秒で理由付き 3 店舗提案

会話から予算・雰囲気・好みを抽出、8 層 AI 品質パイプラインで根拠付きの 3 案。

二層学習プロファイル

恒常プロファイル (アレルギー・NG) + シーン別 (接待・仲間内・デート) で使うほど精度向上。

PR 表示の監査ログ

広告掲載店舗には PR 表示を付与し、全表示履歴を追記専用テーブルで追跡。景表法対応の設計。

店舗ダッシュボード

掲載管理・予約通知・会話分析。人手不足の店舗運営を数字と自動化で解決。

今すぐ始める

個人の方は無料で会話開始、店舗の方は掲載プランで予約流入を獲得。相談希望は info@xiora-official.com へ。
