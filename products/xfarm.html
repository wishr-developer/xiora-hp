What X farm is

Android の 群れ を、
「1 画面 で 全部 見える」に。

複数 の Android 端末 を 業務 で 使う 現場 で は、 「今 どこ で · 何 が · どう 動いて いる か」を 把握 する だけ で 半日 が 消える こと が あります。 X farm は enrollment → command → metrics の flow を 1 画面 で 統合 し、 IT 管理者 · 現場 責任者 · 開発 chief が Android の 群れ を 「1 画面 で 全部 見える」状態 に 保ちます。

Core Features

7 領域 の 端末 管理 機能

QR enrollment

Web 管理画面 で 発行 した 使い捨て QR を 端末 で スキャン → 30 秒 で 登録 完了。 IT 管理者 が 一括 で 発行 可能。

Remote command 14 種

PING / SYNC_DEVICE_INFO / SYNC_APP_INVENTORY / REFRESH_CONFIG / COLLECT_LOGS / CAPTURE_SCREENSHOT / RESTART_APP / CLEAR_CACHE / SET_KIOSK_MODE 等 14 種 の コマンド を 遠隔 から 実行。

Realtime metrics

Heartbeat (20 秒 間隔) · battery temperature / level · network type (WiFi/LTE/5G) · connection state · CPU (取得 可能 な もの) · memory (PSS) · storage の 実測 値 を 収集。

Screenshot capture

MediaProjection consent 経由 で 端末 の 画面 を キャプチャ。 現場 問題 解決 の 「今 何 が 見えて いる か」を 遠隔 で 確認。

Logs sink

logcat + アプリ ログ を 定期 収集、 サーバ側 で 保存 + 検索 可。 PII redaction 内蔵。

Multi-tenant · RBAC

組織 · チーム 単位 で 権限 分離。 super_admin / admin / operator / viewer の 4 role · audit log 内蔵。

self-hosted 対応

Docker Compose で 30 分 導入。 自社 サーバ · Xiora VPS · AWS/GCP どこ で も 動く。 データ は 顧客 側 に 全 保有。

Architecture

3 layer 構成 · self-hosted 対応

Agent (Android 端末 側): Kotlin + Compose の ネイティブ アプリ。 Foreground Service で 常駐、 Socket.IO で サーバ と 常時 接続、 command handler 14 種 内蔵、 metrics collector 実装。 Play Store 配布 or APK 直配布 対応。

API (サーバ 側): NestJS + Prisma + Socket.IO + BullMQ で command dispatch。 PostgreSQL に device / command / metrics / event / audit log 全 保存。 nginx 前段 で WebSocket upgrade + rate limit。

Web (管理画面): Next.js 15 + React + Tailwind。 Live device list · command dispatch UI · metrics chart · 11 タブ device 詳細 · Bulk action · Admin RBAC。 English UI 切替 対応。

Deploy 選択肢: (1) SaaS (Xiora ホスト、 サーバ 管理 不要、 SLA 付き) or (2) self-hosted (Docker Compose · 顧客 環境、 データ は 完全 顧客 側)。 SaaS 版 は Starter / Growth プラン、 self-hosted 版 は 同じ プラン 価格 + 独自 サーバ 費用。
