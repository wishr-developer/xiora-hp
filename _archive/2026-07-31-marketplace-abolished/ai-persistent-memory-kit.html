What's inside

含まれる もの

  • Ollama 呼び出し wrapper (Python) — 7b default / 14b 精度優先 の 2 mode 切替 + timeout / retry

  • 朝 briefing cron script (前日 event 要約 + 今日 の todo top 3 抽出 + Slack / email 送信)

  • README.md 7,000 字 (Ollama install · Postgres 起動 · cron 登録 · 記憶 削除 protocol)
