差別化 factor 1: FSRS + IRT 記憶 科学 の 内蔵

Xiora Lingua は FSRS (Free Spaced Repetition Scheduler) と IRT (Item Response Theory) を 順次 実装 予定 の 記憶 科学 機能 と して 設計 して います。 現在 の β 版 は 基本 lesson + AI tutor が 稼働 中、 FSRS/IRT は 実装 進捗 次第 で β ユーザー に 段階 展開 予定。

  • A 社 サービス (語学 学習 SaaS) は 独自 の spaced repetition アルゴリズム、詳細 は 非 公開
  • Xiora は FSRS (open source、学術 論文 で 検証) + IRT の 標準 実装 を 明示
  • 単語 / 文法 / 発音 の 3 領域 で 別個 の 記憶 モデル を 走らせる

差別化 factor 2: 音素発音 評価 (Phoneme-level pronunciation scoring)

「発音 が 上達 して いる か」を 客観 数値 で 判断 する に は 音素 単位 の 評価 が 必要 です。 Xiora Lingua は 各 単語 の 音素 分解 → 音素 単位 で 期待値 と の 距離 を score 化、fluency / pronunciation / accuracy の 3 軸 で feedback 出力 の 想定 です。

  • 音素 単位 の red/yellow/green ヒート マップ で 「どの 音 が 弱い か」が 一目 で 分かる
  • 母語 (日本語) の 影響 で 苦手 な 音素 (l/r、th、æ 等) を 検出 → 集中 練習 提示
  • A 社 サービス (語学 学習 SaaS) の 発音 判定 は 通過 / 不通過 の 2 値 が 多い 想定 (最新 の A 社 サービス (語学 学習 SaaS) Max は 未検証)
