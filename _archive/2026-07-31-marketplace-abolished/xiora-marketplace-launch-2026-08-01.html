xiora Marketplace 開始 — 内部 で 動いて いる code · pipeline · asset を そのまま 販売 (5 SKU)

2026-08-01

「実 使用 中 の 内部 code」を そのまま 販売 する 発想

xiora は 単独 founder が Kigen · Xiora Lingua · Nexa Education OS · XCloud Connect の 4 core SaaS を 24/7 運用 する 会社。 4 core を 動かす 過程 で、 「内部 で 実 使用 して いる template · pipeline · research asset」が 積み 上がって います。

これら を 「開発 者 が 一 から 書か なくて 済む 素材」として 買切 販売 する の が xiora Marketplace の 発想。 SaaS 販売 (subscription) と は 別 layer の revenue stream で、 米国 の 「7 streams of income」 概念 に 対応 する Business income の sub-form。

5 SKU 一覧 (Gumroad 決済 · 買切 · 即 ダウンロード)

  • Solo SaaS Postgres 16 boilerplate (¥19,800) — Next.js + FastAPI + Stripe webhook + Postgres 16 の Nexa/Lingua 実 稼働 base。 Docker Compose で 1 command 起動、 auth + billing + admin UI 込み。 詳細
  • Xiora Cold Email Pipeline (¥9,800) — Playwright + Gmail SMTP + 4 段 follow-up の XAIOutreach 実 稼働 code。 越谷 · 草加 SMB 展開 で 実 送信 数 100+ の 実 実 績 pipeline。 詳細
  • AI 秘書 Persistent Memory Kit (¥14,800) — xiora の Rei 秘書 基盤 の 汎用 版。 SQLite + JSON schema + LLM prompt template で 「AI が 過去 会話 を 覚え る」を 実装。 詳細
  • Xiora Autonomous QA 4-stage cascade (¥7,800) — build/fact/UX/browser MCP の 4 段 verification pipeline。 xiora HP の 全 deploy 前 に 通す QA。 詳細
  • Japanese SMB Cold Outreach 500-target list (¥4,980) — 越谷 · 草加 · 東京 の SMB 500 社 の research 済 CSV (企業 名 · site · contact form URL · ICP score)。 GDPR / 個人情報 保護 法 遵守 の 法人 情報 のみ。 詳細

「内部 実 使用 中」の 意味 (差別 化 factor)

Gumroad · Stripe · Etsy 等 の marketplace に は 大量 の template が 存在 します。 xiora Marketplace の 差別 化 factor は 「著者 (xiora) が 自 分 の 事業 で 24/7 実 稼働 中 の code · pipeline を そのまま 提供」する 点。

  • Solo SaaS boilerplate → Xiora Lingua v1.0 (Web 43 lesson) が この base で 動作 中
  • Cold Email pipeline → XCloud Connect 越谷 · 草加 outreach で 100+ send 実 実 績
  • AI Memory Kit → Rei 秘書 の 12 ヶ月 分 の 過去 会話 記憶 で 実 使用
  • QA cascade → xiora HP の 50+ commit で 全 deploy 前 通過
  • SMB 500-target list → XCloud Connect 実 送信 target と 同 一 CSV

「実 使用 して ない template」で は なく 「今 動いて いる 事業 の 副産物」を 販売 する 形。 買 手 は 「実 稼働 の 証拠 を 持つ code」を 得られ、 xiora は 4 core 運用 の 副次 revenue が 得られる。

米国 「5+ 収入源」 概念 の xiora 適用

米国 Tom Corley の 「Rich Habits」study で は、 self-made millionaire の **65% が 3 種類 以上 の income stream** を 持つ こと が 判明 (233 名 追跡 · 5 年)。 上位 29% は 5 種類 以上。

xiora は 現在 3 分類 (SaaS subscription / retail digital SKU / affiliate)。 Marketplace 開始 で 4 分類 目 に なり、 iOS IAP (Kigen Lifetime) · KDP 電子書籍 · API monetization · note magazine を 加えて 合計 7 分類 に 到達 予定。

詳細 は xiora 5+ 収入 源 拡張 計画 を 参照 (内部 doc、 公開 URL は 準備 中)。
