# Cover Design Brief — book1_ai_solo_saas_12

## 概要 (for Canva MCP)

**book title**: AI で 完全 無人 SaaS を 12 個 立ち上げた 記録
**subtitle**: 単独 founder が 2026 に 実 挑戦 した 全 手順
**author**: 沓澤 怜士 (xiora 代表)
**series**: xiora Solo Founder Playbook · 第 1 巻

## KDP cover 規格

- **format**: JPEG or TIFF、 RGB、 300 DPI
- **aspect ratio**: 1.6:1 (縦 : 横)、 目安 1600 × 2560 px
- **file size**: 50 MB 以下 (推奨)
- **fonts**: 商用 利用 可 (Google Fonts の Noto Sans JP / Inter 推奨、 xiora brand kit と 一致)

## デザイン コンセプト

xiora brand は 「白 基調 · ミニマル · 事業 に 実装 する 技術 パートナー」 の tone。 本書 の 表紙 も その tone に 揃える。 「凄い 成功 story」 の 派手さ は 避け、 「事実 の 実 記録」 の 冷静さ を 前面 に。 Vercel / Linear / shadcn の 白 基調 ミニマル tone を 参照。

## hero image concept (3 案)

### Concept 1: 「12」 の 数字 を hero に (推奨)

- 表紙 中央 に 巨大 な 「12」 の 数字 (Inter Bold、 サイズ 400-500 pt 相当)
- 「12」 の 各 桁 は xiora blue accent、 周囲 に 12 個 の 小さな dot (12 プロダクト の 象徴)
- 数字 の 下 に「AI で 完全 無人 SaaS を 立ち上げた 記録」 の 一 行
- ミニマル で 遠 目 で も 認識 可、 sumnail (Amazon の 検索 結果 で 小 表示) で も 訴求 が 残る

### Concept 2: 「12 個 の dot grid」 パターン

- 表紙 に 12 個 の dot を 3 × 4 grid で 配置
- 各 dot に プロダクト の 略 記号 (K · L · N · X · A · G · S · E · M · F · S · H の 頭 文字)
- タイトル は grid の 下 に 配置
- 「12 個 の プロダクト の 一 覧」 を 視覚 的 に 表現、 具体 感 が 強い

### Concept 3: xiora 曲線 mark を 巨大 化 hero に

- xiora 公式 brand mark (曲線 + 上 部 の 円) を 表紙 中央 に 大 きく 配置
- タイトル は mark の 上 に、 subtitle は mark の 下 に
- brand 認知 を 前面、 続 巻 の 「シリーズ 感」 を 出せる

## avoid list

- 派手 な グラデ ーション · 光 沢
- 「成功」 「稼ぐ」 「億」 「必勝」 の 語 は 表紙 に 入れ ない (誇大 表現 憲法 遵守)
- 顔 写真 · 人物 イラスト は 使わ ない (xiora brand は 人物 露出 を 抑える tone)
- 他 社 サービス 名 · ロゴ の 使用 (景表法 · 商標 リスク)
- emoji · 記号 過多 (dot prefix 「・」 のみ 許可)
- 「12 個 の SaaS で 月商 数 百万」 等 の 収益 誇示 (fact-first 憲法)
