XMIP 発表 —
市場を「一つの AI」で理解する情報提供 platform

Xiora は Xiora Market Intelligence Platform (XMIP) を発表します。XMIP は「販売サイト」ではありません。 公開データを集約・分析・比較し、user の最適選択を統計根拠で支援する情報提供 platform です。 Xiora は販売業者・仲介業者・契約当事者にはなりません。

XMIP が「しない」こと

XMIP の設計は、Xiora が売買の当事者にならないことから逆算しています。 契約仲介も行いません。あくまで公開データを集約・分析し、意思決定を支援するだけの情報提供事業として運営します。

  • 商品を販売しない (Xiora が売主にならない)
  • 契約を仲介しない (Xiora が仲介業者にならない)
  • 売買の当事者にならない (Xiora が代理人にならない)

提供するもの

  1. Market Data Lake — 各業界の公開 listing とオープンデータを時系列で蓄積、履歴保持。
  2. AI Analysis Engine — 価格 / 需要 / 供給 / 地域 / 人気 / ブランド / 競合 / トレンドの 8 分析。統計処理のみで hallucination を排除。
  3. Decision Support — user query から統計根拠付き top-N を提示。「これがなぜ推薦されるか」の formula, sample size, percentile を透明に開示。

初期対象業界

Phase 1 は 自動車 (中古車) と 不動産。 続けて 求人 / EC / ブランド品 / バイク / リフォーム / 保険 / 投資 / 補助金 / 医療 / 教育 / 飲食 / 宿泊 と横展開します。 各業界について、Xiora が超えない免許境界を明示しています (古物商 / 宅地建物取引業 / 職業紹介事業 / 保険業法 / 投資助言業 / 医療広告ガイドライン)。

Path A (SMB tool) と Path C (Data moat) の統合

XMIP は 2 つの収益経路を同じ data 基盤の上に載せます。

  • Path A: 個人・中小企業向けの SaaS (Free / Standard ¥1,980 / Pro ¥4,980 / Enterprise ¥30,000〜)。 物件探し、車探し、市場調査などの日常意思決定を支援します。
  • Path C: 蓄積された履歴 data を base に、Fortune 500 向け Data licensing (¥100〜500 万/年) を T+3 年で展開。 これが Xiora の長期 moat になります。

設計原則

  • 断定表現 (「買え」「絶対」「保証」等) を code レベルで grep block
  • 全 output に disclaimer を自動付与
  • 掲載元 site への参照リンクのみ提供、Xiora 側で checkout を持たない
  • 分析 formula は version 管理、同一 input で同一 output を保証
  • Reo (Xiora founder) の承認前に外部データを fetch しない (egress-check gate)

ロードマップ

  • T+1 ヶ月: β 公開 (mock data + 車/不動産 dashboard)
  • T+3 ヶ月: 実 data 反映、first-yen (Standard tier 課金開始)
  • T+12 ヶ月: Phase 2 業界追加 (求人 / EC)
  • T+24 ヶ月: Phase 3-5 (ブランド品 / 保険 / 投資 / 医療 / 教育 / 飲食 / 宿泊)
  • T+36 ヶ月: Data licensing 本格化
