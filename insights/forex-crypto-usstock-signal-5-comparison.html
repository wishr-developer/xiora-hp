なぜ 5 サービス 比較か

TradingView の invite-only indicator SaaS は 2020 以降 増加、 現在 主要 5 サービス が 存在 (Swift Algo / LuxAlgo / TrendSpider / TradingView Premium builds / Xiora Algo)。 各社 差別化 point を 5 軸 で 整理。

Swift Algo

米国発 (2022 創業)、月額 $67 / 四半期 $179 / lifetime $799。 Forex + 仮想通貨 + 米株 3 マーケット 対応、 Discord community あり。 backtest は 静的画像 中心、動的 dashboard なし。 access は 決済 後 手動 invite (数時間-数日)。

LuxAlgo

米国発 (2019 創業)、月額 $59.95 / lifetime $1,995。 40+ indicator (LuxAlgo Premium)、Toolkits シリーズ が 有名。 backtest 数値 公開、 Discord + Telegram 併用。 access は 決済 後 自動 invite (数分)。

TrendSpider

米国発 (2019)、月額 $107-$188 (プラン別)。 独自 platform (TradingView 非依存)、AI パターン 検出、backtest 高機能。 対応 マーケット 幅広い が、独自 platform 学習 コスト 高。

TradingView Premium builds

TradingView 公式 の Premium 会員 限定 script。 月額 $29.95 (Premium)。 official 保証、 但し 個別 signal サービス では ない。 「script library」の一部 と いう 位置付け。

Xiora Algo (日本発)

月額 ¥8,800 / 四半期 ¥22,800 / lifetime ¥128,000。 Forex + 仮想通貨 + 米株 3 マーケット 対応。 決済 完了 → 15 分 以内 に TradingView user 自動 invite (Reo 介在 なし = 完全 self-serve)。 5 年 backtest 動的 dashboard、 Discord community + AI moderator、 週次 update。 日本語 UI + JPY 決済 + 特商法 表記 が 差別化 point。

価格 対効果 比較

月額換算 で $59.95 (LuxAlgo) < ¥8,800 ≒ $58 (Xiora Algo) < $67 (Swift Algo) < $107 (TrendSpider)。 Lifetime は Xiora Algo ¥128,000 ≒ $850 vs Swift Algo $799 vs LuxAlgo $1,995。 Xiora Algo が cost-performance top、 且つ 日本市場 特化。
