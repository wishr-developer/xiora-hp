サブスク 期限管理 で 年 ¥20,000 節約 する 3 step — Kigen 実測 家計 audit

契約中 の サブスクリプション を 全て 洗い出す と、 「使って いない のに 続けて いる」契約 が 数 個 見つかる ケース が 一般 的 に あります。 本 記事 は 個人 で 契約中 の サブスク 15 個 を Kigen で 棚卸し し、 年 ¥20,000 (参考値) の 無駄 契約 を 見つけた 3 step の 実測 手順 を 情報 整理 します。 数値 は 実測 例 で あり、 効果 は 契約 状況 に よって 大きく 差 が あります。

この記事は何か

この 記事 は、 個人 で 契約中 の サブスクリプション 15 個 を Kigen (キゲン) で 棚卸し した 実測 事例 を 3 step で 情報 整理 する 記事 です。 3 step (棚卸し → Kigen 登録 → 判定) を 経て、 15 契約 が 12 契約 に 減り、 月 目安 ¥1,700 · 年 目安 ¥20,000 の 削減 が 発生 した 参考値 を 記載 します。 効果 は 個別 事情 (契約 数 · 単価 · 使用 頻度) に よって 大きく 差 が あり、 本 事例 の 数値 が 保証 される もの では ありません。

Step 1: 全 サブスク の棚卸し (クレカ 明細 + Apple/Google IAP + 銀行 direct 引落)

まず 「今 何 に 課金 されて いる か」を 全 経路 で 洗い出し ます。 実運用 で 見落 とし が 発生 しやすい 3 経路 は 以下 の 通り です。

  1. クレジット カード 明細 (過去 3 ヶ月): 動画 · 音楽 · SaaS · 雑誌 · フィットネス アプリ 等 の 大半 が ここ に 現れます。 明細 CSV を ダウンロード し、 「毎月 同 金額 の 引落」を 抽出 する と 効率 的。
  2. Apple / Google IAP (アプリ内 課金): iPhone なら 設定 → Apple ID → サブスクリプション、 Android なら Play ストア → お支払い と 定期購入。 「App Store 経由 で 契約 した もの」は クレカ 明細 で は 「Apple」と しか 表示 されない ため 個別 把握 が 必要。
  3. 銀行 direct 引落 · 口座 振替: 新聞 · 通信 · 生保 系 が ここ に 集中 する ケース。 通帳 · ネット バンキング の 直近 3 ヶ月 で 「毎月 同 相手 · 同 金額」を 抽出。

実測 例 で は この 3 経路 で 15 契約 が 発見 されました。 「そう いえ ば 契約 して いた」の 気付き が 数 件 発生 する の が 一般 的 な 傾向 です。

Step 2: Kigen に 「契約日 / 更新日 / 月額」で 登録

棚卸し で 抽出 した 15 契約 を Kigen に 登録 します。 各 契約 で 記録 する 項目 は (1) サービス 名、 (2) 契約日 (可能 なら)、 (3) 次回 更新日、 (4) 月額 (税込)、 (5) カテゴリ tag (動画 / 音楽 / SaaS / 雑誌 / フィットネス 等) の 5 項目 を 目安 に します。 15 契約 の 登録 は 慣れる と 20-30 分 で 完了 する ケース が 一般 的。 契約日 が 不明 な もの は 空欄 の まま 登録 し、 次回 更新日 だけ でも 埋めて おく の が 実運用 の tips です。

Step 3: 3 axis (使用頻度 / 代替可 / 継続意思) で 判定 → 解約 or 継続

15 契約 の 一覧 を 前 に、 各 契約 を 3 軸 で 判定 して 継続 / 解約 を 決めます。

  1. 使用頻度 (High / Mid / Low): 直近 3 ヶ月 で 実際 に 何 回 使ったか。 「月 0-1 回」の Low が 解約 候補 の 一次 スクリーニング。
  2. 代替可 (Yes / No): 同 機能 が 無料 · 別 契約 で カバー できる か。 動画 系 で 2 契約 ある 場合 は 片方 が 代替可 の ケース が 一般 的。
  3. 継続意思 (Yes / Neutral / No): 「あった 方 が 良い」と 感じる か。 使って い なくて も 「安心 の ため に あった 方 が 良い」と 明確 に 答え られる もの は 継続 で 良い。

この 3 軸 で 「使用頻度 Low + 代替可 Yes + 継続意思 No/Neutral」の 契約 を 解約 対象 と します。 解約 手続き は Kigen の 「更新日」通知 の タイミング で 実施 する と、 「解約 忘れ で 1 ヶ月 分 追加 課金」を 避け られます。

実測 結果: 15 → 12 契約、 年 ¥20,000 節約 (参考値)

本 実測 例 で は 15 契約 → 12 契約 に 減り、 月 目安 ¥1,700 · 年 目安 ¥20,000 の 削減 が 発生 しました。 解約 した 3 契約 の 内訳 は 動画 サービス 1 契約 (代替可)、 雑誌 系 1 契約 (使用頻度 0)、 SaaS 1 契約 (継続意思 No) の 参考 例 です。 Kigen Plus プラン (¥600/月 = 年 ¥7,200) を 契約 して も、 削減 額 の 純 益 は 年 目安 ¥13,000 前後 に なる 計算 例 で した。 数値 は 契約 状況 に よって 差 が 大きい ため、 参考値 と して お考え ください。
