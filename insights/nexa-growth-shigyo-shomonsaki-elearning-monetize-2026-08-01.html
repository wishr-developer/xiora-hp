この記事は何か

本 記事 は、 税理士 · 社労士 · 行政書士 事務所 (3-30 名 規模) が 顧問先 企業 (10-50 社 想定) に 「法改正 対応 e-learning」を 追加課金 で 配信 する 具体 手順 を 情報整理 する ガイド で す。 Nexa Growth (¥29,800/月, ≤50 名 · 2026 年 8 月 現在 の 参考 値) を 前 提 に、 教材 制作 · 配信 · 進捗 · 修了証 · 課金 モデル の 4 phase と 導入 時 注意 点 を fact-based で 記載 します。

背景: 顧問先 教育 needs の 高まり (法改正 頻度 + オンライン 化)

近年、 インボイス 制度 · 電子帳簿保存 法 · 労働 基準 法 · 個人情報 保護 法 等 の 法改正 が 頻繁 に 発生 して おり、 士業 事務所 の 顧問先 企業 で は 「担当 者 が 動画 で 短時間 に キャッチ アップ したい」と の ニーズ が 一定 存在 する 目安 で す。 対面 セミナー は 移動 · 日程 調整 コスト が 高く、 オン デマンド 動画 + 修了 確認 の 形式 で 提供 する 選択 軸 が 徐々 に 拡大 して いる 傾向 が 見られ ます。 需要 · 顧問先 の 反応 は 事務所 · 業種 · 地域 に 依存 し、 一律 で 保証 される もの で は ありません。

Nexa Growth (¥29,800/月, ≤50名) の 提供 機能

Nexa Growth プラン は 2026 年 8 月 現在 の 参考 値 で 、 月額 ¥29,800 · 学習 者 数 上限 50 名 · 教材 upload 無制限 · SCORM 1.2 / 2004 対応 (順次 拡充 予定) · 進捗 dashboard · 修了証 PDF 自動 発行 · AI 講師 (講義 script · 小テスト 生成 補助) · 事務所 別 schema 分離 (顧問先 データ の 分離) を 想定 して います。 各 機能 の 提供 時期 · 仕様 は 変更 され得 る 目安 で 、 契約 前 に 公式 pricing ページ で ご 確認 ください。

Phase 1: 事務所 名義 の 「法改正 e-learning」設計

初期 設計 で は、 (1) 対象 顧問先 の 業種 · 従業 員 規模 · IT リテラシー を 把握、 (2) 「30 分 動画 + 5-10 問 の 小テスト + 修了証 PDF」の 3 元素 で 1 講座 を 構成、 (3) 配信 頻度 を 「月次 1 講座」または 「制度 改正 発生 時 に 随時」の どちら か で 事務所 内 で 合意 する の が 目安 で す。 講座 テーマ 例 は 「2026 年 インボイス 対応 の 実務 変更 点」「電帳法 の 保存 要件 更新」「労基法 改正 と 就業 規則 見直し」等 で 、 士業 独占業務 に 該当 しない 「一般 情報 提供 範囲」に 留める 設計 が 前 提 と なります。

Phase 2: 教材 制作 (自作 or AI 補助)

教材 制作 は、 Nexa 内蔵 の AI 講師 機能 で 「講義 script 骨子 · 小テスト 5-10 問 · 修了証 用 タイトル 案」を 生成 補助 し、 事務所 職員 が 40 分 程度 の 撮影 · 収録 で 30 分 動画 に 編集 する 参考 手順 が あります。 撮影 機材 は 一般 的 な スマート フォン + 三脚 + マイク で 目安 品質 に 到達 する 事例 が あり、 初期 投資 を 抑え られる 傾向 が 見られ ます。 生成 された 講義 script · 小テスト は、 士業 資格 者 が 監修 · 事実 確認 を 行い、 一般 情報 提供 の 範囲 で 収まる か を 確認 する 工程 を 必ず 入れる の が 目安 で す。

Phase 3: 顧問先 へ の 課金 モデル 設計

課金 モデル は、 事務所 側 が Nexa Growth (¥29,800/月) を 契約 し、 顧問 契約 に 「e-learning 配信 オプション」と して 追加 する 想定 で す。 参考 モデル と して 「顧問料 に 上乗せ ¥3,000/月 × 20 顧問先 = ¥60,000/月」の 単純 計算 で は、 事務所 コスト ¥29,800 を 差し引き ¥30,200/月 = 年 ¥362,400 の 差益 参考 例 と なります。 この 数値 は 単純 計算 例 で あり、 実 収益 の 保証 で は ありません。 実際 の 収益 は 顧問先 数 · 導入 率 · 解約 率 · 制作 工数 に 依存 し、 事務所 · 業種 · 地域 で 差 が 発生 する 目安 で す。 課金 開始 前 に、 顧問 契約 書 の 変更 · 追加 提供 の 覚書 · 消費 税 の 取扱 等 を 顧問 弁護士 · 顧問 税理士 と 確認 する の が 目安 で す。

Phase 4: 実運用 (配信 → 進捗 dashboard 監視 → 修了証 発行 → 契約 更新 訴求)

実 運用 で は、 (1) 顧問先 担当 者 を Nexa 上 に 招待 · ID 発行、 (2) 月次 で 講座 配信 の 案内 メール を 送信、 (3) 進捗 dashboard で 受講 完了 率 · 小テスト 合格 率 を 事務所 側 で monitor、 (4) 修了 者 に 修了証 PDF を 自動 発行、 (5) 年 1 回 の 契約 更新 面談 で 受講 実 績 を 提示 · 継続 訴求、 の 5 手順 が 参考 と なります。 dashboard に は 個別 学習 者 の 進捗 · 修了 日 · スコア が 表示 され、 顧問先 の 教育 効果 を 事務所 側 で 可視 化 する 目安 と なります。 契約 更新 · 単価 上げ の 成否 は 顧問先 状況 に 依存 する 点 に ご 留意 ください。

導入時 の 3 注意点

(1) 士業 独占業務 の 境界 — 税理士 法 · 社会 保険 労務 士 法 · 行政 書士 法 の 独占業務 (税務 相談 · 労務 相談 · 権利 義務 に 関する 書類 作成 相談 等) は e-learning 講座 に 含めず、 「一般 情報 提供 の 範囲」に 留める の が 目安 で す。 個別 具体 の 相談 は 従来 通り 顧問 契約 の 中 で 資格 者 が 対応 する 建付 と します。 (2) 顧問先 IT リテラシー — 一部 顧問先 で は 動画 視聴 · ID ログイン に 慣れて い ない 目安 が あり、 導入 時 に 「初回 ログイン 案内 PDF」「1 対 1 サポート 30 分」を 用意 する と 定着 率 が 上がり やすい 参考 傾向 が あります。 (3) 個人情報 · GDPR 遵守 — 顧問先 従業 員 の 氏名 · メール · 進捗 データ は 個人情報 で ある ため、 Nexa の schema 分離 · 監査 log · アクセス 制御 の 設定 を 事務所 側 で 事前 確認 し、 顧問先 と の 覚書 に 明記 する の が 目安 で す。

まとめ + CTA

士業 事務所 が Nexa Growth (¥29,800/月, ≤50 名) で 顧問先 教育 を 追加 収益 化 する 実装 は、 教材 設計 · 制作 · 課金 · 運用 の 4 phase と 3 注意点 の 順 で 進める の が 目安 で す。 数値 · 差益 例 は 全て 参考 値 で 、 実 収益 の 保証 で は ありません。 プラン 詳細 · 契約 条件 は 下 記 pricing ページ で ご 確認 ください。
