Ocean LLM.
業種特化 dataset を moat とする 独自 LLM。

Ocean LLM は Xiora が 内部 R&D として 進めている 独自 LLM プロジェクト。
汎用 base model と 差別化する 4 つの 業種特化 dataset (飲食 / 士業 / 教育 / 投資) を moat と し、
P0 (baseline 選定) から P5 (自社運用 base model) まで 段階的 に 育てます。 public launch は 未定。

Insights の Ocean LLM 記事 R&D 領域 を 見る

What Ocean LLM is

「Xiora の 全プロダクト の 応答基盤」を、
1 つ に 統合する 独自 LLM。

Xiora は Kigen / XCloud / Aiverse / Shigyo Agents / Restaurant OS / TradeOS 等 多数 の プロダクト を 運用しています。 各プロダクト の 応答 が バラバラ の 商用 API に 依存すると、統合品質 と cost が 制御 できません。 Ocean LLM は 全プロダクト の 応答基盤 を 段階的 に 内製化する 内部 プロジェクト です。

R&D Focus

4 つの R&D 領域

業種特化 4 dataset

飲食 / 士業 / 教育 / 投資。 各 dataset は Xiora の 実運用 プロダクト から 匿名化 の 上 抽出し、SFT / DPO 段階 で 活用予定。

P0-P5 段階 ロードマップ

P0 (baseline 選定) → P1 (SFT) → P2 (DPO) → P3 (RAG 統合) → P4 (routing layer) → P5 (自社運用 base)。 各 phase は Insights で 公開。

内部 basin 統合

Agent Factory / Content Engine の 内部 basin と 連携し、agent 側 の 応答品質 を 一気通貫 で 制御する 予定。

cost & routing

汎用 API / 自社 model / OSS model を 応答ごと に 動的 route する layer を 段階 導入。 cost / latency / 品質 を 3 軸 で 最適化。

Status

public launch は 未定

Ocean LLM は 現在 Xiora 内部 の R&D プロジェクト で あり、public API / SDK の 提供 は していません。 顧客 が 実際 に 体験できる 最も 近い 経路 は OceanChat (一般公開 対話 AI、¥1,980/月、DNS 準備中) です。

R&D 進捗 の 一部 は Xiora Insights の 「Ocean LLM 4 dataset」「Ocean LLM public launch」等 の 記事 で 段階 公開しています。 SDK / API 化 の 検討 状況 は 追記予定 です。

R&D 情報 の 追跡

Ocean LLM の 進捗 は Xiora Insights で 段階 公開しています。 早期 に 業種特化 LLM を 使いたい 場合 は OceanChat の launch 案内 に ご登録ください。
