What XioraEC is

「Shopify + Zendesk + 商品撮影」を、
AI で 1 SaaS に。

現在 の EC 事業者 は、EC platform (Shopify 等) + 顧客対応 tool (Zendesk 等) + 商品 撮影 / 説明文 作成 を 個別 発注 で 運用しています。 XioraEC は これら を AI で 1 SaaS に 統合し、個店 / 小規模 事業者 が 立ち上げ から 運用 まで 少人数 で 回せる 状態 を 目指します。 現在 building 段階。

Core Features

4 本柱

商品登録 AI

商品 画像 を アップロード する だけで、AI が 説明文 / カテゴリ / タグ / SEO タイトル を 自動生成。 手動 修正 も 可能。

在庫 管理

SKU / 在庫 数 / 発注 点 の 一括 管理。 複数 販売 chan (自 EC + 楽天 / Amazon) の 在庫 集約 に 対応予定。

決済 統合

Stripe / PayPay / コンビニ決済 の 3 chan を 1 契約 で 統合。 特商法 表記 / 領収書 発行 も 自動化。

顧客対応 AI

問い合わせ mail に対する 返信 draft を AI で 自動 生成。 事業者 は 送信 前 に 確認 の みで 対応 完了。
