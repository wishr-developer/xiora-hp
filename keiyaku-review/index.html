Xiora 契約書 AI レビュー

NDA / 業務委託 / 秘密保持 の 契約書テキスト を 3 tier (即受入 / 交渉推奨 / 弁護士送り) に 分類 + business 観点 気づき。 LegalOn の 100 分の 1 の 価格で SMB / 個人事業主 特化。

重要: 本ツール は 法的助言 ではありません
本ツール が 提示する 内容 は 一般的な business 観点 の 気づき / 参考情報 です。 実際の 契約締結 判断 / 具体的 法的解釈 は 必ず 弁護士 に ご相談ください。 弁護士法 72 条 の 「法律事務の代理」に 該当 する 行為 は 提供 していません。

使い方

  1. Anthropic API key を 取得 (console.anthropic.com)
  2. 下記 の 「Anthropic API Key」 に 貼付 (localStorage 保存、Xiora サーバー には 送信されません)
  3. 契約書 の text を 貼付
  4. 「レビュー実行」→ 3 tier 分類 + 気づき が返る

API key は お客様 の browser に 保存 され、 直接 Anthropic API に 送信 されます。 Xiora サーバー は key を 一切 受信 しません。

個人情報 (氏名 / 住所 / 電話 等) は 必ず 削除 or 匿名化 してから 貼付 してください。

よくある 質問


Q. Xiora サーバー に 契約書 が 送信 されますか?


A. いいえ。 貴社 browser から Anthropic API に 直接 送信 されます。 Xiora サーバー は 契約書 も API key も 一切 受信 しません。



Q. Anthropic API key の 取得方法 は?


A. console.anthropic.com で 無料 signup、 「Create Key」で 発行。 従量課金 (1 レビュー ¥3-20 目安)。



Q. 弁護士法 違反 では ないですか?


A. 弁護士法 72 条 は 「法律事務の 代理」を 禁止 していますが、 本ツール は 「一般的な business 観点 の 情報提供」に 限定 しており、 具体的 な 法的助言 / 代理 は 一切 行いません。 分析結果 に基づく 実際の 契約 判断 は 必ず 弁護士 に ご相談ください。



Q. Pro プラン の 特典 は?


A. 現時点 (2026-08-28 MVP) は Free と Pro で 機能差 は ありません が、 Pro は 履歴保存 + PDF export + 拡張分析 を 順次 実装 予定 (2026 Q4)。 早期 加入者 は grandfather price ¥1,980 で 永続 固定。
