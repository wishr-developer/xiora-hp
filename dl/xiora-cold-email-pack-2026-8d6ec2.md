## 1. 骨格 (Skeleton) と 6 原則

全 email 共通の骨格:

```
subject: <55 字以内> — <hook 1 語 + 業種 keyword>

body:
  1) 名乗り (1 行): 「<自社> の <自分> と申します。」
  2) 事前調査で見えた 1 事実 (2-3 行): 「<公式サイト / SNS> を拝見し、<具体 fact> が印象的でした。」
  3) 業種 pain point 仮説 (2-3 行): 「<業種> では <pain> が起きやすいと伺うことがあります。」
  4) free-value 記事 (1 行 + URL): 「参考までに <記事 title>: <URL>」
  5) soft CTA (1-2 行 + URL): 「30 分 の オンライン相談 で 状況を お伺いできますでしょうか。 押し売りの意図はありません: <URL>」
  6) 署名 (3 行): 名前 / mail / 発信者所在地
  7) opt-out (1 行): 「配信停止: <URL>」
```

**6 原則:**

1. **research-based**: 事前 3 点調査 (公式 HP 1 ページ + 直近 6 か月の投稿 3 件以上 + 業種特有 pain 想定) を必ず 冒頭 の 1 事実 に 反映
2. **250-400 字 body**: 短すぎず長すぎず、スクロールなしで読める分量
3. **subject 55 字以内**: モバイル Gmail で 全表示される 上限
4. **soft CTA only**: いきなり販売しない、無料相談 or free-value 記事 の 提示 のみ
5. **opt-out 必須**: 特電法 (特定電子メール法) に基づく 配信停止 URL を 全 email に 記載
6. **1:1 送信**: CC / BCC / mail list への 一括送信は 禁止

## 13. Hook A/B バリエーション集

Subject と 冒頭 1 事実 の hook パターンを 業種横断で 集約。

| No | パターン | 例 |
|----|---------|-----|
| 1 | 直近ニュース | 「2024 年 xx 月 リニューアル」 |
| 2 | 数値 milestone | 「MRR ¥100k 達成」「販売 5,000 個 突破」 |
| 3 | メディア露出 | 「Product Hunt 順位」「note 記事 series」 |
| 4 | 特化領域 | 「オーガニック カラー 特化」「平屋 注文住宅」 |
| 5 | 実績 | 「英検 準 2 級 合格 xx 名」「施工 xx 件」 |
| 6 | 直近 launch | 「新商品 発表 拝見しました」 |
| 7 | 受賞 | 「xx 賞 受賞 拝見しました」 |
| 8 | 補助金採択 | 「IT 補助金 採択 発表 拝見しました」 |
| 9 | 記事 series | 「note SaaS 記事 series 拝見しました」 |
| 10 | founder ストーリー | 「創業 のインタビュー 拝見しました」 |

**推奨**: Subject には No.1-3 を、body 冒頭 1 事実 には No.4-10 を 使うと 開封率 と 反応率 が バランスする。

## 14. 配信停止 (opt-out) 案内文 テンプレ (特電法準拠)

全 email の 末尾 に 必須。 少なくとも 以下 5 要素:

1. 送信者 名前 (法人名 or 個人事業名 + 個人名)
2. 送信者 mail
3. 送信者 発信者所在地 (住所)
4. 配信停止 URL (1 タップで停止できる)
5. 「拒否 の 意思表示 に 応じます」の 文言

推奨テンプレ:

```
---
{{ 自社 }} / {{ 自分 }} ({{ mail }})
```

## 15. 送信前 3 点 checklist

各 email 送信 の 前 に 必ず 手作業 (or 自動化 gate) で 確認:

- [ ] **事前調査 3 点**: (a) 公式 HP or SNS の 1 ページ 閲覧、(b) 直近 6 か月 の 投稿 / 記事 / review 3 件 以上 確認、(c) 業種特有 pain point 想定 記述 (research_summary 40 字以上)
- [ ] **MX record check**: mail domain の MX 存在確認 (typosquat 防止)
- [ ] **suppression list 参照**: 過去 opt-out / bounce / complaint hit しないこと
- [ ] **1:1 送信**: CC / BCC / mail list 使用禁止、to は 1 address のみ
- [ ] **subject 55 字以内**: mobile Gmail で 全表示される 上限
- [ ] **body 250-400 字**: スクロールなしで読める分量
- [ ] **opt-out URL 記載**: 特電法 必須
- [ ] **発信者所在地 記載**: 特電法 必須
- [ ] **同一 target 30 日以内 再送禁止**: 過去 log 参照

**hard limit**:

- 1 日 送信上限: 30 通 (warm-up 期間、Gmail SMTP)、100 通 (Gmail SMTP 上限)、500 通 (SendGrid / SES 等 の paid 契約時)
- 1 時間 送信上限: 5 通 (warm-up)、20 通 (通常時)
