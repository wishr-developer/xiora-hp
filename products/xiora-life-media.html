What XioraLifeMedia is

「curation を、属人 化 させ ない」
生活 商品 revenue engine。

楽天 ROOM の 上位 影響 力 は、これまで 手動 curation の 属人 化 が 前提 でした。
XioraLifeMedia は 商品 選定 → affiliate URL 変換 → SNS 投稿 draft 生成 の 3 工程 を 自動 化 し、
複数 プラットフォーム 横断 の 生活 系 curation 運用 を engine 化 します。

Core Features

4 つ の standard 機能

楽天 商品 API 連携

楽天 Ichiba Item Search から 生活 カテゴリ (キッチン / 収納 / 家電 / 食品 等) の 上位 商品 を 収集、内部 inventory に 蓄積。

EV スコアリング

期待 価値 (expected value) スコア で 商品 を 評価 し、上位 のみ を curation 対象 に 昇格。 現行 平均 EV2 = 1.728 (自社 dogfood 21 products)。

affiliate URL 変換

rafcid (_ra_ variant、ROOM 用) を 適用 して affiliate URL を 自動 生成。 投稿 draft に そのまま 埋込 済 の 状態 で 出力。

SNS 投稿 draft 生成

楽天 ROOM を 起点 に、 X (Twitter) / Instagram / Threads 等 の 多 プラットフォーム draft を 統一 template で 生成。 Reo 側 は 承認 の みで 展開 可能。

Roadmap

3 phase 展開

Phase 1 (現行)

Xiora 自社 の 楽天 ROOM 1 account で dogfood 稼働中。 21 products の inventory + affiliate URL + 本文 draft を 常時 保持。 収益 は 楽天 affiliate report を 経由 して 積み上げ 中。

Phase 2 (2026 Q4)

3 account × 5 投稿 / 日 (計 15 投稿 / 日) の 定常 運用 に 昇格。 X (Twitter) 拡散 と の 併走、投稿 の 疲弊 を engine で 完全 吸収。

Phase 3 (2027 Q1+)

4 platform (ROOM / X / Instagram / Threads) 統合 の revenue engine 化。 教材 パッケージ (Xiora Rakuten Article Template Pack 姉妹) で 外販 経路 の 検討 開始。

Stack

技術 構成 の 概要

data source

楽天 Ichiba Item Search API (v2、 openapi.rakuten.co.jp 準拠、applicationId + accessKey + Referer allowlist)。

inventory

SQLite (dev) → PostgreSQL 16 (prod)。 全 21 products が 100% affiliate URL + 本文 draft を 保持。

AI 分担

Ollama 7b default (curation copy)、14b escalate (品質 判定)。 Xiora 憲法 準拠 で 過大 表現 を 前段 で 除外。

publish flow

Playwright semi-auto posting (2026-07-21 Reo 明示 認可)、Reo 側 は 承認 の みで engine が 展開。

運用 β の 案内 を 受け取る

現在 は Xiora 自社 dogfood 期間 で、外部 提供 は 開始 して いません。 Phase 3 の 教材 パッケージ 開放 時 に メール で ご案内 します。
生活 系 curation を engine 化 したい 個人 事業 者 / 副業 アフィリエイター は 事前 に 登録 して ください。
