Overview

Xiora の 5 層 (Path A/B/C/D + Ocean LLM)

Xiora は 単一 プロダクト の 会社では ありません。 業種特化 SaaS / 受託 インフラ / 配信・研修・組織 SaaS / 法務・キャリア / 独自 LLM の 5 層 を 並行して 運用しています。 下記 は 各層 の 位置付け と 主要 プロダクト の 対応関係 です。

Path A — 生活・iOS SaaS

個人 / 家族 の 期限管理・生活情報 を On-Device で 支援する iOS プロダクト。 代表: Kigen。

Path B — 受託 / インフラ SaaS

受託 SaaS の 保守 / インフラ を 束ねる 統合基盤。 代表: XCloud Connect / XCloud Flow。

Path C — AI 配信・現場 SaaS

AI VTuber 配信・飲食店選び・受託運営 の 現場 SaaS 群。 代表: Aiverse Studio / Gourmie / Restaurant OS。

Path D — 法務・研修・組織

士業支援 と 実務研修 を 束ねる 組織向け プロダクト。 代表: Shigyo Agents / Nexa Academy (Xiora Apps 内)。

Ocean LLM — 独自 LLM 事業

業種特化 4 種 dataset を moat とする 独自 LLM 開発。 P0-P5 ロードマップ を Insights で 公開中。

Content Engine — 記事 / SEO / PR

Xiora HP Insights の SEO 記事、News の 発表、及び 外部 PR チャネル を 束ねる 内部 basin。

Path A/B/C/D + Ocean LLM の 位置関係

それぞれ の Path は 独立した 事業層 であり、共通の 内部 basin (Agent Factory / Content Engine) を 通じて 相互 連携します。

個人・生活 (Path A)

Kigen を 起点 に、生活 領域 iOS SaaS を 拡張。 On-Device / privacy first を 標準。

受託・保守 (Path B)

XCloud Connect / Flow を 起点 に、中小企業 向け DX 実装 を Xiora 名義 で 一元化。

AI 現場 SaaS (Path C)

Aiverse Studio / Gourmie / Restaurant OS / TradeOS。 現場 の 業務 SaaS を 段階 展開。

組織・法務・研修 (Path D)

Shigyo Agents / Nexa Academy。 士業支援 + 実務研修 を 束ねる 組織向け層。

Ocean LLM (LLM 層)

P0-P5 の 5 phase 構成。 Path A-D の 実運用 log を 業種特化 dataset として活用。

内部 basin (infra)

Agent Factory + Content Engine は 全 Path を 横断 する 内部 basin。 公開・外部提供 は 段階検討。
