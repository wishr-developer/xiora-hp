2. 取得する個人情報の項目

  • お客様からのお問い合わせ内容、面談録音・議事メモ (お客様が同意された場合のみ)
  • LLM プロンプト 履歴 (Nexa Academy / Xiora Lingua / Kigen 等 の 4 core AI 機能 を 利用 した 場合)

3. 個人情報の利用目的

取得した個人情報は、以下の目的で利用いたします。

お問い合わせ、ご相談への対応
サービス改善のための統計処理 (氏名を含まない集計)
重要なお知らせ、アップデート情報の配信
マーケティング目的の配信 (ただし お客様の同意またはオプトアウト機会の提供を前提とします)
法令に基づく開示、当社の権利保護、不正利用防止

4. 第三者提供 / 委託

原則として、お客様の同意なく個人情報を第三者に提供いたしません。 ただし、以下の場合は例外とします。

  • 決済処理のため Stripe, Inc. (米国) にトークン化情報を提供する場合
  • クラウド事業者 (CONOHA VPS 日本、Cloudflare Pages 米国、Google (Gmail / GA4) 米国、Resend 米国、Sentry 米国) に処理を委託する場合
  • AI モデル 提供事業者 に プロンプト / 補足 情報 を 送信 する 場合: Anthropic (Claude、米国)、OpenAI (米国、一部 機能)、Google (Gemini、米国、一部 機能)、Ollama (self-host 日本、基本 経路)
  • 法令に基づく開示要請があった場合
  • 事業の承継 (吸収合併、事業譲渡等) が発生した場合、承継先に開示する場合

※ 米国 事業者 へ の 越境 データ 移転 は、 EU/EEA 加盟国 の 個人 データ に つき Standard Contractual Clauses (SCC) 相当 の 対応 を 順次 実施 予定 です。 現時点 で は 主 顧客 が 日本 在住 者 で ある こと を 前提 に 運用 して います。

当社は 利用状況分析 (Google Analytics 4 等) および 認証維持 のために Cookie および類似技術を使用します。 詳細は「Cookie ポリシー」をご参照ください。

6. 個人情報の保管期間

  • 契約期間中および契約終了後 5 年間 (税務上の帳簿保存義務との整合)
  • 保管期間経過後は、当社の内部規程に従い遅滞なく削除または匿名化します

7. お客様の権利

お客様は、当社に対し、ご自身の個人情報について以下の請求を行うことができます。

  • 開示、訂正、追加、削除、利用停止、第三者提供の停止
  • 保有個人データの利用目的の通知

上記請求は info@xiora-official.com 宛メールにてお申し出ください。 本人確認のうえ、法令の範囲内で対応いたします。

8. 未成年のご利用

18 歳未満 の 方 が 本 サービス を ご利用 に なる 場合 は、保護者 の 同意 を 得た うえ で ご 利用 ください。 一部 プロダクト (Nexa Academy 学生 塾 コース の うち 高校生 未満 向け コース、Xiora Lingua 家族 プラン 等) は 保護者 の 同意 を 前提 と します。

9. 越境データ移転

本 サービス は Stripe (米国)、Cloudflare (米国 / 日本 CDN)、Google (Gmail / GA4、米国)、Anthropic (Claude、米国)、Resend (米国)、Sentry (米国) 等 の 海外 事業者 を 利用 します。 これら の 事業者 は 各国 の 個人情報 保護 規制 (米国 CCPA、EU GDPR 等) に 従って 情報 を 取り扱い ます。 EU/EEA 居住 者 の データ は Standard Contractual Clauses (SCC) 相当 の 対応 を 順次 実施 予定 です。
