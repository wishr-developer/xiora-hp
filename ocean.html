Ocean — Xiora の 内部 AI インフラ Stack

Ocean は Xiora の 内部 AI インフラ stack (2026-07-19 に旧 codename から rebrand)。 20+ AI 社員、brain runtime、12+ handler、内部ガードレールを組み合わせて 24/7 自動運用しています。 本ページは Ocean stack の 公開 status / roadmap を掲載します。

Ocean とは

Ocean は Xiora が 自社 SaaS (Kigen / Aiverse Studio / Nexa / Gourmie / XCloud Connect 等) を 少人数運営で 24 時間動かすための 内部 AI インフラです。 外部提供 product ではなく、Xiora 内部の backing stack として位置づけられています。

  • Brain runtime — 12+ handler で mail / GitHub / Stripe / 監視 event を吸収
  • AI 社員 20+ — CEO Proxy / Developer / Research / Legal / Growth の 20 名構成
  • Vault + Edge Gateway — Caddy auto TLS + ConoHa VPS 上で単一 edge に集約
  • 内部ガードレール — outgoing money / KYC / delete / permission / contract の永続 human gate

Path A / B / C / D (T+30 年 vision と接続)

Xiora の 長期戦略は 4 パスで整理しています。Ocean はいずれのパスでも実行基盤として機能します。

  • Path A — Xiora SaaS 事業の自動運用 (Kigen / Aiverse Studio / Nexa 等)
  • Path B — 越谷・草加・川口 の中小 IT/SaaS 会社への AI 導入支援
  • Path C — Xiora Academy Nexa による Learning 事業
  • Path D — Xiora Career / XioraHire による HR 事業
