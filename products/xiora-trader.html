What XioraTrader is

個人投資家 の 「自作 インジ 集」を、会員化。

Xiora の 代表 が 個人投資家 として 使用してきた TradingView 用 Pine Script インジケーター (トレンド / RSI / ボラ / 出来高 系) を 月額 会員向け に 提供します。 インジ は TradingView chart 上 に 追加する 情報 tool で あり、売買 の 助言・推奨 は 一切 行いません。 各 会員 の 判断 で ご利用ください。

Contents

会員 提供 内容

Pine Script インジ 群

Xiora 自作 の TradingView 用 Pine Script インジケーター を 会員限定 で 公開。 追加・改修 の 度 に 通知。

使用方法 の 解説

各 インジ の 表示 パラメータ / 設定例 / 誤読 の 注意点 を 会員 向け ページ で 解説 (投資 の 推奨 は しません)。

版数 管理

インジ の 更新 は 版数 と 変更点 を 明示。 過去版 も 参照可能 に する 予定。

Discord サポート

会員 向け Discord で 質問・要望 を 受付。 投資助言 は 提供しません (使用方法 の 疑問 のみ 対応)。
