OceanChat.
業種特化 dataset で、答える 対話 AI。

OceanChat は、Xiora の Ocean LLM 基盤 を 活用する 一般公開 向け 対話 AI プロダクト。
汎用 LLM と 異なり、飲食 / 士業 / 教育 / 投資 の 4 dataset を moat と し、実務 に 直結する 応答 を 目指します。

What OceanChat is

「汎用 AI」に、業種特化 dataset を 足した 対話 AI。

既存 の 汎用 対話 AI は 幅広く 答えられる 一方、業種 の 実務 に 落ちにくい 弱点 が あります。 OceanChat は Xiora が 自社運用中 の 業種特化 4 dataset (飲食 / 士業 / 教育 / 投資) を 統合し、実務者 が 使える レベル の 応答 を 提供します。 個人 ¥1,980/月 の 単一 tier で 提供予定。

Core Features

4 つの standard 機能

業種特化 4 dataset

飲食 (Xiora Restaurant OS 由来) / 士業 (Shigyo Agents 由来) / 教育 (Nexa Academy 由来) / 投資 (TradeOS 由来) の 4 dataset を 応答時 に 参照。

Ocean LLM 基盤

Xiora 独自 LLM 開発プロジェクト (P0-P5 ロードマップ) の 一環。 base model 開発 と 応答 UI を 分離し、model 差し替え に 対応可能。

単一 tier ¥1,980/月

個人 向け に 単一 tier のみ 提供 (無料 / 従量 なし)。 使用回数 の 上限 と subscribe 中断 は Web UI から 一括管理。

公開 subdomain 提供

ocean.xiora-official.com subdomain で 提供 (現在 DNS approve 待ち)。 launch 時 に mail / X で アナウンス予定。
