What XioraPredict is

指標 の 「事前 レンジ 見立て」を、
統計 で 定量 化。

XioraPredict は、市場 が 注目 する 主要 経済 指標 (CPI / 雇用統計 / GDP / FOMC 等) に対して、Xiora の 統計 dataset を 元に 発表前 の レンジ 見立て を 月次 report で 提供します。 report は 個人投資家 の 情報 参考 用 で あり、 具体 銘柄 の 推奨 や 売買 助言 は 一切 行いません。

Report Contents

月次 report の 構成

指標 別 レンジ 予測

CPI / 雇用統計 / GDP / FOMC 等 の 予測 レンジ を 過去 統計 と 併せて 提示。

過去 実績 の 統計 分布

各 指標 の 過去 5-10 年 の 実績 分布 を chart 化し、レンジ の 相対 位置 を 可視化。

データ ソース 明示

BLS / BEA / 総務省 統計局 等 の 一次 ソース URL を 全 report に 明示。 出典 追跡 可能。

PDF 配布

月次 で PDF report を メール 配信。 過去 report は 会員 ページ で 参照可能 に する 予定。
