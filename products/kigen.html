What Kigen is

「Kigen」 = 期限 を 逆算 する iOS アプリ

「Kigen」 は 期限 の こと。 免許 の 更新 · 保証 の 期限 · サブスク の 継続 · 薬 の 使用 期限 · パスポート · 車検 まで、 生活 で 「うっかり 切らす と 困る 期限」を 一つ の iOS アプリ で 逆算 で 通知 · 管理 します。 App Store で 提供 中 (Free で 基本 機能 が 使用 可能、 Plus プラン ¥600/月 で 拡張 機能)。

Core Features

用途 例

免許 · 保証 · 車検

免許 更新 の 誕生 月 · 保証 の 期限 · 車検 満了 日 · パスポート 期限 を 登録。 期限 が 近づく と 通知 する 設計 で、 郵送 通知 の 見落とし を 補完。

サブスク · 薬 の 期限

使って い ない サブスク の 継続 日 · 開封 済 市販 薬 の 使用 期限 を 登録。 判定 の base として 期限 直前 の 通知 で 「継続 or 解約」「使い切る」の 判断 を 支援。

家族 共有 (Plus)

Plus プラン ¥600/月 で 家族 分 の 期限 を まとめて 管理 · 通知 の 拡張 設定 が 可能。 詳細 · 実 の 仕様 · プライバシー 実装 は App Store の 公式 説明 · アプリ 内 の 設定 を ご確認 ください。
