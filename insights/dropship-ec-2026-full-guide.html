なぜ無在庫 EC か

無在庫 (ドロップシッピング) は 在庫リスク 0、初期投資 数万円、副業層 に 最も 導入 障壁 が 低い EC モデル。 反面 の 課題 = 4 工程 (仕入先 選定 / 出品 / 発注 / CS) を 手動 で 回すと 100 商品規模 で 破綻。 EC-Autopilot は この 4 工程 を 20 の AI エージェント に 自動化 する SaaS。

仕入先 選定 (5 主要 プラットフォーム)

日本国内 の 主要 仕入 は netsea (BtoB 卸)、 スーパーデリバリー、 卸の達人、 TOPSELLER、 ETonet。 商品数 / 手数料 / 発送スピード / 会員費 の 4 軸 で 比較。 EC-Autopilot は 各 API を統一 interface で扱い、 商品 dataset を 一括管理。

出品 (自動化 の 中核)

1 商品 = 商品名 + 説明文 + 画像 + カテゴリ + 価格。 手動で 100 商品 = 20 時間。 AI エージェント で 5 分/商品 に短縮 (画像は仕入元 引継ぎ、 説明文 は AI 生成、 価格 は 需給から自動)。 楽天 / Amazon / メルカリShops / BASE / Shopify 5 platform に一括出品。

価格最適化 (需給 signal)

商品 の 需給 は 検索順位 / 競合価格 / seasonal trend の 3 signal で 判定。 EC-Autopilot の Price agent は 24 時間おき に 再評価、下限 (仕入 + 手数料 + 送料 + 目標粗利) を 保証。 動的価格 で 上乗せ 収益 を 最大化。

注文発注 (冪等化)

注文 → 仕入先 発注 の パイプラインは 冪等化 必須。 Webhook 重複 / 発注失敗 3 回リトライ / 高額 hold (¥30,000 以上) / 高リスク 注文 (規制品目 / 大量注文) の 6 分岐 テスト。 二重発注 = 副業層 の 破産 リスク。

CS の 一次応答

問い合わせ の 80 % は 定型 (発送状況 / 返品 / 商品仕様 / キャンセル)。 AI エージェント で 一次応答 = 3 秒、 回答 精度 90 %+ (fine-tune 後)。 残 20 % は human エスカレ、 承認 flow 経由。 副業層 は 「CS の 深夜対応 が 消える」のが最大 効果。

Stripe SAQ-A 準拠

決済 は Stripe Checkout (SAQ-A 準拠、カード情報 は Stripe が 保管、当社 は 一切 保持しない) を採用。 PCI DSS レベル 1 認定 済 の Stripe を挟むことで 自社 の 監査対象 は 最小 (SAQ-A の 24 質問 のみ)。

特商法 表記 の 自動 生成

EC-Autopilot は 「販売者名 / 事業者住所 / 電話 / メール / 販売価格 / 送料 / 支払方法 / 引渡時期 / 返品条件」の 9 項目 を テナント 情報 から 自動生成。 法令 遵守 の 手間 を 0 に。
