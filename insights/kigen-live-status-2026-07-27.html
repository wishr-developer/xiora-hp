  • 状態: App Store LIVE (審査 済 · 配信 中)

2. 収益 rail の 位置付け

Kigen の 課金 は Apple IAP が primary rail。 App Store で iOS Plus プラン を 契約 する 場合 が 想定 導線。 Stripe web fallback (kigen.xiora-official.com) は 以下 の 想定 で 併設 して いる:

  • App Store 経由 を 使わ ない 選択肢 が 欲しい ユーザー 向け の 代替
  • ブラウザ 経由 で 課金 したい ユーザー 向け の 補助 導線 (App Store IAP を primary 経路 と して 継続)
  • Xiora HP の 導線 統一 (他 SaaS が Stripe payment link を 使用 して いる 中 で、 Kigen のみ App Store 直リンク だと 表示 一貫性 が 崩れる 対策)

2026-07-27 時点 で Stripe rail の Kigen 関連 subscription は 0 件、 実 収益 は Apple IAP 側 で 集計 される (APS Store Connect の 数値 pull は API key 発行 が 前提 の ため、 本 report で は 割愛)。
