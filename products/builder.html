よくある 質問

生成 された 自動化 は どこで 動きますか？

Pro / Team は Xiora Cloud で ホスト します。 Free は 生成 結果 を コピー して 自分 で n8n / Google Apps Script / Vercel / kintone 等 に 置ける 形 で 提供 します。

プログラム を 書けない 私 でも 使えますか？

Free 版 の 目的 は まさに それ です。 日本語 で 書く → 動く URL / 手順 が 手 に 入る、 の みで 完結 します。 詰まる 点 は Pro 以上 で メール 引取 します。

解約 は いつでも できますか？

月単位 で 解約 可能。 作った 自動化 は、 解約後 も 引取 用 の ソース と 手順書 を お渡し します。
