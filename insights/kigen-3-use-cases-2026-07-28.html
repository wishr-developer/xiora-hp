事例 1: 家族 3 人 分 の 免許 を 一箇所 で 管理

家族 3 人 (30 代 夫婦 + 高校生 の 子) の 免許 系 書類 を Kigen で 一元 化 した 事例 です。 免許証、教習所 学生証 (仮免 期間)、原付 免許、資格 系 (英検、簿記) を 対象 に、初期 登録 で 15 分 の 投資 で 3 年 の 更新 忘れ を ゼロ に します。

手順:

  1. Plus プラン に アップグレード (¥600/月、家族共有 が 開放)
  2. Kigen で 家族 招待 → 3 人 分 の アカウント を 束ねる
  3. 各人 が 自分 の 免許 を OCR で 撮影 (1 枚 3 秒)。 種類・有効期限・免許番号 が 自動抽出
  4. 「所有者」タグ を 付ける (父 / 母 / 子)
  5. 期限 3 ヶ月 前 / 1 ヶ月 前 / 1 週間 前 の 3 段階 リマインド を 全員 に 通知

3 週間 使い込んだ 結果:

  • 子 の 仮免許 が 期限 1 週間 前 に 通知 → 通常 なら 気付かなかった 免許 期限 を 事前 に 教習所 予約
  • 父 の 英検 準 1 級 合格証書 の 更新 期限 を 発見 (資格 は 更新 が 不要 な もの が 多い ですが、更新 が 必要 な 語学 系 は 情報 として 明示)
  • 母 の 免許 更新 通知 は 従来 郵便 で 気付いて いた が、Kigen 通知 の 方 が 3 週間 早い こと が 分かり、優良 講習 の スケジュール 調整 が 楽 に なった

この 事例 が 示す こと: 期限 の 情報 は 各人 の 頭 の中 に 分散 して います。 家族 3 人 分 を Kigen に 集約 する だけ で、家庭 内 の 期限 事故 の 半数 以上 が 予防 できる 可能性 が あります。

事例 2: サブスク 月次 棚卸し ¥3,200 削減

個人 で 契約 中 の 12 個 の サブスク (動画、音楽、SaaS、雑誌、フィットネス、ジム) を Kigen で 棚卸し した 事例 です。 「毎月 使って いる 感覚 が ない サブスク」を Kigen の 一覧 画面 で 見える 化 する だけ で、3 個 の 解約 を 決断 できました。

手順:

  1. クレジット カード 明細 を 見ながら、月次 引き落とし の サブスク 12 個 を Kigen に 登録
  2. 各 サブスク に 「次回 更新 日」「金額」「契約 経緯 (なぜ 契約 した か)」を 記録
  3. 「継続 判断 タイミング」を 更新 日 の 7 日 前 に セット
  4. 3 週間 の 使用 頻度 を 手動 で 記録 (使用 回数 0 / 1-2 / 3+)
  5. 月末 の 棚卸し タイム (30 分) で、Kigen 一覧 を 見て 継続 / 解約 を 判断

3 週間 の 結果:

  • 使用 回数 0 の サブスク 3 個 を 発見 (雑誌 サブスク ¥980、音楽 サブスク ¥980、フィットネス アプリ ¥1,240)
  • 合計 ¥3,200/月 = 年間 ¥38,400 の 削減 に 成功
  • Kigen Plus ¥600/月 は 削減額 ¥3,200 の 18% 相当。 実質 ¥2,600/月 の 純粋 な 家計 改善

この 事例 が 示す こと: サブスク の 課題 は 「解約 忘れ」だけ では ありません。 「使って いない こと を 認識 できて いない」が 本質。 Kigen の 一覧 画面 は、その 認識 を 強制 する 装置 として 機能 します。

事例 3: 家庭 常備薬 の 開封後 期限 管理

目薬、軟膏、湿布 の 3 種類 は 開封後 の 使用 期限 が パッケージ に 印字 されて いない こと が 多く、家庭 で 期限 切れ を 起こしやすい 代表 です。 Kigen で 開封日 を 記録 し、開封後 の 目安 期限 (目薬: 1 ヶ月、軟膏: 3 ヶ月、湿布: 6 ヶ月) を リマインド する 事例 です。

手順:

  1. 薬箱 を 全て 取り出し、パッケージ を 1 個 ずつ 撮影 (14 個 → 8 分)
  2. OCR で 未開封 の 有効 期限 が 自動抽出 される 一方、開封後 期限 は 手動 入力 (目薬 30 日、軟膏 90 日、湿布 180 日)
  3. 「開封日」フィールド を 空 のまま 登録 し、実際 に 開封 した 日 に アプリ から 開封日 を 入力
  4. 開封日 + 目安 日数 で 使用 期限 が 自動 計算 され、期限 3 日 前 に リマインド

3 週間 の 結果:

  • 期限 切れ の 目薬 2 本 を 発見 (使用 継続 して いた もの、開封後 3 ヶ月 経過)、医師 相談 の うえ 廃棄
  • 家族 の 花粉症 目薬 の 開封日 を 記録 し始めて 以降、期限 内 消費 の 意識 が 定着
  • 薬局 へ 期限切れ 薬 を 一括 返却 する 「月末 薬 廃棄 日」が 新習慣 に

この 事例 が 示す こと: 薬 の 期限 管理 は 「未開封 の 消費 期限」だけ で なく 「開封後 の 使用 目安」の 2 軸 が 必要 です。 Kigen は 開封日 フィールド と 手動 目安 日数 で この 2 軸 を 記録 でき、家庭 の 薬箱 を 3 週間 で 健全 化 します。

3 事例 の 横断 学び

  1. 初期 登録 の 15-30 分 の 投資 が、3 年 スパン で 数万円 の 損失 予防 に 直結。 ROI は 極めて 高い。
  2. 家族 共有 は Plus プラン の コア 価値。 単独 での 期限 管理 なら 無料 版 で 十分 な 場面 も 多い が、家族 の 期限 を 集約 する 瞬間 に Plus の 費用対効果 が 一気 に 反転 する。
  3. OCR は 万能 では ない。 薬 の 期限 印字 は フォント や レイアウト の ばらつき が 大きく、手動 補正 が 発生 する ケース あり。 逆 に 免許証 系 は フォーマット が 統一 されて おり OCR 精度 が 高い。
  4. On-Device 完結 は プライバシー 上 の 安心感 だけ で なく、機内 モード でも 使える 実利 に 直結。
