What XioraHire is

「求人 出稿 + 応募者 管理 + 一次 選考」を、
SaaS で 一気通貫。

中小企業 の 採用 担当 は 求人 サイト への 出稿 / 応募者 の Excel 管理 / 一次 選考 面談 の 3 段 で 疲弊 しがち です。 XioraHire は これら を SaaS 化 し、更 に 一次 選考 面談 の 代行 (面談 実施 と 記録 の 業務 支援) を Xiora が 受託 する ハイブリッド モデル で 提供予定。 職業紹介 の 有料 斡旋 は 行いません。

Core Features

3 本柱

求人 出稿 統合

Indeed / Wantedly / Green 等 の 主要 求人 サイト への 出稿 を 1 契約 で 統合。 出稿 内容 の AI draft 支援 も 提供。

応募者 管理 SaaS

Excel 管理 を 置き換える 応募者 pipeline SaaS。 選考 段階 / メモ / 面談 記録 を 一元 管理。

一次 選考 代行 (受託)

一次 面談 の 実施 と 記録 を Xiora が 受託 (業務 支援)。 判定 は 契約 企業 が 実施。 有料 職業紹介 では ありません。

職業安定法 準拠

職業安定法 の 有料 職業紹介 事業 に 該当 しない 範囲 で 運営。 契約 内容 は 法務 レビュー 前提 で 準備中。
