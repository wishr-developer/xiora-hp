Nexa Learner Annual (¥19,800/年) と Monthly (¥1,980/月) の 実 差額 · 選択軸 — 27 課程 学び 放題 の 年間 継続 で 得する 3 pattern (2026)

Nexa Learner サブスク の 4 契約 期間 (Monthly ¥1,980 / Quarterly ¥5,640 / Half-Year ¥10,690 / Annual ¥19,800) を 対象 に、 Monthly と Annual の 実 差額 · 割引 率 · 月 換算 を 単純 比較 の 参考 値 と して 整理 し、 27 課程 学び 放題 で 年間 継続 する 場合 の 具体 パターン 3 種 (3 課程 以上 継続 / 資格 · キャリア 準備 期間 / 家族 · 同僚 共有 用途) と Annual に 向か ない 3 pattern を fact-based で 記載 します。 「必ず 得 する」表現 は 使わず、 選択 軸 の 判断 材料 を 提示 する 情報 整理 で す。

Nexa Learner 4 tier の 価格 tab (Monthly / Quarterly / Half-Year / Annual)

Nexa Learner サブスク の 4 契約 期間 は 以 下 の 参考 値 で 提供 予定 です (税込 · 2026 年 8 月 現在)。 (1) Monthly ¥1,980 / 月 = 短 期 · お 試し 帯。 (2) Quarterly ¥5,640 / 3 ヶ月 — Monthly ×3 = ¥5,940 と の 単純 差額 は ¥300 (約 5% off の 参考 値)。 (3) Half-Year ¥10,690 / 6 ヶ月 — Monthly ×6 = ¥11,880 と の 単純 差額 は ¥1,190 (約 10% off の 参考 値)。 (4) Annual ¥19,800 / 年 — Monthly ×12 = ¥23,760 と の 単純 差額 は ¥3,960 (約 16.6% off の 参考 値、 月 換算 ¥1,650)。 いずれ も 契約 期間 途中 の 解約 · 月 単位 返金 の 可 否 は 契約 条件 に 準じる ため、 事前 に 特商 法 表記 · pricing ページ の 記載 を ご 確認 ください。

Annual (¥19,800) の 実 差額 計算 と 割引 率

Annual ¥19,800 と Monthly 12 ヶ月 分 ¥23,760 (¥1,980 × 12) の 単純 差額 は ¥3,960 で 、 割引 率 は 約 16.6% (小数 点 以下 は 切り 捨て 参考 値) と なります。 月 換算 で は ¥19,800 ÷ 12 = ¥1,650 / 月 相当 と なり、 Monthly ¥1,980 との 差 は 1 ヶ月 あたり ¥330 で す。 「2 ヶ月 分 free 相当」と 表現 する 場合 は 「¥3,960 ÷ Monthly ¥1,980 = 2.0」に 基づく 単純 比較 の 参考 値 で あり、 「必ず 2 ヶ月 分 得 する」保証 で は ありません。 実 際 の 経済 メリット は、 12 ヶ月 継続 · 学習 継続 · サービス 継続 が 前 提 と なる 点 に ご 留意 ください。 途中 で 学習 を 停止 した 場合、 Annual の 未 使用 期間 分 が 「差額 メリット」を 相殺 し得 ます。

Pattern 1: 3 課程 以上 を 年間 通して 継続 する 人

1 課程 集中 → 完了 → 次 課程 を 年間 で 3-5 課程 進める 学習 者 は、 Annual の 差額 参考 値 と 相性 が 合い やすい 目安 で す。 例 えば 「Q1: プログラミング 基礎、 Q2: データ 分析 入門、 Q3: プロジェクト マネジメント、 Q4: ビジネス 英語」の 4 課程 想定 で 12 ヶ月 使う 場合、 月 換算 の 実 費 が ¥1,650 に 抑え られる 参考 値 と なります。 27 課程 学び 放題 の 特性 上、 単一 課程 だけ で なく 「複数 課程 を 横 断 で 進める」使い 方 を 想定 する 場合、 Annual の 選択 軸 が 立ち やすく なります。 但し、 学習 継続 は 個人 の 状況 に 依存 し、 3 課程 完了 を 保証 する もの で は ありません。

Pattern 2: 業務 資格 · キャリア シフト の 6-12 ヶ月 準備 期間 に 使う 人

資格 試験 · 転 職 · 新 領域 へ の キャリア シフト の 準備 で 「6-12 ヶ月 の まとまった 学習 期間」を 想定 する 学習 者 は、 Half-Year (¥10,690) · Annual (¥19,800) の どちら か の tier で 事前 予算 化 する 選択 軸 が 立ち やすい 傾向 が あります。 例 えば 「基礎 課程 3 ヶ月 → 応用 課程 3 ヶ月 → 実践 課程 3 ヶ月 → 総 復習 3 ヶ月」の 12 ヶ月 想定 で は Annual、 「集中 準備 6 ヶ月」で 完了 想定 の 場合 は Half-Year が 実 使用 期間 と の gap が 少ない 目安 で す。 資格 合格 · 転 職 成功 · 昇 給 は 個人 の 実 力 · 面接 · 市場 環境 に 依存 し、 コース 受講 で 保証 される もの で は ありません。

Pattern 3: 家族/同僚 で 共有 する 用途 (規約 の 原則 に 触れる)

「家族 · 同僚 で 1 契約 を 共有 したい」と の ニーズ は 一定 存在 します が、 Nexa Learner サブスク は 1 ID = 1 人 の 個人 利用 が 契約 の 原則 で ある 点 を 事前 に ご 確認 ください。 家族 · 同僚 で 学習 する 場合 は、 (a) 各自 が Monthly / Annual を 契約 する パターン、 (b) 将来 提供 予定 の 家族 · 法人 プラン を 待つ パターン、 (c) 個別 に お 問い合わせ 上 で 検討 する パターン、 の 3 目安 が 参考 と なります。 1 ID を 複数 人 で 共有 する 使い 方 は 契約 違反 · アカウント 停止 の リスク が 発生 し得 る 点 に ご 留意 ください。 詳細 は Nexa Academy 特商 法 表記 · 利用 規約 を ご 確認 ください。

Annual に 向か ない 3 pattern

公平 な 判断 材料 と して、 Annual (¥19,800) が 選択 軸 と 合い にくい 3 pattern を 併記 します。 (1) 学習 対象 が 1-2 課程 未満 で 短 期 完了 想定 の 場合 — 月 数 が 少なく 差額 メリット を 得 にくい 目安 で 、 Monthly か Quarterly が fit する ケース が あります。 (2) 3 ヶ月 以内 の 短 期 集中 用途 — Quarterly ¥5,640 の 方 が 実 使用 期間 と gap が 少ない 参考 値 と なります。 (3) 学習 習慣 が 未 確立 の 段階 — まず Monthly で 継続 可 否 を 確認 し、 3 ヶ月 継続 後 に Half-Year · Annual へ の 切り 替え を 検討 する 段階 導入 が 損失 リスク を 抑える 目安 で す。 いず れ の 場合 も、 個人 の 学習 状況 · 生活 状況 · 収入 状況 に 依存 する 判断 で す。
