プラットフォーム 4 択 の 意味

副業 EC の 出品先 は 大きく 4 択: (1) 大型 マーケット (メルカリShops / ヤフー) (2) 独自 URL (Shopify / BASE)。 前者 は 集客 力 が 強 / 手数料 高、 後者 は 独自 ブランディング 可 / 集客 は 自力。 選択 は 「自社 の 集客 力」で決まる。

メルカリShops (副業 の 王道)

商品検索 の 集客 が 強 (メルカリ 月間 2000 万 UU)、 販売手数料 10 %、 決済手数料 0 % (メルカリ支払い)、 API 開放 部分的 (公式 API + 3rd party)。 副業 開始 の 第 1 候補。 EC-Autopilot は メルカリShops API 経由 で 出品 / 在庫連携 自動化。

ヤフーショッピング (中規模 の 王道)

販売手数料 0 %、 ストア開設料 0 円、 決済手数料 3.24 %、 プロモーション 費 が 追加 発生。 API 開放 (RakutenMWS 相当 の EasyPay)、 中規模 EC (月商 100 万円 - 1000 万円) 向け。

Shopify (独自 ブランディング)

販売手数料 0 %、 月額 $29-299 (プラン別)、 決済手数料 3.4 % (Shopify Payments 経由)、 App Store 8000+ の 拡張 性。 独自 ブランディング を 重視 する EC。 集客 は 自力 (SEO / 広告 / SNS)。

BASE (簡単 に 始める)

販売手数料 3 % + 決済手数料 3.6 %、 月額 0 円 (Basic プラン)、 API 開放 部分的、 App 300+。 SNS 連携 と 「かんたん決済」が 強 み、 個人 の 小規模 EC (月商 10 万 - 100 万) 向け。

EC-Autopilot の 4 platform 一元管理

各 platform の API を 統一 interface に 抽象化、単一 dashboard から 出品 / 在庫 / 注文 / CS を 管理。 platform 追加 は EC-Autopilot 側 で 対応 済 = ユーザー は 「メルカリShops + Shopify」等 の 併用が 1 契約 で 可能。

在庫 の 同期 問題

無在庫 の 場合 は 仕入元 の 在庫 変動 が 発生。 各 platform に 「在庫あり」で 出品 したが 発注時 に「在庫切れ」= キャンセル 対応 = 顧客満足度 低下。 EC-Autopilot は 仕入元 の 在庫 API を 5 分毎 poll、 変動 発生 時 に 全 platform の 在庫 を 即 同期。

手数料 の 総合比較

月商 100 万円 の 場合、 メルカリShops = 手数料 10 万円 (販売 10 %)、 ヤフー = 手数料 3.24 万円 (決済 のみ) + プロモ 費、 Shopify = 手数料 3.4 万円 (Shopify Payments) + 月額 $29-299、 BASE = 手数料 6.6 万円 (販売 3 % + 決済 3.6 %)。 単価 / 集客 依存度 で 選ぶ。
