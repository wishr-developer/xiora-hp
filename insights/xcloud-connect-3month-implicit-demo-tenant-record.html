Introduction

XCloud Connect は 中小企業 の 情シス代行 + SaaS 保守 を 受託する Xiora の プラットフォーム。 過去 3 ヶ月 の implicit demo tenant 運用 + Restaurant OS shadow 事例 を 情報整理します。

「implicit demo tenant」 = 正式契約前の 潜在顧客 を 想定した 内部 shadow tenant。 実顧客 データ は 使わず、Xiora 内部 の 模擬 tenant で 保守 workflow を 継続 dogfood。

XCloud Connect の 3 プラン

Basic ¥3,300 / 月: 月次 1 回 の 死活確認 + SSL 期限 監視 + 基本 SaaS (Slack / Notion / Zoom) 設定 サポート。

Business ¥16,500 / 月: Basic + 月次 2 回 の 対応 + 情シス 代行 (パスワード リセット / 権限管理 / VPN トラブル)。

Enterprise 個別見積: 上記 + 24/7 監視 + Xiora AI エージェント による 自動一次対応 + 月次 レポート。

Implicit demo tenant で 検証した 3 workflow

workflow 1: SSL 期限 監視 + 更新 サポート。 dummy 証明書 3 種 (Let's Encrypt / Cloudflare / Vercel 自動) を 期限 30 日前 に 検知、通知 テンプレ + 更新手順 の 事前準備。 3 ヶ月間 で 12 回 検知 → 全 dummy 更新 success。

workflow 2: SaaS 権限 レビュー。 dummy Slack / Notion / GitHub workspace の 権限 (member / admin / guest) を 週次 スキャン、退職者 想定 の 権限剥奪 workflow を 検証。 3 ヶ月で 週次 12 回 全成功。

workflow 3: 情シス 代行 チャット 一次対応。 内部 従業員 想定 の チャット 質問 (VPN 接続不能 / パスワード 失念 / SaaS 招待方法 等) を Xiora AI エージェント が 一次 draft、代表 が 承認 後 送信。 3 ヶ月で 168 件 対応、承認率 81%。

Restaurant OS shadow 事例

Xiora が 別途運用する Restaurant OS (飲食店向け業務システム) を XCloud Connect の Enterprise plan shadow として 3 ヶ月 運用。

SSL 期限 更新 3 回、監視アラート 45 件 (うち 誤検知 8 件、実問題 37 件、平均 対応時間 4.2 時間)、SaaS 権限 レビュー 12 回 全成功。

この shadow 運用 は 実顧客 契約 では 無く、Xiora 内部 dogfood。 正式 顧客 導入時 の workflow 品質 保証 の 前提として 継続。

3 ヶ月で 見えた 3 学び

学び 1: 中小企業 の 「情シス 常駐 が 居ない」問題 は 深刻。 月 ¥3,300-¥16,500 の 保守料 で 常駐相当 の 安心感 を 提供できるのが 差別化 点。

学び 2: SaaS の 権限管理 は 「退職者 権限剥奪 の 漏れ」が 最大リスク。 週次 レビュー の 定型化 が 効く。

学び 3: AI 一次対応 の 承認率 81% = 5 件 中 4 件は AI draft で 解決可能。 代表 の 対応時間 が 75% 削減。

次 phase

3 ヶ月 の shadow record を 基に、正式 顧客 (中小企業 5-10 社) の Enterprise plan 導入 を 段階的に 進める予定。

料金 tier 見直し (Business ¥16,500 → ¥22,000 を 検討) と、Xiora AI エージェント による 24/7 一次対応 の 提供時間帯 拡張 (現在 9-21 時 → 24/7) を 計画。
