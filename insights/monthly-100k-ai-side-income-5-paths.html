Path 1 — マーケットプレイス出品 (Coconala / Lancers / CrowdWorks)

難易度: Low。 時間投下: 1 出品 あたり 20-40 分、9 出品 で 3-6 時間。 月 revenue 目安: ¥30k-¥180k。

コンサル / SEO ライティング / 動画編集 の 3 カテゴリ × 3 platform = 9 出品 で 露出面 を 分散する 戦略。

Xiora も Coconala / Lancers / CrowdWorks 3 platform × 3 カテゴリ で 9 listing を submit-ready 状態に 整えており、pricing tier band は 各 platform の 中堅 band 下限 (¥5,000-¥15,000) に配置。

レビュー 3.5+ 維持 と 継続 case-study 蓄積 が 6 ヶ月後 の tier up 条件。

Path 2 — 特化型 SEO ブログ + アフィリエイト

難易度: Mid。 時間投下: 記事 1 本 あたり 2-4 時間 × 週 1-2 本 = 月 8-16 時間。 月 revenue 目安: ¥10k-¥50k (半年後)、¥30k-¥200k (1 年後)。

Xiora HP insights の 30+ 記事 の 実運用録 から 見ると、SEO 記事 の 収益化は 「業種特化 + 単価高 keyword」 に 絞ると 継続性 高い。

月 ¥10 万 を 狙うなら 単価 ¥3,000-¥10,000 の アフィリ商材 (SaaS 紹介 / IT 教材 / DX 支援 サービス) を 選ぶのが 現実的。

Path 3 — AI 動画配信 (Aiverse Studio 型)

難易度: Mid。 時間投下: 週 5-10 時間 の 配信 + 準備。 月 revenue 目安: ¥5k-¥30k (半年後)、¥30k-¥300k (1 年後、リスナー数 依存)。

AI VTuber / AI ライバー 領域 は 2026 時点 で 配信技術・音声 合成 が 成熟し、個人 参入 の 障壁 が 大きく下がった。

Xiora の Aiverse Studio (M1a ウェイトリスト受付中) は 単独クリエイター 向け Creator プラン (月額 ¥1,650) から 参入 可能。

Path 4 — B2B 研修 講師 (Nexa Academy 型)

難易度: High。 時間投下: 準備 20-30 時間 + 講義 1 回 4 時間。 月 revenue 目安: ¥50k-¥300k (1 社 貸切 の 単発 講義)。

「AI 実務 (Claude Code / Cursor / ChatGPT 業務活用)」を 教える B2B 研修 の 講師 単価は 4 時間 で ¥50,000-¥300,000 が 相場。

月 1-2 件 でも 月 ¥10 万 到達 可能、経験値 蓄積 と 顧客リスト形成 で 半年後 単価 up が 現実的。

Xiora も Nexa Academy を通じて 中小 IT サービス 会社 向けに 「Claude Code + Cursor 3 週研修」 パッケージ を 展開中。

Path 5 — AI 業務 委託 (エンジニア / ライター / 動画 編集)

難易度: Mid-High。 時間投下: 月 20-40 時間。 月 revenue 目安: ¥50k-¥200k。

Wantedly / Green / YOUTRUST 等の 副業 マッチング platform で 「AI 実装 経験者 副業」 の 案件 が 継続増加。

時給 ¥3,000-¥8,000 × 週 5-10 時間 で 月 ¥60k-¥300k が 現実的。

Xiora の 実運用録 から 見ると、Claude Code + Cursor の 実務スキル (Lv3 Advanced 以上) が 単価 up の 分岐点。

5 path の 難易度 x 継続性 比較

難易度 Low × 継続性 High = Path 1 (マーケットプレイス出品)、Path 2 (SEO ブログ)。 初動 6 ヶ月 の 種まき が 必要。

難易度 Mid × 継続性 Mid = Path 3 (AI 動画配信)。 リスナー 定着 が 分岐点。

難易度 High × 継続性 High = Path 4 (B2B 研修)、Path 5 (AI 業務委託)。 実務スキル と 実績 が 蓄積 されると 単価 が 上昇。
