Blender で 3DCG を学ぶ書籍 5 選 — Xiora の 3D pipeline 実運用ノートから (2026)

Xiora では、映像・広告用 3D アセットを Blender + Substance で回す社内 pipeline を持っています。 3DCG は学習曲線が急峻で、YouTube チュートリアルの断片だけでは章横断の設計が身につきにくく、書籍による体系学習が結果として時間短縮になります。 本記事では、Xiora の運用で章単位に参照した Blender 系書籍 5 冊を、実務トピック (モデリング / UV / テクスチャ / ライティング / 演出) に紐付けて紹介します。

1. Blender 総合入門書 (基礎トポロジー章が要)

「Blender ではじめる」「Blender 3DCG モデリング・マスター」系の総合入門書は、初期の UI 学習だけでなく「エッジフロー」「N-gon 回避」「ミラー・サブディビジョンの効かせ方」など基礎トポロジーの章が実運用に直結します。 Xiora は agent 経由でモデルを生成する時の「acceptable topology のチェックリスト」を本系書籍の章単位で明文化しました。 楽天ブックスで「Blender 入門」で検索できます。

楽天ブックスで「Blender 入門」を検索する

2. UV 展開 / テクスチャベイクの実務書

UV は生成 AI との相性で言うと事故りやすい領域で、シームの位置・展開比率・padding の設計を書籍で標準化しておかないと、テクスチャベイクで gap が出ます。 「Substance Painter」「PBR テクスチャ」系の書籍を、Xiora は agent への「UV shell の配置ルール」の下地として参照しました。 楽天ブックスで「Substance Painter」「PBR テクスチャ」で検索できます。

楽天ブックスで「Substance Painter」を検索する

3. PBR / マテリアル設計の書籍

PBR (Physically Based Rendering) は「roughness / metallic / normal / AO」の 4 マップを扱うだけでなく、「値そのものの物理的意味」を理解しないと画が崩れます。 「Physically Based Rendering: From Theory to Implementation」「The PBR Guide」邦訳版系を、Xiora は agent が material 値を提案する際の validation ルール (roughness の 0.02 以下は基本使わない、metallic は 0/1 の 2 値運用に近い等) の根拠として参照しました。 楽天ブックスで「PBR」「Physically Based Rendering」で検索できます。

楽天ブックスで「PBR レンダリング」を検索する

4. ライティング / コンポジションの書籍

3 点照明・key/fill/rim の役割・カラーテンパチャの選び方は、映像でも 3DCG でも共通する設計論です。 「Light for Visual Artists」「Painting with Light」系の書籍を、Xiora の agent には「照明配置の初期案は 3 点照明から始めよ」「rim light の色温度は key と 1000K 以上ずらせ」というルール化を反映しています。 楽天ブックスで「ライティング デザイン」「照明設計」で検索できます。

楽天ブックスで「ライティング デザイン」を検索する

5. 演出 / Shot Language の書籍

ショットの設計 (アングル / 焦点距離 / カメラ動き) は、モデル・マテリアルの完成度と同等に画のクオリティを決めます。 「Cinematography Theory and Practice」「The Filmmaker's Eye」系の書籍を、Xiora は agent への shot language 語彙付与に使い、レンダー前の camera プリセットの初期候補生成に反映しています。 楽天ブックスで「撮影 演出」「Cinematography」で検索できます。

楽天ブックスで「Cinematography」を検索する
