キャリアシフト 準備 期間 の 学習 needs

キャリア シフト 準備 の 学習 needs は 大 別 で 4 phase に 分類 され ます。 (1) 目標 業界 · 職種 の リサーチ · 課程 選定 (1-2 週)。 (2) 基礎 学習 (1-3 ヶ月)。 (3) 応用 · 実務 学習 (3-6 ヶ月)。 (4) 実 践 · 転職 活動 · 独立 準備 (6-12 ヶ月)。 各 phase の 学習 内容 が 異なる ため、 単一 課程 で は 不足 する 傾向 が あり、 27 課程 学び 放題 (2026-07-31 時点 · 順次 拡充) の 幅 広い 課程 群 を 横 断 で 使う 選択 軸 が 立ち やすい 目安 で す。 事業 者 と して の 学習 投資 予算 の 単位 に Annual を 組み入れ る 判断 材料 と なります。

Phase 1: 目標 業界 · 職種 の 課程 選定 (1-2 週)

1 phase 目 は 目標 業界 · 職種 の リサーチ と 課程 選定 で す (1-2 週 目安)。 転換 先 の 職種 で 求め られる スキル 領域 (プログラミング / データ 分析 / プロジェクト マネジメント / ビジネス 英語 / マーケティング 等) を 業界 求人 情報 · 業務 記述 書 · 現 職 者 の 情報 発 信 から 洗い 出し、 Nexa Learner 27 課程 (2026-07-31 時点 · 順次 拡充) の 中 で 該当 課程 を 3-5 個 選定 する 段階 で す。 Annual 契約 前 に 課程 一覧 を 事前 確認 し、 該当 課程 が 十分 に 存在 する か 判断 する こと で 学習 期間 の 無駄 を 減らせる 目安 で す。

Phase 2: 基礎 学習 (1-3 ヶ月)

2 phase 目 は 基礎 学習 期間 (1-3 ヶ月 目安) で す。 転換 先 の 職種 の 前 提 知識 · 用語 · 基本 概念 を 課程 1-2 個 で 習得 する 段階 で 、 平日 30-60 分 + 週末 2-3 時間 の 学習 pace が 一般 的 な 参考 目安 と され ます。 個人 の 生活 状況 · 現 職 の 負荷 · 家族 状況 に 依存 する ため、 実 pace は 個別 で 調整 が 必要 で す。 基礎 phase で 学習 継続 が 困難 と 感じる 場合、 Annual 契約 の 「12 ヶ月 使い 切る」前 提 が 崩れる リスク が あり、 Phase 3-4 へ 進む 前 の 判断 point と なります。

Phase 3: 応用 · 実務 学習 (3-6 ヶ月)

3 phase 目 は 応用 · 実務 学習 期間 (3-6 ヶ月 目安) で す。 基礎 phase で 得た 用語 · 概念 を 元 に、 実務 で 使う ツール · プロセス · 事例 分析 を 課程 2-3 個 で 深める 段階 で す。 業界 実務 スキル の 習得 度 は 個人 の 学習 履歴 · 前 職 経験 · 練習 量 に 依存 し 、 「N 時間 学習 = 実務 適応 可能」の 保証 は ありません。 応用 phase で ポートフォリオ · 副 業 · 業界 コミュニティ 参画 等 の 実践 経験 を 並列 で 進める 場合、 学習 単独 より 転換 期間 の 短縮 に 寄与 する 傾向 が あります (個別 状況 に 依存)。

Phase 4: 実践 · 転職 活動 (6-12 ヶ月)

4 phase 目 は 実践 · 転職 活動 · 独立 準備 期間 (6-12 ヶ月 目安) で す。 応用 phase で 得た スキル を 元 に、 実 案件 · 副 業 · 転職 面接 · 独立 準備 (事業 計画 · 開業 手続き 等) を 進める 段階 で す。 Nexa Learner の 課程 は 面接 準備 · プレゼンテーション · プロジェクト マネジメント 等 の 「実践 段階 で 併用 する 課程」も 含まれ ます (2026-07-31 時点 · 順次 拡充)。 転職 成功 · 独立 収益 発生 · 面接 通過 は 個人 の 実 力 · 業界 需給 · 面接 官 判断 に 依存 し、 コース 受講 で 保証 される もの で は ありません。

Annual に 向か ない 3 pattern (継続 意思 不安定 / 3 ヶ月 以内 短 期 / 単発 資格 対策)

公平 な 判断 材料 と して、 キャリア シフト 用途 で Annual (¥19,800) が 向か ない 3 pattern を 併記 します。 (1) 学習 継続 意思 が 不安定 な 段階 — まず Monthly ¥1,980 で 1-2 ヶ月 継続 可 否 を 確認 し、 3 ヶ月 継続 後 に Annual 切り 替え を 検討 する 段階 導入 が 損失 リスク を 抑える 目安 で す。 (2) 3 ヶ月 以内 の 短 期 集中 用途 — Quarterly ¥5,640 の 方 が 実 使用 期間 と gap が 少ない 参考 値 と なります。 (3) 単発 資格 対策 のみ の 用途 — 該当 資格 対策 が Nexa 課程 で 直接 提供 されて いる か 事前 確認 が 必要 で 、 該当 が 少ない 場合 は 資格 専門 の 個別 教材 が fit する 場合 が あります。 いず れ も 個人 の 学習 状況 · 生活 状況 · 収入 状況 に 依存 する 判断 で す。
