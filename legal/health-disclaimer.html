健康・医療 免責事項 (Kigen App)

Xiora が提供する Kigen App (以下「本サービス」といいます) に関する 健康・医療分野の 免責事項を以下のとおり定めます。

1. 本サービスの位置付け

Kigen App は、市販薬・処方薬・サプリメントの 服用期限 (使用期限) の 管理を 支援するための 生活支援ソフトウェア です。 医薬品医療機器等法 (薬機法) に定める 医療機器・医薬品には 該当しません。

2. 医療行為ではないこと

本サービスは、以下の 行為を 提供するものではありません。

  • 診断、治療、疾病予防、症状の緩和
  • 特定の医薬品の 使用推奨、代替薬の 提案
  • 医師・薬剤師 による 診療・服薬指導 の 代替

体調に不安がある場合、または 服薬に関する 疑問がある場合は、必ず 医師 または 薬剤師 にご相談ください。

3. 情報の正確性

本サービスは、市販薬パッケージ に印字された 使用期限 の 読み取り、ユーザー入力による 保管情報 に基づく リマインダー 機能を 提供します。 印字の 読み違え、入力ミス、印字劣化 等の理由で 実際の使用期限と 表示内容が 相違する可能性があります。

服薬前には 必ず 実物パッケージ の 使用期限 を ご確認ください。

4. 損害の免責

本サービスの 情報 または 通知の 利用・不利用 に起因する いかなる 健康被害・財産損害についても、当社は 一切の 責任を負いません。

5. アレルギー・副作用

医薬品には 副作用・アレルギー 反応のリスクがあります。 本サービスは 副作用情報 の 提供を目的としておりません。 副作用・アレルギーに関する 情報は 医薬品添付文書、または 医師・薬剤師 にご確認ください。

6. 未成年・妊婦・授乳婦

未成年 (18 歳未満)、妊娠中・授乳中の方は、市販薬の 服用について 医師 の 助言を 優先してください。 本サービスは これらの方の 服薬判断を 代替するものではありません。

7. 個人情報の取り扱い

本サービスに登録された 医薬品情報 (品名、購入日、使用期限、服薬メモ等) は プライバシーポリシーに従って取り扱います。 医療情報として第三者に提供することはありません。
