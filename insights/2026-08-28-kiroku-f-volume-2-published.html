Vol 2 の 内容

『クビになった俺の《記録:F》』 Vol 2 を Amazon Kindle (KDP) で 発売開始 し ました。 副題 は 「SS ランク の 霧 を 制御 せよ 三人目 の 弟子・浅霧渚 と 《転写》 の 風祭颯飛」。 第二章 完結 + 橋渡し 特別 編 まで 収録 の 構成 です。

Vol 1 で 育成 型 主人公 として 走り出し た 蓮 が、SS ランク の 霧 という 上位 の 「観測 不能」 な 現象 に 対峙 し、単に 記録 する だけ で は 突破 でき ない 領域 に 踏み込む 巻 です。 三人目 の 弟子 として 浅霧渚 が 加入、《転写》 スキル を 持つ 風祭颯飛 が シリーズ 上位 の 敵 側 の 象徴 として 立ち上がる 展開 です。

シリーズ の 位置づけ

Writer Studios は、Xiora の 出版・IP 展開 事業 として、SaaS / AI Agent 事業 と 独立 した 収益 pillar を 目指し て い ます。 Vol 1 は 「Writer Studios が 販売 中 の 実 IP を 持つ 事業 に 移行 し た 節目」 でし た。 Vol 2 は 「シリーズ 型 IP として 継続 供給 でき る 体制 の 実 稼働 開始」 の 節目 です。 巻数 が 積み上がる こと で、単発 型 で は 得 られ ない 「シリーズ 買い の テール」 が 資産 化 さ れ 始め ます。

Amazon で の 探し方

Amazon Kindle Store で 検索 キーワード 「クビになった俺の 記録F」 で ヒット し ます。 Vol 1 / Vol 2 が 同 シリーズ として 並ぶ 予定 です。 KDP の 反映 タイミング の 関係 で、公開 直後 は 検索 に 出る まで 最大 72 時間 程度 かかる 場合 が あり ます。 その 場合 は 少し 時間 を 置い て 再度 検索 し て み て ください。

Vol 3 以降 の 予告

Vol 3 以降 は、SSS クラス 覚醒、新興 dungeon へ の 挑戦、弟子団 の 再編 と 《記録:F》 スキル 自体 の 限界 突破 を 描く 三 章 に 入っ て いき ます。 Writer Studios の 継続 目標 は 「四半期 に 1 巻 以上 の 新刊 リリース」。 Vol 1 / Vol 2 の 販売 動向 を 見 な がら、続巻 の 展開 順、外伝、二次 IP 展開 の タイミング を 判断 し て いき ます。

Xiora 事業 map の 中 の 意味

Writer Studios は、Xiora の 20+ プロダクト の うち 「非 SaaS」 の 収益 pillar として 位置づけ て い ます。 SaaS は 月次 課金、書籍 IP は 単発 購入 と 長期 の テール、AI エージェント 事業 は 労働 代替 と、それぞれ 異なる 収益 プロファイル を 組み合わせ て、単一 事業 依存 を 避ける 設計 です。 Vol 2 の リリース は、書籍 IP が 「単発 の 実 販売」 から 「シリーズ の 継続 供給」 へ 移行 し た 意味 が あり ます。
