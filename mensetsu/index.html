Xiora 面接質問ジェネレーター

役職 + レベル + 要件 を 入力 → STAR (Situation-Task-Action-Result) 準拠 の 10-12 質問 + red flag + follow-up 質問 が 60 秒 で 生成。 SMB 採用担当 / 個人事業主 の 初回採用 の 「感覚判断」を 客観指標 に置換。

採用差別に該当する 質問 は 除外
本ツール は 職業安定法 5 条 の 4 / 雇用対策法 に 沿って、 出身地 / 家族 / 宗教 / 支持政党 / 病歴 (業務上必要 除く) 等 の 差別的質問 は 生成 しません。 出力された 質問 は 貴社 の 採用ポリシー に照らして 最終判断 してください。

使い方

  1. Anthropic API key を 取得 (console.anthropic.com)
  2. 下記 に 貼付 (localStorage 保存)
  3. 役職 / レベル / 期待要件 を 入力
  4. 「質問セット生成」→ 60 分面接用 10-12 質問 が返る

Xiora サーバー は key を 一切 受信 しません、 直接 Anthropic API に 送信。

よくある質問



Q. HRMOS を すでに 使っています。 併用可能?


A. はい、 独立ツール なので併用可能。 HRMOS で 応募者管理 + 本ツール で 質問セット 生成 が 一般的な 使い方。



Q. 差別禁止 質問 は 本当に 出力 されない?


A. 職業安定法 5 条の 4 に 沿って、 プロンプト側 で 「出身地 / 家族 / 宗教 / 支持政党 / 病歴 (業務上必要 除く) 等 の 差別的質問 は 除外」を 明示。 生成後 の 目視 確認 は 推奨。



Q. Xiora サーバー に 要件 が送信 されますか?


A. いいえ。 browser から Anthropic API に 直接 送信。 Xiora サーバー は 一切 受信 しません。



Q. 面接官 の 経験不足 でも 使える?


A. はい、 STAR (Situation-Task-Action-Result) 型 は 初心者 面接官 向け の 世界標準。 質問 + follow-up + red flag が セット で 出るので、 面接中 の 「次 何 聞く?」に 対応可能。
