結論 先出し

SaaS 起業 で 詰まる の は アイデア や コード では なく、 「LP + 決済 + SEO + 記事 + 商品 一覧 + outbound」 を 揃える 準備 の 手間 (半日〜数日)。 Xiora Factory は spec JSON 1 枚 で 一式 を 30 秒 で 生成 する 内部 CI。 fabrication 防止 の ため テンプレ 置換 は 決定的、 LLM は 使わない。

1. なぜ 決定的 な テンプレ 置換 に した か

LLM 生成 の LP は 精度 の バラツキ が 大きく、 事務 レベル で は 「毎回 見直し」 が 必要 に なる。 Xiora Factory は 出力 の 再現性 を 最優先 し、 テンプレ 内 の {{VARIABLE}} を spec で 置換 する 方式 に した。 LLM は spec を 書く 段階 で 使える (spec draft を Xiora Builder に 投げる など)。

2. 何 を 一式 で 出力 する か

  • LP HTML (breadcrumb / OG / JSON-LD / GA4 埋込 まで)
  • Insights 記事 HTML (SEO 目的、 canonical / schema.org 付)
  • sitemap.xml patch
  • products/index.html への カード 挿入 + nav 一覧 追加
  • outbound メール テンプレ (spec の 内容 に 応じて 差込 済)

3. ドッグフード 記録

2026-09-27: Shigyo AI Workbench (士業 事務所 向け) を spawn。 生成物 は そのまま prod に push、 手直し は 5 分 未満。 2026-09-28: Xiora Factory 自身 の LP を Factory で spawn (この 記事 も Factory 生成)。

4. spec の 書き方

spec は フラット な JSON で、 name / tagline / description / features / pricing / faq / cta を 埋める だけ。 詳細 は services/systems/XioraFactory/specs/ 配下 の 実例 を 参照。 Beta 期間 は spec draft を Xiora が 一緒 に 埋める サポート を 提供 する。

5. 次 の 拡張 予定

  • Stripe Payment Link 自動 発行 (spec の pricing から)
  • 独自 ドメイン CNAME + Vercel deploy 自動
  • Xiora Builder と の 連携 (spec draft を 日本語 から 生成)
  • OG 画像 自動 生成 (Cloudflare Image Resize + テンプレ)
