What's inside

含まれる もの

  • Next.js 16 (App Router) frontend scaffold — layout / auth pages / dashboard / pricing / Stripe checkout redirect
  • FastAPI (Python 3.12) backend — REST + async job worker + Postgres 16 asyncpg 接続 pool
  • Postgres 16 schema (users / sessions / subscriptions / stripe_events / audit_log) + migration script
  • Stripe webhook receiver (checkout.session.completed / customer.subscription.updated / invoice.paid の 3 event 処理 完動)
  • scrypt 版 session (node scrypt + jose JWT cookie、 Supabase Auth 依存 なし)
  • Docker Compose (dev + prod) + GitHub Actions CI + Cloudflare Pages / VPS 両対応 の deploy script
  • 設定 サンプル .env.example (Stripe key 3 種 · Postgres URL · 送信 Gmail SMTP)
  • README.md 8,000 字 (setup · migration · webhook 疎通 test · 本番 化 checklist)

Where to use

使い どころ

  • 単独 founder / 副業 SaaS の MVP を 1 週間 で LIVE 化 したい 場合 の base
  • Supabase / Firebase 等 の 有料 依存 を 避けて Postgres direct で 開発 したい 場合
  • Stripe subscription を 早く 動かしたい が webhook 実装 の pitfall を 全部 避けたい 場合 (idempotency · signature 検証 · event_id 重複)
  • Next.js 16 App Router の 最新 仕様 に 沿った SaaS の 参考 実装 が 欲しい 場合
  • Docker Compose で local dev + VPS prod を 両方 動かしたい 場合
