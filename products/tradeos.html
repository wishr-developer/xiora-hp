TradeOS.
分散した投資 tool を、1 つに。

個人投資家のためのポートフォリオ管理 + マーケットダッシュボード + 自作ルール alert を統合。
Excel + iSpeed + Yahoo Finance + Google スプレッドシート の分散を解消します。
金融商品取引法上の投資助言業には該当させない情報 tool として設計。

Phase 2 (SaaS) の案内を受け取る 機能を見る

What TradeOS is

"投資判断は自分で"、
"整理と監視は tool で"。

特定銘柄の売買推奨・target price 提示は行いません (投資助言業に該当しない設計)。
市場データ表示・portfolio 記録・自作 alert・過去取引の振り返りに特化した情報 tool です。

Core Features

4 つの standard 機能

ポートフォリオ横断表示

SBI / 楽天証券 / bitFlyer 等の broker を横断してポジションを 1 画面に。JP 株・US 株・crypto・FX・投信を統合。

マーケットダッシュボード

日経平均・S&P 500・USD/JPY・BTC/USD 等を TradingView public widget で埋め込み表示。

自作ルール alert

「価格が閾値を上下抜けたら通知」等のルールを自分で設定。Phase 2 で brain runtime + LINE 通知に統合。

過去取引の振り返り

取引記録の CSV export で税務用に活用。年次パフォーマンスの可視化。
