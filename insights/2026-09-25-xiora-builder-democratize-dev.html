「誰もが 開発 できる」 を 現実化 する — Xiora Builder の 設計 と 3 つ の 割り切り

2026-09-25 公開 / Xiora Insights

結論 先出し

ノーコード ツール は 溢れている の に、 中小事業者 の 手元 に は なぜ 動く もの が 残らないのか。 汎用 に する ほど 学習コスト が 上がり、 テンプレ に する ほど 「自社 の 事情」 に 合わない。 Xiora Builder は この 中間 を 割り切って 設計 した: 入力 は 日本語 の 文章 1 本、 出力 は 動く コード or URL、 テンプレ 化 できない 要件 は 人間 が 24h で 引取。

1. 「誰もが 開発 できる」 を 曖昧 の まま 残さない

「誰でも」 は 3 種類 の 意味 に 分岐 する。 学生 / 業務 担当者 / 経営者 で 求める もの は 違う。 Xiora Builder が 対象 に する の は 業務担当者 —— 日々 の 集計・通知・フォーム・振り分け が 手作業 で 残っている 人。 対象 を 絞ら ない と 「学ぶ ため の ツール」 と 「実務 で 使う ツール」 が 混在 し、 どちら の 用途 に も 中途半端 に なる。

2. テンプレ を 3 分類 に 絞った 理由

  • ① 定期通知 (schedule_notify) — 毎朝・毎週・月末 の 集計 + 通知
  • ② フォーム 記録 (form_sheet) — 入力欄 + 記録先 (Sheets / Notion / kintone)
  • ③ AI 判定 と 振り分け (ai_score) — 入って きた テキスト を 分類 / スコア

実際 の 業務 要望 の 8 割 は この 3 パターン の どれ か に 収束 する。 汎用 の 「何でも 作れる」 は 結局 学習 が 必要 に なり、 導入 が 進まない。 3 テンプレ + 4 番目 は 「人間 引取 (concierge)」 と 割り切って、 1 分 触った ら 動く 物 が 手 に 入る 体験 に 集中 した。

3. AI 生成 を 決定的 な 部分 に 閉じ込める

初期 版 の Builder は 生成 を LLM に 丸投げ し ない。 テンプレ + プレースホルダ 置換 で ほぼ 決定的 に コード を 生成 し、 LLM は 「入って きた 文章 の 分類」 と 「値 抽出」 の みに 使う。 これ に より、 生成 は 再現性 を 持ち、 テンプレ を 見た だけ で 予測 できる。 幻覚 で 使え ない コード が 返る リスク を 意図的 に 下げた。

4. 「詰まったら 人間」 と 明記 する

Free で 触った ユーザー が 詰まる の は 避けられ ない。 これ を 隠さず、 「詰まった 時 は Pro (¥2,980/月) で Xiora が 引取 実装 します」 と 明記 する。 概ね 24 時間 以内 で コード + 手順 を 返す ため、 ここ が 商品 の 芯 に なる。 生成 の 完成度 で 勝負 する の で は なく、 「動く もの が 手 に 入る 確度」 で 勝負 する。

5. どこ で 動く の か

Free 版 の 生成 結果 は Google Apps Script / n8n / kintone の いずれ か に 貼れば 動く 形 で 返す。 Pro 以上 は Xiora Cloud で ホスト を 引取る。 Team は SSO / Slack Bot 連携 と 承認 フロー を 追加 する。 この 段階 は 全て 実 サービス として 使える 状態 で 提供 する。

Xiora Builder は 今日 から Beta 公開。 日本語 で 業務 を 書けば、 30 秒 で 動く コード / 手順 が 手 に 入ります。
