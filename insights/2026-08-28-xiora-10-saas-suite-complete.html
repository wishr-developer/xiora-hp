10 SaaS を 2 層 に 分けて 理解

Xiora の SaaS suite は、 個人事業主 が 抱える 2 大 課題 領域 を 網羅 する 設計 です。

  • ① 業務 効率 化 5 SaaS: 請求書 · 契約書 · 議事録 · メール · 採用 の 定型 業務 を AI が 30 分 → 5 分 に
  • ② SNS 発信 · 集客 pipeline 5 SaaS: hashtag research → 動画 台本 → 8 platform 発信 → 告知 パッケージ → 1-to-1 DM の フル 導線
全 SaaS 共通: 会員 登録 なし。 メール で ログイン リンク が 届く だけ。 CF Pages + Workers AI backend、 データ は 自社 保管。 全 Free tier あり (¥0 で 全機能 試せる)。 Pro は Stripe LIVE 課金 で ¥980-¥1,980/月。

使い始め 方 (1 分 で 完了)

  1. 使いたい SaaS の URL を 開く (上記 「▶ 開く」 リンク)
  2. メールアドレス を 入力 → 「ログインリンク を 送信」
  3. メール 受信 (現在 DEV MODE の ため URL が 直接 画面 に 出ます) → クリック
  4. ダッシュボード に 入って 即使い始め

会員 登録 も、 パスワード 設定 も、 クレジットカード 登録 も 不要 (Free tier は 全機能)。 Pro プラン に 上げる 時 だけ Stripe secure checkout で 決済 する 設計 です。

技術 構成 (全 10 SaaS 共通)

  • Frontend: バニラ HTML / JS SPA、 依存 ゼロ
  • Backend: Cloudflare Pages Functions (serverless)
  • Database: Cloudflare KV × 3 (users / data / sessions) per SaaS
  • AI: Cloudflare Workers AI (@cf/openai/gpt-oss-120b / llama-3.3-70b-fp8-fast) — 第三者 LLM API に データ を 送らない
  • Auth: magic-link (パスワード 不要) + HttpOnly Secure Cookie
  • Payment: Stripe LIVE (JPY subscription、 payment_link で 未 認証 でも checkout 可)
