24/7 AI Customer Agent

xiora は 完全 無人 運営 を 前提 と した SaaS 事業体 です。 その ため 全 product に AI customer agent を 常時 配置、 深夜 も 土日祝 も 中断 なく 対応 いたします。

💬

Chat widget (各 SaaS)

各 product 画面 の 右下 に 常設。 質問 → AI agent → 即時 応答。 コンテキスト (現在 開いている page / 契約 プラン) を 引継 ぎ ながら 会話。

SLA: 応答 < 3 秒
📧

Email (info@xiora-official.com)

受信 → LLM classifier で 分類 (billing / bug / feature / 一般) → AI が draft → 難易度 に 応じ escalation。

SLA: 1 時間 以内 に 初動 応答
🔗

統合 API (法人向け)

Enterprise 契約 の 顧客 は 自社 Slack / Teams から 直接 呼出 可能。 SSO 連携、 role-based access。

SLA: 契約 SLA 準拠
🎥

動画 tutorial (自動 生成)

質問 内容 に 応じ、 AI が 即座 に 該当 機能 の short tutorial (30-60 秒) を 生成 して 提示。 静止 資料 と 動画 の hybrid。

SLA: 即時 生成

応答 フロー

顧客 質問 │ ▼ [AI Classifier] ─── 意図 分類 (billing / how-to / bug / feature 等) │ ├─ 一般 質問 → AI agent 即時 応答 (95%+ の 質問 は ここ で 完結) │ ├─ 複雑 質問 → 上位 AI agent (Rei 相当 の 内部 escalation) │ └─ Absolute gate (billing 変更 / データ 削除 / 契約 / KYC / 権限 変更) └─ Reo 承認 gate へ 提示、 通常 24 時間 以内 に 判断

AI Agent 体制

1st line: Product-specific AI

各 SaaS product は 専属 の AI customer agent を 配置。 契約 プラン / 利用 履歴 / ドキュメント を 全部 参照 して 回答。

  • Sales AI OS — 営業 pipeline / lead 状況 / AI エージェント 動作 説明
  • EC-Autopilot — 商品 リサーチ / 注文 / 発送 / 会計 統合 状況
  • Nexa Academy — 課程 内容 / 進捗 / 修了証 / 会員 プラン 案内
  • Xiora Algo — signal 判読 / TradingView 統合 / 会員 access
  • Gourmie / XCloud Connect / Flow / Aiverse / Xiora Lingua — 各 product 固有 の 支援

2nd line: 汎用 AI (Ocean Chat)

1st line で 解決 しない 複雑 な 質問 は Xiora 自社 開発 の 汎用 対話 AI (Ocean Chat) が 引継 ぎ。 全 product docs + 過去 全 会話 を 参照。

3rd line: 人 (Reo) 承認 gate

Absolute gate 5 種 (billing / delete / permission / contract / KYC) は 必ず Reo 承認。 これ 以外 は 全 AI で 完結。 通常 24 時間 以内 に 判断。

AI 判断 の 説明性

Xiora の AI agent は 全て 「なぜ その 判断 に 至ったか」 の 根拠 を 表示 します。 ブラックボックス 応答 は 憲法 で 禁止。 顧客 は AI 応答 の どの 参照 資料 (docs / 契約 / 過去 会話) を 根拠 に 判断 したか を 常 に 確認 可能 です。

escalation 経路 (Absolute gate)

以下 5 事項 は AI 単独 判断 不可、 必ず Reo 承認 経由:

  • Billing 変更 — 課金 額 / プラン 変更 / 返金 / 追加 請求
  • データ 削除 — 物理 削除 (soft delete は AI 可)
  • 権限 変更 — role escalation / access grant
  • 契約 締結 — 新規 契約 / 更新 / 解約
  • KYC / 本人 確認 — 身分 証 upload / 認証

お問い合わせ

まず 各 SaaS 画面 の chat widget から。 それ で 解決 しない 場合 は info@xiora-official.com (件名 に 該当 product 名) 宛。 24 時間 365 日 (深夜 / 土日祝 含む) 対応 いたします。
