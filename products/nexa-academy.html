Nexa Academy.
実務で使える AI を、コースで。

Xiora Academy は、企業研修 / 塾 / 就活 / 資格 / 投資 の 5 領域を 統合する 教育 SaaS。
商業コース 11 種 + Career 領域 6 SKU + dogfood 3 コース を 段階提供します。
教材は OER 78 sources から 引用強制、出典明示 の 学術水準を 標準採用。

What Nexa is

「AI を 学ぶ」ではなく、
「AI で 仕事を 動かす」教育 SaaS。

既存 の e-learning は 概念解説 が 中心。 Nexa Academy は、実務ワークフロー (Slack / Notion / スプレッドシート / 営業 メール) を そのまま 教材化し、 受講者 が 自社案件 で 使える 状態 で 修了 するよう 設計しています。 個人ライセンス / 法人契約 / 塾向け SaaS の 3 契約形態 で 提供。

Course Domains

5 領域 の 商業コース

B2B 研修 (3 コース)

Slack / Notion / スプレッドシート の AI 自動化。 中小企業 の 情シス代替 として 導入可。 講師派遣 + 録画 の hybrid。

学生塾 (2 コース)

大学生 / 高校生 向け の AI リテラシー + 進路 対策。 塾契約 (法人) と 個人 の 両方 に 対応。

就活・キャリア (3 SKU)

ES 添削 / 業界研究 / 面接シミュレーション を AI で 個別化。 Career 領域 は 6 SKU 用意。

資格対策 (3 コース)

基本情報 / 応用情報 / 統計検定 の 演習 と 添削。 過去問 dataset を 元 に した AI 個別 学習計画。

投資教育 (2 コース)

個人投資家 向け 情報 リテラシー 教育 (投資助言業 に は 該当しない 教育コース)。

Dogfood 3 コース (β)

Xiora 社内 で 実運用 中の 3 コース (Claude Code / Playwright / Ollama) を dogfood として 公開。
