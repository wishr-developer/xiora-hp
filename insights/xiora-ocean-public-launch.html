Xiora が 汎用 対話 AI「Ocean」を 公開 launch — 日本語 native + ¥1,980/月

Xiora 株式会社 が 開発した 汎用 対話 AI「Ocean」を 公開 launch。 日本語 native + Xiora product 統合 + Free ¥0 / Pro ¥1,980/月。 対 ChatGPT Plus (¥3,000) 34% off の 価格帯で SMB / solo founder を 対象に 提供します。

Introduction

Xiora 株式会社 は 本日、汎用 対話 AI product「Ocean」を 公開 launch します。 Ocean は OpenAI ChatGPT / Google Gemini 相当の 汎用 対話 AI で、日本語 native、SMB / solo founder domain 特化、Xiora product ecosystem 統合を 特徴とします。

本記事では Ocean の 位置付け、tier、内部構造、Xiora ecosystem との 関係、今後の roadmap を 公開します。

Ocean の 位置付け

Ocean は Xiora が 開発した 独自の 汎用 対話 AI です。 内部 LLM は Ocean LLM (現 P0 = qwen2.5:7b 借用、P1+ で Xiora domain fine-tuned) を 使用し、Xiora が 運用します。

公開 URL は https://ocean.xiora-official.com/ (DNS 準備中、launch 時 更新)。 login 不要で 即 試用可能、cookie ベースの anonymous session を default とします。

Pro tier ¥1,980/月 は、公表参考価格 ChatGPT Plus ¥3,000/月 と 比較して 34% off の 価格帯です。 SMB / solo founder の 予算に fit する pricing を 目指しました。

差別化 point (5 axis)

1. 日本語 native — SMB / solo founder domain の 語彙 / 商習慣に 特化。 意図しない 多言語 (中国語 / 韓国語) 混入は post-process で 除去します。

2. 憲法 5 条準拠 — 「絶対」「必ず」「保証」等の 過度な断言表現を 使用しない。 hallucination 禁止 (「不明」「未確認」を 明示)。

3. Xiora product 統合 — Aiverse Studio (AI 配信者)、Xiora Academy (AI 学習)、XCloud Connect (SaaS 統合) 等、Xiora ecosystem の 情報を Ocean 経由で 参照可能。

4. 誠実な hedge — 医療 / 法律 / 投資 の 具体 advice は 提供せず、「専門家 相談推奨」の disclaimer を 添付。

5. Xiora account 経由 billing — Stripe 決済は Xiora account (acct_xxx) で 一元管理、user は 単一 subscription で Ocean を 使用可能。

Xiora ecosystem との 関係

Xiora は 複数の AI product を 提供しています。 各 product の 位置付けは 以下の 通りです:

  • Ocean — 公開版 汎用 対話 AI (本 launch 対象)
  • Aiverse Studio — AI 配信者立ち上げ SaaS (AITuber / streaming)
  • Xiora Academy — AI 学習 platform (B2B / 学生 / 資格 / 投資)
  • XCloud Connect — SaaS 統合 hub

Xiora には この他に 社内専用の Chief of Staff AI「Rei (赤坂零)」も 存在しますが、Rei は Xiora 社内 業務専用で 一般 user は 触れられません。 Ocean は 公開版として 独立した product です。

技術構成 (概要)

Ocean は Node.js HTTP server で 実装され、LLM inference は Ollama (localhost:11434) 経由で 実行します。 現状 Free tier は qwen2.5:7b、Pro tier は qwen2.5:14b を base に 使用しています。

今後の P1+ では Xiora domain 特化の fine-tuned model への 差替を 予定しています (詳細 timeline は Reo 判断で 決定)。

content safety は 応答の post-processing で 憲法 5 条違反表現を 検知 / 置換、user input の pre-filter で 違法 / 有害 request を refuse します。

Roadmap

Phase 1 (現在): Free / Pro tier 提供、SMB 対象 marketing。

Phase 2 (3-6 ヶ月): Ocean LLM P1 fine-tune、file upload、API access GA。

Phase 3 (6-12 ヶ月): multimodal (画像 / 音声 入力)、context 32k+、Xiora Academy / Aiverse Studio との 深度 cross-integration。

Phase 4 (12+ ヶ月): Enterprise 契約 (専用 tenant + SSO + Xiora domain 専用 model)。

試用方法

login 不要で https://ocean.xiora-official.com/ から Free tier を すぐに 試用できます。 Pro tier は login (OAuth / Passkey、準備中) 後に Stripe checkout 経由で 申込可能です。
