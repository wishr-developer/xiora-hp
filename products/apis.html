3 APIs

4 core SaaS を 支える 3 内部 API

xiora が 日々 の 自社 業務 で 使用 して いる API を そのまま 外部 提供。 検証 済 の 実 稼働 code base、 品質 は 自社 使用 と 同 水準。

API 01 · business-registry

JP Business Registry API

国税庁 法人 番号 API (国 公開 情報) の wrapper。 13 桁 法人 番号 で 会社 名 · 所在 地 · 設立 日 を 取得、 曖昧 検索 も 対応。 Postgres cache 30 日、 レスポンス 数十 ms。

  • GET /v1/companies/{corporate_number}
  • GET /v1/companies/search?q=xxx&limit=10
API 02 · text-normalize

Japanese Text Normalization API

全角/半角 変換、 送り 仮名 正規化、 住所 郵便 番号 展開、 姓 名 分離 · furigana 推定。 Xiora Lingua の 内部 normalizer を 転用。

  • POST /v1/normalize/text
  • POST /v1/normalize/address
  • POST /v1/normalize/name
API 03 · contact-extract

xiora Contact Extraction API

HP の URL または HTML から email · phone · 住所 · 代表 者 名 · 会社 名 を 抽出。 LLM 補助 + regex fallback、 各 field に confidence score を 付与。

  • POST /v1/extract/contact

SDK snippets

3 言語 で 即 呼出

Python · JavaScript · curl。 `X-RapidAPI-Key` ヘッダ 1 つ で 動作、 追加 SDK 不要。

Python (requests)

import requests

url = "https://xiora-official.com/api/v1/companies/2011101044774"
headers = {"X-RapidAPI-Key": "YOUR_RAPIDAPI_KEY"}

resp = requests.get(url, headers=headers, timeout=10)
resp.raise_for_status()
company = resp.json()

print(company["name"], company["address"])
# → 株式会社 example  東京都渋谷区道玄坂1-10-8

JavaScript (fetch)

const url = "https://xiora-official.com/api/v1/normalize/text";
const body = {
  text: "ＸＩＯＲＡ　の　商　品　",
  options: { fullwidth_to_halfwidth: true, collapse_spaces: true }
};

const resp = await fetch(url, {
  method: "POST",
  headers: {
    "X-RapidAPI-Key": "YOUR_RAPIDAPI_KEY",
    "Content-Type": "application/json"
  },
  body: JSON.stringify(body)
});
const data = await resp.json();

console.log(data.normalized);
// → XIORA の 商品

curl

curl -X POST "https://xiora-official.com/api/v1/extract/contact" \
  -H "X-RapidAPI-Key: YOUR_RAPIDAPI_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url": "https://xiora-official.com/company.html"}'
