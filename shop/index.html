POD マーチ (α 準備中)

Xiora ブランド、Kakuyomu 作品 (赤坂零 名義)、KigenX キャラクター の T-shirt / tote / mug / stationery を、Print-on-Demand (Suzuri / Printful) 経由で 完全無在庫販売。 在庫 リスク ゼロ、24 時間 supplier 発送、全国 送料 商品込み。

Xiora Shop の 3 つの原則

  • 在庫ゼロ · 資本ゼロ: 全商品 は Suzuri / Printful の POD supplier が 受注 → 印刷 → 発送 の 一連 を 担当。 Xiora は デザイン と 商品説明 のみ 提供。
  • Xiora IP 中心: 汎用グッズ でなく、Xiora 既存 IP (Kakuyomu 3 作品 / KigenX キャラ / Xiora ブランド アイコン) を 中心 に 展開。 audience が 既に 存在。
  • 返品 / 配送 は supplier 責任: Xiora は 顧客窓口 として 一次対応、実務 は supplier 側 process。 SLA と 品質 は supplier の 実績 に 依存。
