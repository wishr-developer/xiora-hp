Web で 動く 語学 学習 サービス を 選ぶ 3 判断 軸 — インストール · Free tier · 進捗 保存

2026-07-28

まず 状況 の 整理

語学 学習 サービス の 多く は 「iOS/Android アプリ を install する」形 が 主流 です。 一方 で 「PC で 使いたい」「install したく ない」「今 すぐ 試したい」といった ケース で は、 Web ブラウザ で 動く タイプ の サービス が 選択肢 に なります。

Web 型 は 手軽 で ある 一方、 App Store / Google Play に 掲載 され て いない ため、 選ぶ 際 の 判断 材料 が 少 ない こと が あります。 本 記事 で は、 Web 型 語学 学習 サービス を 選ぶ 時 に 見る べき 3 判断 軸 を 整理 します。

軸 1 — インストール の 要 · 不 要

Web 型 サービス で も、 3 段階 が あります。

  • 完全 Web (install なし): ブラウザ で URL を 開く だけ で 動く。 アカウント 登録 も opt-in。 試験 導入 に 向く。
  • PWA (Progressive Web App) 対応: Web だ が 「ホーム 画面 に 追加」で アプリ の ように 起動 できる。 オフライン 対応 の 有無 は サービス に よる。
  • Web 版 + native アプリ 併用: 大手 サービス に 多い。 進捗 は 同期 され る が、 一部 機能 (音声 練習 等) は アプリ 限定 の こと が ある。

初 めて 試す なら 「完全 Web (install なし)」が 摩擦 が 少ない。 継続 する と 決めた 段階 で PWA / native アプリ に 移行 する の が 実 運用 で は 現実 的。

軸 2 — Free tier で どこ まで 使える か

Web 型 語学 サービス の Free tier は、 大 きく 4 パターン に 分類 できます。

  • A. lesson 数 に 制限 なし + 広告 表示: 全 lesson が 使える が、 学習 中 に 広告 が 挿入 される。
  • B. lesson 数 に 制限 あり (最初 の N lesson のみ Free): 続き は 有料 tier。
  • C. 全 機能 Free (課金 は 別 tier の 機能 拡張 のみ): 基本 は 完全 無料。 課金 は 家族 共有 · 詳細 学習 履歴 · 追加 course 等。
  • D. Free tier なし (全 tier 有料): 有料 会員 モデル。 trial 期間 (7-14 日) を 提供 する サービス が 多い。

短期 で 集中 学習 したい なら B か D の 有料 tier、 継続 で 少 しずつ 進 めたい なら A か C の Free tier が 適して います。 選ぶ 前 に 「何 lesson まで Free で 使えるか」「有料 tier で 何 が 追加 され るか」を 明示 して いる サービス を 選ぶ の が 安全 です。

軸 3 — 進捗 の 保存 場所

Web 型 の 進捗 保存 に は 3 種類 が あります。

  • ① browser localStorage (匿名): アカウント 不要、 学習 は すぐ に 始められる。 但 し、 browser data を 削除 する と 進捗 も 消える。 別 device (PC → iPhone 等) に 引き継 げない。
  • ② アカウント 登録 (email + password): 進捗 が cloud に 保存 され、 別 device で も 復元 できる。 サービス 側 に 学習 履歴 が 保存 される 点 は 認識 が 必要。
  • ③ OAuth (Google / Apple / X 等 で ログイン): ①② の 中間。 サード パーティ 認証 経由 で アカウント が 紐 づく。

「試す 段階」なら ①、「継続 する と 決めた」なら ② に 移行 する の が 一般 的。 サービス に よって は ① で 始めて ② に 途中 で 移行 できる もの も あります。

3 判断 軸 の 適用 例 — Xiora Lingua v1.0 (自社 例)

xiora が 提供 する Xiora Lingua v1.0 を 3 軸 で 記述 する と 以下 に なります (2026-07-27 時点)。

  • 軸 1 (インストール): 完全 Web + PWA 対応 (ホーム 画面 追加 可能)。 native アプリ 版 は 「事業 見直し 中」に 集約。
  • 軸 2 (Free tier): 上記 パターン C 相当。 現在 は 43 lesson × 3 course (日常 · 旅行 · 表現力) を Free で 全 開放。 Super (¥980/月) / Family (¥1,980/月) は LIVE (Stripe 決済 稼働 中)。
  • 軸 3 (進捗 保存): ① browser localStorage で 開始 → 途中 で ② アカウント 登録 (email + password) に 移行 可能。 device 間 で 進捗 復元 可。

試す なら: xiora-official.com/lingua.html に アクセス し、 install や 登録 なし で 1 lesson 触って みる。 続け たい と 感じたら アカウント 登録 で 進捗 保存 に 移行、 という 使い 方 を 想定 して います。

まとめ

Web 型 語学 学習 サービス を 選ぶ 時 は、

  1. インストール の 要否 (完全 Web / PWA / native 併用)
  2. Free tier の 範囲 (全 lesson / 一部 lesson / 追加 機能 有料)
  3. 進捗 の 保存 場所 (localStorage / アカウント / OAuth)

の 3 軸 を 事前 に 確認 して おく と、 「試す → 続ける → 使い 分ける」の 判断 が スムーズ に なります。

本 記事 は 一般 情報 として の Web 型 語学 サービス 選び の 判断 軸 を 整理 した もの です。 個別 の サービス の 品質 · 学習 効果 は 実 使用 環境 で ご 確認 ください。 xiora は 学習 成果 · 語学 資格 取得 を 保証 する もの では ありません。
