Xiora が実際に使っている / 推奨する Tool 一覧

Xiora が単独創業 SaaS 会社の運用で実際に使っている、AI エージェント / SaaS / VPS / 書籍 / 開発ツールの一覧です。 選定理由と使い所を分野別に整理しています。 情報は 2026-07-19 時点のものです。 一部リンクにはアフィリエイトを含みます。

AI エージェント / LLM 基盤

  • Anthropic Claude (API + Claude Code) — Xiora の brain runtime と代理人層の主軸。 24/7 handler の実行 / draft 生成 / コードレビューに使用。 公式サイト。
  • Ollama (self-hosted) — VPS 上でローカル LLM を動かす際の runtime。 コスト最適化と egress 縮小に有効。 公式サイト。
  • Model Context Protocol (MCP) — Stripe / Gmail / GitHub 等の外部 SaaS を Claude から直接叩くための共通プロトコル。 公式仕様。

SaaS / 決済 / 分析

  • Stripe — 決済 / Subscriptions / Webhook。 Xiora の billing-core-service の中心。 公式サイト。
  • GA4 + BigQuery — サイト計測 / 意思決定基盤。 GA4 は無料、BigQuery は従量。 GA4。
  • Notion — ナレッジ / task / 内部ドキュメント。 公式サイト。

Hosting / VPS / エッジ

  • ConoHa VPS — Xiora の Edge Gateway が動く VPS。 東京リージョン / 従量。 公式サイト。
  • Vercel — Next.js アプリのデプロイ / Preview。 Xiora HP や Nexa の一部が稼働。 公式サイト。
  • Railway — Docker container 単位で小規模サービスをデプロイ。 公式サイト。
