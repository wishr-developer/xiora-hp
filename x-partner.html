Service Lineup

3 つのサービスで、
事業を支える。

02 / Platform

X Partner Core

クライアント案件と
運営を一元管理する基盤

準備中

X Partner の運営基盤として、Xiora が内部で構築している管理プラットフォームです。クライアントごとの案件、契約、請求、改善ロードマップを一元管理し、伴走する側の品質と透明性を担保します。将来的にはクライアント企業も状況をリアルタイムで参照できるポータルとして提供することを構想しています。

  • 案件・契約・請求の一元管理
  • クライアント別 改善ロードマップ
  • 月次レポート自動生成
  • 支援履歴のナレッジ化
  • クライアント向けポータル（構想）
  • 担当割当・稼働可視化
開発状況について問い合わせる

※ Xiora 内部の運用から段階的に展開中です。クライアント向けの公開時期は未定です。

03 / Future

X Link

企業 DB と
BtoB マッチング構想

構想中

X Partner の伴走を通じて蓄積される、中小企業の事業情報・採用ニーズ・取引候補のデータを基盤に、企業 DB と BtoB マッチングを提供していく構想です。「Web 制作の発注先」「採用の応募者」「営業先候補」が一つのネットワークで繋がる ── そこまでが、X Partner ブランドの最終ゴールです。

  • 中小企業向け 企業 DB
  • BtoB マッチング（発注 × 受注）
  • 採用候補 × 企業マッチング
  • 業界別ナレッジ / ベンチマーク
  • API による外部連携
  • クライアント参加型ネットワーク
構想について意見交換する

※ 現在は構想段階です。協業・実証パートナー企業を募集しています。

Roadmap

X Partner の歩み。

サービス、運営基盤、ネットワークの順に、段階的に立ち上げていきます。

  1. Now ─

    X Works 提供開始

    Web 制作・保守・採用ページの定額伴走サービスとして、X Works の提供を開始しています。

  2. Next ─

    X Partner Core 内部運用

    Xiora 内部での案件・契約・運営ナレッジ管理として、X Partner Core を段階的に運用開始。クライアント向けの公開は次フェーズです。

  3. Later ─

    X Partner Core 外部公開

    クライアント企業向けのポータルとして X Partner Core を公開。案件状況・改善ロードマップ・月次レポートをリアルタイムで参照できる体験を提供します。

  4. Vision ─

    X Link 構想の実証

    蓄積された中小企業ネットワークを基盤に、企業 DB と BtoB マッチング、採用ネットワークの実証を開始予定です。協業パートナー企業を募集しています。

FAQ

よくあるご質問

Xiora と X Partner の関係を教えてください。

X Partner は、Xiora が運営する中小企業向けの伴走ブランドです。Xiora 本体が AI・DX・Web Engineering を含むより広い領域を扱うのに対し、X Partner は中小企業の Web・採用・営業に特化し、長期の伴走を前提に設計しています。

X Works のプランや料金を知りたいです。

事業フェーズ・サイト規模・運用範囲によりプランをご提案しています。スポット制作のみのご相談、または月額の伴走プランの両方に対応可能です。詳細は商談時にご案内します。

X Partner Core はいつ使えるようになりますか?

現在は Xiora 内部運用フェーズです。クライアント向けの公開時期は未定ですが、X Works の継続クライアントから順次ご案内する予定です。最新状況はお問い合わせください。

X Link はサービスとして使えますか?

X Link は現在「構想中」のフェーズで、サービスとしては未提供です。実証フェーズに向けた協業・パートナー企業を募集しています。ご興味のある方はご連絡ください。

遠方の企業でも対応してもらえますか?

全国対応しています。オンライン MTG を中心に、必要に応じて訪問も承ります。
