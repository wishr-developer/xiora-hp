海外 LMS 3 大 platform の 概観

本 記事 で 比較 対象 と する 海外 LMS は 以下 3 本 です。 いずれ も 一般 公開 情報 に 基づく 概要 で、詳細 仕様 は 各 サービス の 公式 サイト を ご 参照 ください。

  • Teachable (US) — 個人 course creator 向け の 定番 LMS、$59-$249/月 帯 の 3 tier + Free。 主 機能 は course 販売、決済 (Stripe/PayPal)、drip コンテンツ、affiliate。 UI と 決済 は 英語 と USD 中心。
  • Thinkific (CA) — 中規模組織 向け LMS、$49-$499/月 帯 の 4 tier + Free。 course 販売 + Communities + membership + certificates。 UI 英語、加/多言語 パック あり。
  • Docebo (US) — Enterprise LMS、価格 非公開 の quote-based (数十万 ~ 数百万 円/年 帯)。 SCORM / xAPI / SSO (SAML/OIDC) / API 連携 が 標準、AI features も 提供 (Docebo AI)。 大企業 導入実績 多数。

3 本 に 共通 する のは、いずれ も US/カナダ 発 で 英語 UI 中心、決済 通貨 は USD 主軸、AI 機能 の 深統合 (講師 / 採点 / ロードマップ 生成) は 一部 tier のみ、という 現状 です。 Nexa Education OS は この 3 領域 の 交点 (日本語 + 円 + AI 内蔵) を 埋める 目的 で 作られて います。

差別化 factor 1: 日本語 native (UI + サポート + 教材)

日本 の 教育機関 / 塾 / 企業研修 部門 で LMS 導入 する 際 の 最大 の 摩擦 は「UI を 教員 / 講師 / 受講者 に 理解 して もらう コスト」です。 Nexa は UI・通知・エラーメッセージ・サポート documentation を 全て 日本語 native で 設計、教員研修 の 心理的 抵抗 が 大幅 に 下がり ます。

UI 側 の 違い:

  • Nexa の admin UI / 受講者 UI は 全画面 日本語、丁寧語 統一。 教員 が 5 分 で 迷わず 操作 できる 想定 で 設計
  • Teachable / Thinkific / Docebo は 英語 UI が 基本、日本語 化 は community 翻訳 or 独自 手配 が 必要 な こと が 多い
  • カテゴリ 名 / 教材種別 / 通知文 も 日本語 プリセット (講座 / レッスン / 受講者 / 修了証) を 内蔵

サポート の 違い:

  • Nexa は 日本 時間 帯 の 平日 メール 一次対応 24h 以内 (Enterprise は 専任 CS)
  • 海外 LMS は 主 サポート が 英語、日本 timezone 対応 は 別料金 or 未対応 の ケース あり
  • ISMS 準拠 の 情報 セキュリティ 運用 (Nexa) は 国内 の 教育機関 / 士業 で 好感 度 高

fit する 組織: 教員 / 講師 / 受講者 が 日本語 UI を 好む、日本国内 の 学習塾 / 予備校 / 企業研修部門 / 士業事務所 / 自治体・公共機関 / 医療・介護研修、日本 timezone サポート が 必須。

海外 LMS が fit する 組織: 講師 / 受講者 が 英語 native、grosser global 展開 前提、既に Teachable / Thinkific / Docebo の コミュニティ に 参加 済、course 販売 の 主 マーケット が 北米。

差別化 factor 2: Stripe ¥ decimal 決済 (国内 商習慣 に fit)

LMS の 決済 flow で 日本 組織 が 直面 する 摩擦 は「USD 決済 → 為替 手数料 → 日本 会計 上 の 円換算」です。 Nexa は Stripe の JPY 直接決済 を 前提 に 設計、¥1,980 / ¥9,800 / ¥29,800 / ¥98,000 の 整数 円建て で 領収書 / 請求書 / 会計 連携 が 完結 します。

Nexa の 決済 側:

  • Stripe JPY 直接決済、integer 円建て で 為替 手数料 なし
  • 領収書 (適格請求書 / インボイス制度 対応) の PDF 自動発行
  • クレカ + 銀行振込 (Enterprise) + 請求書払い (法人 契約) 対応
  • Xiora が 一元 request 発行、複数 tier / 複数契約 の 統合請求 可

海外 LMS 側 の 決済:

  • Teachable / Thinkific は USD 主軸、JPY 対応 は 一部 tier + 為替手数料 発生
  • Docebo は quote-based で 個別交渉、法人契約 の 円建て 対応 は 可能 だが 商談 期間 長
  • 海外 SaaS の 領収書 は 適格請求書 (インボイス制度) の 記載要件 を 満たさない こと あり、会計 顧問 と 別途 調整 が 必要

fit する 組織: 国内 の 会計事務所 と 顧問契約、インボイス制度 対応 領収書 が 必要、経理 が JPY 会計 の 円建て 直接記帳 を 好む、稟議 で 為替 リスク 議論 を 避けたい。

海外 LMS が fit する 組織: 米国 現地法人 経由 で 決済、既に 海外 SaaS を 多数 契約中、USD 建て の 会計 が 標準、course 販売 の 収益 も USD 建て で 受取 前提。

差別化 factor 3: AI 内蔵 (講師 / 採点 / ロードマップ が 中核 に 組込)

LMS × AI の 統合 は 2025 年 以降 の 主 トレンド ですが、Nexa Education OS は AI を「add-on」で は なく LMS の 中核 に 据えて います。 学習者 一人 ひとり の 学習 履歴 を 前提 に、AI が 講師 / 採点 / ロードマップ 生成 を 分担 します。

Nexa の AI 6 機能:

  • AI 講師 チャット: 24 時間 いつでも 質問できる AI メンター、教材 文脈 を 理解 して 回答
  • AI 学習 ロードマップ: 受講者 の 目標・現在地・過去実績 から 個別 カリキュラム を 自動生成
  • AI 採点・フィードバック: 記述問題 を AI が 即時採点、改善点 を 具体的 に 文章 で フィードバック
  • AI 問題生成: 教材 から 自動 で 小テスト・練習問題・復習カード を 生成
  • 弱点分析 + 教材推薦: 学習履歴 を 解析し 弱点 を 検出、次 に 学ぶ べき 教材 を 自動 レコメンド
  • Adaptive Learning: 受講者 の 理解度 に 応じて 教材難度 を 動的 に 調整

海外 LMS 側 の AI 状況:

  • Teachable / Thinkific は AI 統合 が 進行中 だが、主に course 作成 補助 (AI アシスタント) レベル、講師 / 採点 / ロードマップ の 深統合 は 限定的
  • Docebo は Docebo AI で 学習推薦 + 自動 タグ付け 等 の 機能 を 提供、深い統合だが 上位 tier + 追加料金
  • 海外 LMS の AI は 英語 教材 に 最適化、日本語 教材 での 精度 は 別途評価 が 必要

fit する 組織: 講師リソース が 限られる 中規模組織、AI で 個別対応 を スケールしたい、受講者 の 学習 継続率 を KPI に 置いて いる。

海外 LMS が fit する 組織: 英語 講義 が 主、既存 AI 基盤 (Google AI / Microsoft Copilot) との 統合 を 優先、AI は 別途 内製 する 方針。
