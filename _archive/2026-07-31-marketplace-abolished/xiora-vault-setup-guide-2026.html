FAQ

よくあるご質問。

  • 実 credential 値 は 含まれていますか?

    いいえ、含まれていません。 本ガイドは pattern のみ を 記述しており、Xiora の 実 credential 値 は 一切 含みません。 実運用 の 値 は 皆様 の 環境 に あわせて 入力してください。

  • macOS 以外 (Windows / Linux) でも 使えますか?

    Linux は systemd-creds を 使う手順を 収録しています (section 10)。 Windows Credential Manager は 本 v1.0 では 未収録 (次版で追加予定)。

  • rotation は どのように 運用しますか?

    section 13 で rotation / 削除 の 具体 手順 を 記述。 新 key を 別名 で 追加 → application 側 参照切替 → 動作確認 → 旧 key 削除 → rename の 4 段 flow。
