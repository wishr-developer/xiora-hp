Build with us · インターン / アソシエイト

"受ける" のではなく、
一緒につくる。

Xiora は、AI / SaaS / Web を事業に実装する Founder-led の少数精鋭チームです。
ここで募集しているのは "雑用インターン" ではなく、プロダクトと事業を一緒に育てる仲間です。

  • 長期 / 週 2 日〜
  • フルリモート可
  • 学生・社会人どちらも
  • 有償 / 業務委託

Why now

"AI を作れる人" は増えた。
でも "事業に実装できる人" は、まだ少ない。

AI モデルやライブラリは強力になりました。一方で、それを実際の業務に組み込み、安全に、継続的に運用できる人は驚くほど不足しています。
Xiora は、その "実装力" を育てる場でありたいと考えています。

What you'll do

どんな仕事をするか。

受託案件、自社プロダクト (XCloud / XBeauty)、新規事業。フェーズに応じて、設計・実装・改善のどこかに必ず関わってもらいます。

01 AI / RAG

AI アプリケーション実装

OpenAI / Anthropic API を使った RAG、エージェント、Bot、ドキュメント生成系の機能設計と実装。プロンプト設計から運用監視まで。

  • RAG / ナレッジ検索
  • LLM 評価 / 改善
  • Guardrail / 監査ログ
02 SaaS / Product

SaaS プロダクト開発

XCloud / XBeauty などの自社プロダクト開発。マルチテナント、課金、ダッシュボード、運用基盤まで一通り触ります。

  • 機能設計 / 実装
  • 顧客ヒアリング
  • 運用 / モニタリング
03 Web / Frontend

Web / フロントエンド実装

Next.js / TypeScript を中心に、コーポレートサイトや LP、業務管理画面の UI 実装。デザインからコードまでを一気通貫で。

  • Next.js / TypeScript
  • UI / UX 改善
  • パフォーマンス最適化
04 Automation

業務自動化 / 内部ツール

自社・顧客の業務フローを観察し、AI と自動化で社内の手作業を削る。スクリプト・社内ツール・連携設計まで。

  • 業務観察 / 設計
  • スクリプト / API 連携
  • 社内ツール構築

What you'll learn

ここで得られるもの。

"AI で何ができるか" の知識ではなく、"AI で事業を動かすには何が要るか" の手触り。

  1. 01

    "動く" を出すまでの速度。

    アイデアからプロトタイプまでを 1 週間で出す感覚。考えすぎず、しかし雑にしない実装の手癖。

  2. 02

    AI を業務に "実装する" 設計。

    プロンプトを書く力ではなく、入出力・権限・ログ・評価まで含めて運用に乗せる設計。

  3. 03

    事業と技術の往復。

    顧客の業務を観察し、技術で何を解くかを自分で決める経験。コードだけ書いていてはたどり着けない判断力。

  4. 04

    少数精鋭のチーム運用。

    ドキュメント、レビュー、リリース、運用監視まで。"作って終わり" にしない開発の習慣を、Founder と同じ目線で身に付けます。

Who we're looking for

こんな人と、一緒に作りたい。

必須

  • "自分で調べて手を動かす" 習慣がある
  • Git / GitHub の基本操作ができる
  • 何かしらの言語で動くものを作ったことがある (個人開発で可)
  • 納期 / コミュニケーションへの誠実さ

歓迎

  • Next.js / TypeScript / Python の実装経験
  • OpenAI / Anthropic API の利用経験
  • 個人開発・OSS・ハッカソン等で作ったものがある
  • 事業 / プロダクト / スタートアップに本気で興味がある

合わないかもしれない人

  • "作業を渡されたい" タイプ
  • "AI に詳しい人" を見学したい人
  • 納期や報連相に無頓着な人
  • 事業よりも肩書きが優先な人

Process

応募から参加まで。

  1. 01

    カジュアル面談 (30 分・オンライン)

    お互いの期待値合わせ。志望動機よりも、これまでに作ったもの・興味のある領域を教えてください。

  2. 02

    簡単な実装課題

    数時間〜半日程度。コードレビューを通じて、一緒に働くイメージを確かめます。

  3. 03

    業務委託契約 / NDA 締結

    条件・関わる範囲を明確にしたうえで開始。アサインは希望と適性をすり合わせます。

  4. 04

    ジョイン

    初週はオンボーディング。2 週目以降、実案件 / 自社プロダクトに少しずつ入ってもらいます。
