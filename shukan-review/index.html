Xiora 週次経営レビュー Web

個人事業主 / SMB 経営者 の 週次 KPI (売上 / 経費 / 時間配分 / 案件進捗) を 5 分入力 → LLM が 5 観点 (数字妥当性 / 前週比較 / リスク / 機会 / 次週アクション) で 60 秒 分析。 「なんとなく」の 週次判断 を 客観指標 に。

使い方

  1. Anthropic API key を 取得 (console.anthropic.com)
  2. 下記 に 貼付 (localStorage 保存)
  3. 今週 / 前週 の KPI を 数字入力
  4. 「週次レビュー実行」→ 5 観点分析 が返る

Xiora サーバー は 一切 受信 しません、 直接 Anthropic API に 送信。

よくある質問



Q. freee を すでに 使っています。 併用?


A. はい。 freee で 会計仕訳、 本ツール で 週次 KPI 判断。 5 分入力 で 済む ので 併用負担 小さい。



Q. データ は Xiora サーバー に 送られる?


A. いいえ。 browser から Anthropic API に 直接。 数字 も 案件情報 も Xiora は 一切 受信 しません。



Q. 業種 特化 は?


A. 業種欄 に入力 すると LLM が 業界平均 に照らして 分析。 順次 業種別 プロファイル 拡充予定。
