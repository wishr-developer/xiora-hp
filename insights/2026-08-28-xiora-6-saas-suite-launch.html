共通 の 設計 思想

  • 会員 登録 なし — メール で ログイン リンク が 届く、 パスワード 不要
  • Free tier 必ず あり — 買う 前 に 全機能 を 体感 できる
  • 自社 backend — Cloudflare Pages Functions + KV、 データ は Xiora 側 で 完結
  • AI は Cloudflare Workers AI — 第三者 LLM API (OpenAI/Anthropic) に データ を 送らない
  • DLP 統制 済 — 20 パターン の 秘密情報 (API key / マイナンバー 等) を 自動 検出・遮断

実 使用 例 · 週 の 業務 短縮

  • 月曜: 週次 打ち合わせ 3 本 → Gijiroku で 議事録 化 (15 分 × 3 → 3 分 × 3 = 36 分 短縮)
  • 火曜: 新 顧客 契約 レビュー → Keiyaku で 気づき 提示 (45 分 → 5 分 = 40 分 短縮)
  • 水曜: 業務委託 候補者 3 名 レビュー → Saiyou で fit score + 質問 (60 分 → 10 分 = 50 分 短縮)
  • 木曜: 週 の SNS 発信 → Kakusan で 8 platform 一括 (60 分 → 3 分 = 57 分 短縮)
  • 金曜: 請求書 5 通 発行 → Seikyuu で 一括 (50 分 → 10 分 = 40 分 短縮)
  • 常時: ビジネス メール 10 通 → Otegami で 起草 (100 分 → 20 分 = 80 分 短縮)

週 合計 短縮: ~5 時間。 時給 ¥3,000 換算 で 週 ¥15,000、 月 ¥60,000 の 時間 価値。 Pro 全 ¥8,380/月 で ROI 7 倍。
