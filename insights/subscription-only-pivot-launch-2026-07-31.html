Xiora サブスク 一本 pivot 開始 — 4 core を 継続 課金 型 で 一般 販売 開始 (2026-07-31)

結論

2026-07-31、 xiora は 全 販売 経路 を サブスク 一本 に 統一 し、 4 core (Kigen · Nexa Academy · XCloud Connect · Xiora Lingua) の 一般 販売 を 開始 しました。 単発 買切 販売 は 全 種 で 廃止、 継続 課金 型 の サブスク · 月額 プラン のみ で 提供 します。

サブスク 契約 前 に 明示 している 事項 (特電法 · 消契法 遵守)

各 LP に 「サブスク 契約 前 に 確認 いただきたい 5 項目」を 掲載 しています。 継続 課金 定期 購入 の 事前 開示 義務 を 遵守 する 目的 です。

  • 初回 課金 タイミング: サブスク 決済 完了 と 同時 に 初回 課金 · 即時 利用 開始 (税込)
  • 次回 課金 日: 毎月 契約 起算 日 に 自動 決済 (例: 8/5 契約 → 9/5 次回 決済)
  • 解約 手順: 各 サブスク 管理 画面 の 「解約」ボタン 1 tap で 手続 完了 (電話 · 引き止め なし)。 Kigen は iOS 標準 の Apple ID サブスク 管理 経由 (3 tap)
  • 領収 書: 決済 完了 メール + Stripe billing portal (Nexa/XCloud/Xiora Algo) or Apple ID メール (Kigen) で 自動 発行
  • データ 保持: 解約 後 も 学習 履歴 · 進捗 · 期限 データ は 30 日 間 保存 (再 契約 で 復元 可)

特商法 に 基づく 表記 は /legal/tokusho.html に 全 プロダクト 一覧 と 価格 · 支払 時期 · 解約 手続 の 詳細 を 掲載 しています。

なぜ サブスク 一本 か

xiora は 以下 の 3 つ の 理由 で 販売 経路 を サブスク 一本 に 統一 しました。

  1. 継続 サービス 提供 の 前提 と の 整合: 教育 · SaaS · アプリ の いずれ も 「継続 更新 · 継続 サポート」を 前提 と する 領域。 単発 買切 は 「一度 買ったら 放置」が 発生 しやすく、 実 効用 と の 齟齬 が 起きる。
  2. 顧客 と の 関係 継続: サブスク は 「契約 中 = 顧客」の 明確 な 状態 が 続き、 update · 追加 機能 · サポート の 提供 が 継続 できる。 単発 買切 は 決済 後 に 関係 が 途切れ やすい。
  3. 料金 の 予測 可能 性: 月額 の 固定 額 は 個人 · 法人 の 両方 で 予算 計画 が 立て やすい。 「¥19,800 単発 vs ¥1,980/月 の 選択」は 顧客 の 判断 コスト が 高く、 サブスク 一本 に 統一 する こと で 選択 が シンプル に なる。

単発 買切 販売 の 廃止 は 顧客 の 「一度 だけ 試したい」ニーズ に は 応 えられ ない 側面 も あり ます。 xiora は これ を Free tier と いつ でも 解約 可 の 2 つ の 装置 で 打ち消し ます。 Kigen Free · Nexa Free · Xiora Lingua Free の 3 tier は 完全 無料 で 継続 利用 可、 有料 サブスク は 1 tap で 解約 可能 です。

今後 の 追加 予定

現在 「事業 見直し 中」の pillar (Sales AI OS · EC-Autopilot · Gourmie · AISHAIN · Xiora Algo 等) は、 各 pillar の 実 収益 · 差別 化 · Reo 単独 運用 の 3 軸 で 再 評価 中。 販売 再開 の 際 は 全て サブスク pricing に 統一 します。 単発 買切 · Lifetime プラン の 新規 提供 は 今後 も 行い ません。

Nexa Academy は 現在 27 課程、 順次 拡充 予定 (士業 · 資格 · 副業 · 起業 · 個人 事業 領域)。 XCloud Connect は 越谷 · 草加 の SMB 導入 pipeline から 埼玉 全域 (春日部 · 川口 · 大宮) へ 展開 中。

販売 開始 と 免責

2026-07-31 以降、 上記 4 core の 一般 販売 が 継続 稼働 中 です。 決済 · サポート · 解約 は 全 セルフ サーブ で 24/7 対応。 お問い合わせ は info@xiora-official.com まで。

本 記事 の 価格 · 料金 · 課程 数 は 2026-07-31 時点 の もの で、 変更 され る 場合 が あります。 資格 合格 · 副業 収入 · 事業 の 成功 を 保証 する もの では ありません。 サブスク 継続 · 解約 に 関する 詳細 は 特商法 に 基づく 表記 と 各 LP を 併せて ご 確認 ください。
